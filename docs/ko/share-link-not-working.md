# 바이두 넷디스크 공유 링크가 안 열릴 때: 메시지별 의미

`pan.baidu.com` 링크를 열었더니 파일 목록 대신 짧은 중국어 메시지만 나옵니다. 이 페이지에서는 그 메시지가 무슨 뜻인지, 무엇을 할 수 있는지 알려 드립니다.

## 먼저 주소를 확인하세요

정상적인 링크는 `https://pan.baidu.com/s/1…` 형태이고, `1` 뒤에 영문자와 숫자가 길게 이어집니다. 링크를 열고 나면 브라우저에 `https://pan.baidu.com/share/init?surl=…`가 대신 표시될 수 있는데, 같은 공유입니다.

복사할 때 링크가 잘렸다면 열리지 않습니다. 원래 메시지에서 끝까지 다시 복사하세요.

## 페이지가 알려 주는 것

| 보이는 것 | 의미 | 해결할 수 있는 사람 |
| --- | --- | --- |
| 4자리를 입력하라는 입력란 | 보호된 공유입니다. [추출 코드](extraction-code.md)가 필요합니다 | 소유자에게 받은 코드로 본인이 |
| 너무 늦게 왔고 공유가 취소되었다는 메시지 | 소유자가 공유를 중단했거나 바이두가 파일을 삭제했습니다 | 소유자 |
| 권리 침해나 금지된 콘텐츠에 관한 메시지 | 바이두가 공유를 차단했습니다 | 아무도 없음: 공유는 계속 차단된 상태로 남습니다 |
| 일부 파일이 걸러졌다는 안내가 붙은 파일 목록 | 공유 일부가 바이두 규정을 어겨 숨겨졌습니다 | 소유자 |
| 공유가 더 이상 유효하지 않다는 메시지 | 공유 기간이 만료되었습니다 | 소유자 |

브라우저의 번역 기능을 쓰면 이 메시지들을 구분하기 쉽습니다.

## 해결 방법

- **코드가 거부될 때:** 원래 메시지와 한 글자씩 비교하세요. [추출 코드](extraction-code.md)를 참고하세요.
- **공유가 취소되었거나 만료되었을 때:** 소유자에게 파일을 다시 공유하고 새 링크와 코드를 보내 달라고 하세요.
- **공유가 차단되었을 때:** 받을 수 있는 것이 없습니다. 파일이 다른 곳에도 있는지 소유자에게 물어보세요.

## 돈을 내기 전에 확인하세요

[PanPull 링크 확인](https://panpull.com/ko?utm_source=github&utm_medium=tutorial#link-checker)에서 링크를 시험해 보세요. 확인은 무료입니다. 읽을 수 있는 공유라면 파일 수, 총용량, 요금이 나옵니다. 읽을 수 없으면 대신 오류가 표시되고, 요금은 청구되지 않습니다.

삭제, 취소, 차단된 공유를 되살릴 수 있는 서비스는 없습니다. PanPull에서는 실패하는데 소유자 쪽에서는 잘 열린다면 잠시 뒤에 다시 시도해 보세요. 일시적인 문제일 수 있습니다.
