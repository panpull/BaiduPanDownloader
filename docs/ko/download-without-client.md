# 바이두 넷디스크 클라이언트 설치 없이 Windows·Mac·Linux 브라우저로 다운로드하기

바이두 넷디스크 공유에서 다운로드 버튼을 누르면 중국어 팝업이 뜨면서 바이두 넷디스크부터 설치하라고 합니다. 무시해도 됩니다. 여기서는 팝업이 뜨는 이유, 클라이언트를 쓰면 무엇을 요구받는지, 그리고 브라우저만으로 같은 파일을 받는 방법을 설명합니다.

## 팝업이 뜨는 이유

바이두 웹사이트는 작은 단일 파일만, 그것도 로그인한 사용자에게만 내려받게 해 줍니다. 큰 파일이나 폴더, 또는 여러 파일을 한꺼번에 받으려 하면 데스크톱 클라이언트로 넘깁니다. 대부분의 공유는 결국 클라이언트가 없으면 다운로드할 수 없다는 뜻입니다.

## 브라우저로 받는 게 나은 경우

- **회사나 학교 PC:** 프로그램을 설치할 권한이 없습니다.
- **Linux:** 파일 하나 때문에 소스가 공개되지 않은 패키지를 설치하고 싶지 않습니다.
- **내 Mac이나 PC:** 백그라운드에서 도는 프로그램을 더 늘리고 싶지 않습니다.

## 단계

1. 공유 링크를 [PanPull 링크 확인](https://panpull.com/ko?utm_source=github&utm_medium=tutorial#link-checker) 화면에 붙여 넣습니다. 추출 코드가 있으면 함께 입력합니다.
2. 결과를 확인합니다. 파일 수, 총용량, 요금이 나옵니다.
3. 이메일 주소와 비밀번호로 PanPull에 로그인하고, 무료 주문이 아니면 PayPal이나 카드로 결제합니다.
4. 다운로드가 준비되었다는 이메일이 오면 그 안의 링크를 엽니다. 주문 페이지에도 같은 링크가 있습니다.

파일이 하나인 공유는 그 파일 그대로 받습니다. 파일이 여러 개인 공유는 폴더 구조가 담긴 ZIP 압축 파일 하나로 받습니다.

## ZIP 압축 풀기

| 시스템 | 방법 |
| --- | --- |
| Windows | 압축 파일을 마우스 오른쪽 버튼으로 클릭한 뒤 **모두 압축 풀기** |
| macOS | 압축 파일을 더블클릭 |
| Linux | 파일 관리자를 쓰거나, 터미널에서 `unzip` 뒤에 파일 이름을 입력 |

디스크 여유 공간은 압축 파일 크기의 약 두 배를 확보하세요. ZIP 파일용으로 한 번, 압축을 푼 내용물용으로 한 번입니다.
