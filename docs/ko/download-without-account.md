# 바이두 계정 없이 바이두 넷디스크에서 다운로드하는 방법

친구나 포럼 글, 프로젝트 페이지에서 `pan.baidu.com` 링크를 받았습니다. 페이지는 열리는데 다운로드 버튼을 누르면 바이두 로그인을 요구하고, 바이두는 문자를 받을 수 있는 전화번호에만 계정을 내줍니다. 해결 방법은 [PanPull](https://panpull.com/ko?utm_source=github&utm_medium=tutorial)이 공유를 가져오게 하고, 그 결과를 브라우저에서 다운로드하는 것입니다. 바이두 계정도, 바이두 앱도, 중국어도 필요 없습니다.

## 준비할 것

| 항목 | 설명 |
| --- | --- |
| 공유 링크 | `https://pan.baidu.com/s/`로 시작합니다 |
| 추출 코드 | 영문자나 숫자 4자리. 코드가 없는 공유도 있습니다 |
| 이메일 주소 | PanPull 로그인과 "준비 완료" 알림에 사용합니다 |

## 일곱 단계

1. [panpull.com](https://panpull.com/ko?utm_source=github&utm_medium=tutorial#link-checker)에서 **링크 확인 화면으로 갑니다**.
2. **링크를 붙여 넣습니다**. 코드는 옆 입력란에 넣습니다. 지름길: 링크와 코드가 들어 있던 메시지를 통째로 붙여 넣으면 둘 다 자동으로 찾아 줍니다.
3. **견적을 확인합니다**. 공유에 든 파일 수, 총용량, 요금이 나옵니다. 이 확인은 무료이고, 150 MB 이하 공유라면 끝까지 돈이 들지 않습니다.
4. **PanPull에 로그인합니다**. 처음이라면 이메일 주소와 비밀번호로 가입합니다. 이 로그인에는 바이두가 관여하지 않습니다.
5. **무료 주문이 아니면 결제합니다**. PayPal을 쓸 수 있고, PayPal을 통해 체크카드와 신용카드로도 결제할 수 있습니다.
6. **처리를 기다립니다**. 탭은 닫아도 됩니다. 파일이 준비되면 PanPull이 본인 전용 다운로드 페이지 링크를 이메일로 보내 드립니다. 이 링크는 주문 페이지에도 표시됩니다.
7. **다운로드합니다**. 파일이 하나면 그 파일 그대로, 여러 개면 폴더 구조를 유지한 ZIP 하나로 받습니다.

## 알아 두면 편한 점

- 주문에는 항상 공유 전체, 즉 모든 파일이 포함됩니다.
- 유료 다운로드는 준비된 뒤 24시간 안에 받아야 합니다. 무료 다운로드는 1시간입니다. 그 시간 안에는 끊긴 전송을 다시 시작할 수 있습니다.
- 바이두 비밀번호나 브라우저 쿠키는 전혀 필요 없습니다. 이를 요구하는 사이트나 프로그램은 믿지 마세요.
- 본인 파일이나 소유자가 공유에 동의한 파일만 받으세요.
