# 바이두 앱 없이 iPhone·Android에서 바이두 넷디스크 공유 파일 받는 법

휴대폰에서 바이두 넷디스크 링크를 열면 페이지가 바이두 넷디스크 앱으로 넘기려고 하고, 앱에서는 로그인을 해야 합니다. Safari나 Chrome 등 평소 쓰는 모바일 브라우저 안에서 끝내는 방법이 있습니다.

## 시작하기 전에

| 확인할 것 | 이유 |
| --- | --- |
| 여유 저장 공간 | 파일이 여러 개인 공유는 ZIP 하나로 받습니다. ZIP 파일과, 압축을 푼 뒤의 내용물을 모두 저장할 공간이 필요합니다 |
| Wi-Fi | 큰 파일은 모바일 데이터를 금방 소모합니다 |
| 화면과 브라우저 | 브라우저가 백그라운드로 넘어가면 다운로드를 멈추는 휴대폰도 있습니다. 큰 파일을 받을 때는 브라우저를 화면에 띄워 두세요 |

## 단계

1. 모바일 브라우저에서 [panpull.com](https://panpull.com/ko?utm_source=github&utm_medium=tutorial#link-checker)을 엽니다.
2. 입력란을 길게 눌러 바이두 링크를 붙여 넣습니다. 링크와 추출 코드가 함께 들어 있는 채팅 메시지를 통째로 복사했다면 그대로 붙여 넣으세요. 둘 다 인식됩니다.
3. 결과를 확인합니다. 파일 수, 총용량, 요금이 표시됩니다. 150 MB까지는 요금이 청구되지 않습니다.
4. 이메일과 비밀번호로 로그인합니다. 유료 주문은 PayPal이나 카드로 결제합니다.
5. 이제 휴대폰을 내려놓아도 됩니다. 파일이 준비되면 이메일이 옵니다.
6. 이메일의 링크를 누른 뒤, 열린 페이지에서 **다운로드**를 누릅니다.

## 받은 파일 찾기

| 휴대폰 | 찾는 곳 |
| --- | --- |
| iPhone, iPad(Safari) | 주소창 옆의 화살표 아이콘, 또는 **파일** 앱의 **다운로드** 폴더 |
| Android(Chrome) | 브라우저 메뉴에서 **다운로드**, 또는 파일 관리자의 **다운로드** 폴더 |

ZIP 파일은 파일 앱(iPhone)이나 파일 관리자(Android)에서 누르면 열립니다.

## 문제가 생겼을 때

- **다운로드를 눌러도 아무 반응이 없는 것 같다.** 다시 누르기 전에 브라우저의 다운로드 목록부터 열어 보세요. 한 번 더 누르면 같은 파일을 하나 더 받기 시작할 수 있습니다.
- **다운로드가 중간에 끊긴다.** 저장 공간과 신호 상태를 확인한 뒤 이메일의 링크를 다시 누르세요. 링크는 유료 주문이면 24시간, 무료 주문이면 1시간 동안 유효합니다.
- **파일이 휴대폰에 담기에는 너무 크다.** 같은 이메일을 컴퓨터에서 여세요. 링크는 특정 기기에 묶여 있지 않습니다.
