# 바이두 넷디스크 추출 코드란? 공유를 여는 데 필요한 4자리

바이두 넷디스크 링크만으로는 필요한 것의 절반밖에 갖추지 못한 경우가 많습니다. 나머지 절반은 추출 코드입니다. 공유한 사람이 링크와 함께 받는 영문자나 숫자 4자리입니다. 잠긴 공유는 올바른 코드를 입력하기 전까지 파일 목록을 보여 주지 않습니다.

## 코드를 찾는 곳

- **링크 바로 옆.** 링크가 있던 메시지나 게시글에서 "code", "password", "pwd"라고 표시된 4자리, 또는 짧은 중국어 표시 뒤에 오는 4자리를 찾아보세요.
- **링크 안.** 링크가 `?pwd=`와 4자리로 끝나는 경우가 있습니다. 예를 들면 `?pwd=ab12`입니다. 이것이 코드입니다.
- **소유자에게 묻기.** 코드가 어디에도 없다면 알려 줄 수 있는 사람은 공유한 사람뿐입니다. 다른 누구도 찾아낼 수 없습니다.

## 입력하는 방법

**바이두 페이지에서:** 보호된 공유를 열면 입력란 하나와 그 아래 파란 버튼이 나옵니다. 코드를 입력하고 버튼을 클릭하세요. 대문자와 소문자는 구분하지 않습니다.

**PanPull에서:** 링크를 [링크 확인](https://panpull.com/ko?utm_source=github&utm_medium=tutorial#link-checker)에 넣습니다.

- 링크가 `?pwd=`로 끝나면 코드는 링크에서 읽어 옵니다.
- 메시지 전체를 붙여 넣으면 그 안에서 링크와 코드를 모두 찾아냅니다.
- 그 밖의 경우에는 코드 입력란에 직접 입력하세요. 여기에 입력한 코드는 링크에 다른 코드가 들어 있어도 우선 적용됩니다.

## 코드가 거부되는 이유

| 원인 | 해결 방법 |
| --- | --- |
| 코드 앞이나 뒤의 공백까지 복사됨 | 4자리를 직접 입력하기 |
| 0과 O, 또는 1, l, I처럼 비슷하게 생긴 문자 | 원래 메시지와 한 글자씩 비교하기 |
| 다른 링크의 코드임 | 소유자가 링크를 여러 개 보냈다면 코드마다 맞는 링크와 짝짓기 |
| 소유자가 공유를 새로 만듦 | 가장 최근 메시지를 사용하기. 예전 링크와 코드는 더 이상 작동하지 않음 |
| 공유 자체가 사라짐 | 코드 문제가 아닙니다. [공유 링크가 안 열릴 때](share-link-not-working.md) 참고 |

코드를 아무렇게나 넣어 보지 마세요. 소유자에게 링크와 코드를 다시 보내 달라고 하세요.

## 코드로 할 수 없는 것

코드는 공유 페이지를 열어 줄 뿐입니다. 다운로드하려면 여전히 바이두 로그인이나, 공유를 대신 다운로드해 주는 서비스가 필요합니다. PanPull도 코드 없이는 보호된 공유를 열 수 없고, 소유자가 삭제한 공유를 되살릴 수도 없습니다.
