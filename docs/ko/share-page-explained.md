# 바이두 넷디스크 한국어 안내: 공유 페이지의 모든 입력란과 버튼 정리표

`pan.baidu.com` 공유 페이지는 중국어로만 되어 있습니다. 이 정리표를 보면 위치를 기준으로 길을 찾을 수 있습니다. 각 요소가 어디에 있고, 무슨 기능이며, 필요한지를 정리했습니다. 2026년 10월 31일에 확인한 페이지를 기준으로 합니다.

팁: 브라우저 번역 기능은 긴 문장은 잘 옮기지만, 한 단어짜리 버튼은 엉뚱하게 번역하는 경우가 많습니다. 위치로 판단하는 편이 더 확실합니다.

## 화면 1: 잠금 화면

이 화면은 공유에 추출 코드가 걸려 있을 때만 나옵니다.

| 위치 | 기능 | 필요한가요? |
| --- | --- | --- |
| 가운데, 입력란 하나 | 4자리 코드 입력란 | 예 |
| 입력란 아래 파란 버튼 | 공유 열기 | 예 |
| 일그러진 그림 옆의 추가 입력란 | 캡차: 보이는 문자를 그대로 입력 | 나타날 때만 |
| 공유한 사람 이름 옆의 작은 링크 | 공유한 사람에게 친구 요청 | 아니요 |

코드는 대문자와 소문자를 구분하지 않습니다. 코드를 잃어버렸다면 [추출 코드](extraction-code.md)를 읽어 보세요.

## 화면 2: 파일 목록

| 위치 | 기능 | 필요한가요? |
| --- | --- | --- |
| 머리글 줄 | 공유 제목, 공유 날짜, 만료일 또는 "기간 제한 없음" | 링크가 언제까지 유효한지 볼 때 유용 |
| 머리글 오른쪽 | 구독, 다른 기기에서 열기, 신고 | 아니요 |
| 본문 영역 | 파일과 폴더. 각각 날짜와 체크 상자가 있음 | 안에 무엇이 있는지 볼 때 |
| 목록 위의 줄 | 상위 폴더로 돌아가는 경로 | 폴더 안에 들어갔을 때 |
| 아래쪽 파란 버튼 | 체크한 항목을 내 바이두 저장 공간에 복사 | 바이두 로그인 필요 |
| 아래쪽, 그 옆의 연한 버튼 | 체크한 항목 다운로드 | 바이두 로그인 필요, 대개 데스크톱 앱도 필요 |
| 오른쪽 위 모서리 | 로그인, 가입, 데스크톱 앱 받기, 멤버십 광고 | 바이두 계정이 있을 때만 |

## 계정 없이 어디까지 되나요

| 작업 | 바이두 계정이 없을 때 |
| --- | --- |
| 링크 열기 | 됨 |
| 코드 입력 | 됨 |
| 파일과 폴더 둘러보기 | 됨 |
| 내 저장 공간에 저장 | 막힘: 로그인 필요 |
| 다운로드 | 막힘: 로그인, 그다음 대개 데스크톱 앱, 그다음 느린 무료 계정 속도 |

즉 이 페이지에서는 볼 수는 있어도 가져갈 수는 없습니다. 해외에서 가입하려면 [중국 전화번호가 없다면?](sign-up-phone-number.md)을 참고하세요.
