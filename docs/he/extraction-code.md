# קוד גישה ב־Baidu Pan: ארבעת התווים שצריך כדי לפתוח שיתוף

הרבה פעמים קישור של Baidu Pan הוא רק חצי ממה שצריך. החצי השני הוא קוד הגישה: ארבע אותיות או ספרות שמי ששיתף מקבל יחד עם הקישור. שיתוף נעול לא מציג את רשימת הקבצים עד שמזינים את הקוד הנכון.

## איפה מוצאים את הקוד

- **ליד הקישור.** בהודעה או בפוסט שבהם מצאתם את הקישור, חפשו ארבעה תווים אחרי המילה "code", "password" או "pwd", או אחרי מילה סינית קצרה.
- **בתוך הקישור.** יש קישורים שמסתיימים ב־`?pwd=` ועוד ארבעה תווים, למשל `?pwd=ab12`. זה הקוד.
- **אצל הבעלים.** אין קוד באופק? רק מי ששיתף יכול להגיד לכם אותו. אף אחד אחר לא יכול לברר אותו.

## איך מזינים אותו

**בעמוד של Baidu:** שיתוף מוגן נפתח עם תיבת קלט אחת וכפתור כחול מתחתיה. הקלידו את הקוד ולחצו על הכפתור. אין הבדל בין אותיות גדולות לקטנות.

**ב־PanPull:** הכניסו את הקישור ל[בדיקת הקישור](https://panpull.com/he?utm_source=github&utm_medium=tutorial#link-checker).

- אם הקישור מסתיים ב־`?pwd=`, הקוד נקרא מתוך הקישור.
- אם תדביקו את כל ההודעה, הקישור והקוד יילקחו ממנה שניהם.
- אחרת, הקלידו את הקוד בשדה הקוד. קוד שמוקלד שם קודם לכל השאר, גם אם בקישור יש קוד אחר.

## למה הקוד נדחה

| סיבה | מה עושים |
| --- | --- |
| הועתק רווח לפני הקוד או אחריו | הקלידו את ארבעת התווים ביד |
| תווים שנראים דומים, כמו 0 ו־O, או 1, l ו־I | השוו להודעה המקורית תו אחר תו |
| הקוד שייך לקישור אחר | הבעלים שלחו כמה קישורים: התאימו כל קוד לקישור שלו |
| הבעלים יצרו שיתוף חדש | השתמשו בהודעה האחרונה; הקישור והקוד הישנים כבר לא עובדים |
| השיתוף עצמו כבר לא קיים | הבעיה היא לא בקוד. ראו [קישור השיתוף לא עובד](share-link-not-working.md) |

אל תנחשו קודים באקראי. בקשו מהבעלים לשלוח שוב את הקישור ואת הקוד.

## מה קוד לא יכול לעשות

קוד רק פותח את עמוד השיתוף. כדי להוריד עדיין צריך כניסה ל־Baidu, או שירות שמוריד את השיתוף בשבילכם. גם PanPull לא יכול לפתוח שיתוף מוגן בלי הקוד שלו, וגם לא להחזיר שיתוף שהבעלים מחקו.
