# הורדה מ־Baidu Pan בלי התוכנה למחשב: הורדה בדפדפן ב־Windows, ב־Mac וב־Linux

לוחצים על כפתור ההורדה בשיתוף של Baidu Pan, וקופץ חלון בסינית שאומר להתקין קודם את Baidu Netdisk. אפשר להתעלם ממנו. כאן תמצאו למה החלון מופיע, מה התוכנה הייתה דורשת מכם, ואיך מקבלים את אותם קבצים עם הדפדפן בלבד.

## למה החלון מופיע

האתר של Baidu מוסר רק קבצים בודדים וקטנים, ורק למשתמשים מחוברים. קובץ גדול, תיקייה או יותר מקובץ אחד בבת אחת מועברים לתוכנה למחשב. ברוב השיתופים המשמעות היא: בלי תוכנה, אין הורדה.

## תוכנה או דפדפן?

| | התוכנה של Baidu Netdisk | הורדה בדפדפן עם PanPull |
| --- | --- | --- |
| התקנה | כן. ב־Windows היא גם עולה עם המערכת ונשארת ברקע | אין |
| חשבון Baidu | חובה | לא צריך |
| שפה | סינית בלבד | 29 שפות |
| מהירות | מוגבלת בחשבון חינמי | הורדה רגילה מהאחסון של PanPull |
| עלות | חינם, או מינוי SVIP בתשלום של Baidu | חינם עד 150 MB, ואחר כך לפי נפח |
| מערכות | מערכות Windows, macOS, Android ו־iOS; וגם Linux כ־`.deb` או `.rpm` | כל מכשיר עם דפדפן |

אם בכל זאת אתם רוצים את התוכנה, הורידו אותה מ־Baidu עצמה בכתובת `pan.baidu.com/download`, ולא מאתר הורדות.

## מקרים טיפוסיים להורדה בדפדפן

- **מחשב במשרד או באוניברסיטה:** אין לכם הרשאה להתקין תוכנות.
- **מערכת Linux:** לא מתחשק לכם להתקין חבילה בקוד סגור בשביל קובץ אחד.
- **ה־Mac או ה־PC הפרטי שלכם:** אתם לא רוצים עוד תוכנה שרצה ברקע.

## השלבים

1. העתיקו את קישור השיתוף ל[בדיקת הקישור של PanPull](https://panpull.com/he?utm_source=github&utm_medium=tutorial#link-checker). אם יש קוד גישה, הוסיפו אותו.
2. בדקו את התוצאה: כמה קבצים, מה הנפח הכולל ומה המחיר.
3. היכנסו ל־PanPull עם כתובת אימייל וסיסמה, ושלמו ב־PayPal או בכרטיס, אלא אם ההזמנה בחינם.
4. חכו לאימייל שאומר שההורדה מוכנה, ופתחו את הקישור שבו. אותו קישור נמצא גם בעמוד ההזמנה.

משיתוף עם קובץ אחד מקבלים את הקובץ הזה. משיתוף עם כמה קבצים מקבלים ארכיון ZIP אחד, ובתוכו מבנה התיקיות.

## חילוץ קובץ ה־ZIP

| מערכת | איך |
| --- | --- |
| מערכת Windows | לחצו לחיצה ימנית על הארכיון, ואז **חלץ הכל** |
| מערכת macOS | לחצו פעמיים על הארכיון |
| מערכת Linux | השתמשו במנהל הקבצים, או הקלידו בטרמינל `unzip` ואת שם הקובץ |

השאירו בדיסק מקום פנוי של בערך פי שניים מגודל הארכיון: פעם אחת לקובץ ה־ZIP, ופעם לתוכן שלו.
