# Cara unduh dari Baidu Pan tanpa akun Baidu

Teman, postingan forum, atau halaman proyek memberi Anda tautan `pan.baidu.com`. Halamannya terbuka, tetapi tombol unduh meminta login Baidu, dan Baidu hanya memberi akun untuk nomor HP yang bisa menerima SMS darinya. Jalan keluarnya: biarkan [PanPull](https://panpull.com/id?utm_source=github&utm_medium=tutorial) mengambil file berbagi itu, lalu unduh hasilnya di browser Anda. Tanpa akun Baidu, tanpa aplikasi Baidu, dan tanpa bahasa Mandarin.

## Siapkan ini

| Yang dibutuhkan | Keterangan |
| --- | --- |
| Tautan berbagi | Diawali `https://pan.baidu.com/s/` |
| Kode akses | 4 huruf atau angka. Tidak semua file berbagi memakainya |
| Alamat email | Untuk login PanPull dan pemberitahuan "sudah siap" |

## Tujuh langkahnya

1. **Buka pemeriksa tautan** di [panpull.com](https://panpull.com/id?utm_source=github&utm_medium=tutorial#link-checker).
2. **Tempel tautannya.** Kodenya dimasukkan ke kolom di sebelahnya. Jalan pintas: tempel seluruh pesan yang berisi tautan dan kode, keduanya akan ditemukan otomatis.
3. **Baca penawaran harganya.** Di situ tercantum berapa file dalam file berbagi itu, total ukurannya, dan harganya. Pengecekan ini tidak dipungut biaya, dan Anda tidak membayar apa pun jika file berbaginya 150 MB atau lebih kecil.
4. **Masuk ke PanPull.** Pengguna baru mendaftar dengan alamat email dan kata sandi. Login ini tidak ada hubungannya dengan Baidu.
5. **Bayar, kecuali pesanannya gratis.** Bisa pakai PayPal, juga kartu debit dan kartu kredit lewat PayPal.
6. **Tunggu prosesnya.** Tab boleh ditutup. Setelah file disiapkan, PanPull mengirim email berisi tautan ke halaman unduhan pribadi. Tautan yang sama juga ada di halaman pesanan Anda.
7. **Unduh.** Satu file dikirim apa adanya. Beberapa file dikemas dalam satu ZIP, lengkap dengan struktur foldernya.

## Detail yang menghindarkan masalah

- Satu pesanan selalu mengambil seluruh file berbagi, dengan semua filenya.
- Setelah unduhan berbayar siap, Anda punya waktu 24 jam untuk mengambilnya. Untuk unduhan gratis, waktunya 1 jam. Unduhan yang terputus bisa diulang dalam rentang waktu itu.
- Kata sandi Baidu dan cookie browser Anda tidak pernah dibutuhkan. Situs atau program yang memintanya tidak layak dipercaya.
- Batasi diri pada file milik Anda atau file yang pemiliknya memang mau membagikannya kepada Anda.
