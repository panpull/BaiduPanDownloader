# Baidu Netdisk dalam bahasa Indonesia: contekan setiap kotak dan tombol di halaman berbagi

Halaman berbagi `pan.baidu.com` hanya tersedia dalam bahasa Mandarin. Pakai contekan ini untuk menemukan jalan berdasarkan letaknya: di mana setiap elemen berada, apa fungsinya, dan apakah Anda membutuhkannya. Isinya menggambarkan halaman itu seperti yang kami lihat pada 31 Oktober 2026.

Tips: fitur terjemahan di browser menerjemahkan teks panjang dengan benar, tetapi sering mengacaukan tombol yang hanya berisi satu kata. Letak elemen lebih bisa diandalkan.

## Layar 1: kunci

Layar ini hanya muncul jika file berbagi memakai kode akses.

| Letak | Fungsinya | Perlu? |
| --- | --- | --- |
| Tengah, satu kotak teks | Kolom untuk kode 4 karakter | Ya |
| Tombol biru di bawah kotak | Membuka file berbagi | Ya |
| Kotak tambahan di samping gambar yang buram | Captcha: salin karakter yang Anda lihat | Hanya jika muncul |
| Tautan kecil di samping nama pembagi | Permintaan pertemanan ke pembagi | Tidak |

Huruf besar dan kecil tidak berpengaruh pada kode. Kodenya hilang? Baca [Kode akses](extraction-code.md).

## Layar 2: file

| Letak | Fungsinya | Perlu? |
| --- | --- | --- |
| Baris judul | Judul file berbagi, tanggal dibagikan, tanggal kedaluwarsa atau "tidak pernah kedaluwarsa" | Berguna untuk tahu berapa lama tautan berlaku |
| Sebelah kanan baris judul | Berlangganan, buka di perangkat lain, laporkan | Tidak |
| Area utama | File dan folder, masing-masing dengan tanggal dan kotak centang | Untuk melihat isinya |
| Baris di atas daftar | Jalur kembali ke folder induk | Saat Anda berada di dalam folder |
| Bawah, tombol biru | Menyalin item yang dicentang ke penyimpanan Baidu Anda sendiri | Butuh login Baidu |
| Bawah, tombol pucat di sebelahnya | Mengunduh item yang dicentang | Butuh login Baidu, dan sering juga aplikasi desktop |
| Pojok kanan atas | Login, daftar, ambil aplikasi desktop, tawaran keanggotaan | Hanya dengan akun Baidu |

## Sejauh mana Anda bisa tanpa akun

| Tindakan | Tanpa akun Baidu |
| --- | --- |
| Membuka tautan | Bisa |
| Memasukkan kode | Bisa |
| Melihat-lihat file dan folder | Bisa |
| Menyimpan ke penyimpanan sendiri | Terhalang: harus login |
| Mengunduh | Terhalang: harus login, lalu biasanya aplikasi desktop, lalu kecepatan akun gratis yang lambat |

Jadi halaman ini mengizinkan Anda melihat, tetapi tidak mengambil. Untuk mendaftar dari luar negeri, lihat [Tidak punya nomor HP China?](sign-up-phone-number.md)
