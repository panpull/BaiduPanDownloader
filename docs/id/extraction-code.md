# Kode akses Baidu Pan: 4 karakter yang dibutuhkan untuk membuka file berbagi

Tautan Baidu Pan sering kali baru separuh dari yang Anda perlukan. Separuh lainnya adalah kode akses (kode ekstraksi): empat huruf atau angka yang didapat pembagi bersama tautannya. File berbagi yang terkunci tidak menampilkan daftar file sampai kode yang benar dimasukkan.

## Di mana kodenya

- **Di dekat tautan.** Di pesan atau postingan tempat Anda menemukan tautan, cari empat karakter dengan keterangan "code", "password", atau "pwd", atau label pendek berbahasa Mandarin yang diikuti empat karakter.
- **Di dalam tautan.** Sebagian tautan diakhiri `?pwd=` dan empat karakter, misalnya `?pwd=ab12`. Itulah kodenya.
- **Dari pemiliknya.** Tidak ada kode yang terlihat? Hanya pembagi yang bisa memberi tahu Anda. Tidak ada orang lain yang bisa mencarinya.

## Cara memasukkannya

**Di halaman Baidu:** file berbagi yang dilindungi terbuka dengan satu kotak input dan tombol biru di bawahnya. Ketik kodenya, lalu klik tombol itu. Huruf besar dan huruf kecil dianggap sama.

**Di PanPull:** masukkan tautannya ke [pemeriksa tautan](https://panpull.com/id?utm_source=github&utm_medium=tutorial#link-checker).

- Jika tautan diakhiri `?pwd=`, kodenya dibaca dari tautan.
- Jika Anda menempelkan seluruh pesan, tautan dan kodenya sama-sama diambil dari pesan itu.
- Selain itu, ketik kodenya di kolom kode. Kode yang diketik di sana yang dipakai lebih dulu, meskipun tautannya berisi kode lain.

## Kenapa kode ditolak

| Penyebab | Yang perlu dilakukan |
| --- | --- |
| Ada spasi yang ikut tersalin sebelum atau sesudah kode | Ketik keempat karakternya secara manual |
| Karakter yang mirip, seperti 0 dan O, atau 1, l, dan I | Bandingkan dengan pesan aslinya, satu per satu karakter |
| Kodenya milik tautan lain | Pemiliknya mengirim beberapa tautan: cocokkan setiap kode dengan tautannya sendiri |
| Pemiliknya membuat file berbagi baru | Pakai pesan yang paling baru; tautan dan kode yang lama sudah tidak berlaku |
| File berbaginya sendiri sudah tidak ada | Masalahnya bukan di kode. Lihat [Tautan berbagi tidak berfungsi](share-link-not-working.md) |

Jangan mencoba kode secara acak. Minta pemiliknya mengirim ulang tautan dan kodenya.

## Yang tidak bisa dilakukan kode

Kode hanya membuka halaman berbagi. Untuk mengunduh, Anda tetap butuh login Baidu, atau layanan yang mengunduh file berbagi itu untuk Anda. PanPull tidak bisa membuka file berbagi yang dilindungi tanpa kodenya, dan tidak bisa memulihkan file berbagi yang sudah dihapus pemiliknya.
