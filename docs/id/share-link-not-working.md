# Tautan berbagi Baidu Pan tidak berfungsi: arti setiap pesannya

Anda membuka tautan `pan.baidu.com`, tetapi yang muncul justru pesan pendek berbahasa Mandarin, bukan daftar file. Halaman ini menjelaskan arti pesan itu dan apa yang bisa Anda lakukan.

## Pertama, periksa alamatnya

Tautan yang benar berbentuk `https://pan.baidu.com/s/1…` dengan deretan panjang huruf dan angka setelah `1`. Setelah dibuka, browser mungkin menampilkan `https://pan.baidu.com/share/init?surl=…`. Itu file berbagi yang sama.

Jika tautannya terpotong saat disalin, tautan itu tidak akan terbuka. Salin lagi dari pesan aslinya, sampai ke ujungnya.

## Arti tampilan di halaman

| Yang Anda lihat | Artinya | Siapa yang bisa memperbaikinya |
| --- | --- | --- |
| Kotak yang meminta empat karakter | File berbagi ini dilindungi. Anda butuh [kode akses](extraction-code.md) | Anda, dengan kode dari pemiliknya |
| Pesan bahwa Anda terlambat dan file berbagi sudah dibatalkan | Pemiliknya berhenti membagikan, atau Baidu menghapus filenya | Pemiliknya |
| Pesan tentang pelanggaran hak cipta atau konten terlarang | Baidu memblokir file berbagi ini | Tidak ada: file berbagi tetap diblokir |
| Daftar file dengan catatan bahwa sebagian file disaring | Sebagian isi file berbagi melanggar aturan Baidu dan disembunyikan | Pemiliknya |
| Pesan bahwa file berbagi sudah tidak berlaku | Masa berlaku file berbagi sudah habis | Pemiliknya |

Fitur terjemahan di browser membantu Anda membedakan pesan-pesan ini.

## Yang perlu dilakukan

- **Kode ditolak:** bandingkan dengan pesan aslinya, satu per satu karakter. Lihat [Kode akses](extraction-code.md).
- **File berbagi dibatalkan atau kedaluwarsa:** minta pemiliknya membagikan file itu lagi dan mengirimkan tautan serta kode yang baru.
- **File berbagi diblokir:** tidak ada yang bisa diunduh. Tanyakan kepada pemiliknya apakah file itu tersedia di tempat lain.

## Periksa sebelum membayar apa pun
