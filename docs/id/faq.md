# FAQ unduh Baidu Pan: akun, keamanan, kecepatan, dan harga

Jawaban singkat untuk pertanyaan yang paling sering muncul saat seseorang di luar China menerima tautan `pan.baidu.com`.

## Apa itu Baidu Pan?

Layanan penyimpanan online milik Baidu. Di China, layanan ini dipakai seperti Google Drive atau Dropbox di negara lain. Dalam bahasa Inggris, nama resminya Baidu Netdisk. Anda mungkin juga menemukan nama lamanya, Baidu Cloud dan Baidu Yun; semuanya merujuk ke layanan yang sama. Selengkapnya: [Apa itu Baidu Pan? Penjelasan pan.baidu.com dan Baidu Netdisk](https://panpull.com/id/blog/what-is-baidu-pan?utm_source=github&utm_medium=tutorial)

## Bisakah saya mengunduh tanpa akun Baidu?

Tidak di halaman Baidu sendiri, karena di sana unduhan dimulai dengan login. Dengan [PanPull](https://panpull.com/id?utm_source=github&utm_medium=tutorial#link-checker) bisa, karena PanPull yang mengunduh file berbagi itu untuk Anda. Lihat [Cara unduh tanpa akun Baidu](download-without-account.md).

## Bisakah saya mendaftar tanpa nomor HP China?

Kadang bisa. Tergantung kode negara Anda, dan tidak ada satu pun negara Uni Eropa di daftar Baidu. Lihat [Tidak punya nomor HP China?](sign-up-phone-number.md)

## Apakah aman membuka tautan pan.baidu.com?

Ya. Itu situs resmi Baidu. Risikonya ada pada filenya, karena siapa saja bisa membagikan apa saja. Pindai file yang Anda unduh, dan paling berhati-hatilah dengan program dan file instalasi. Selengkapnya: [Apakah Baidu Pan (pan.baidu.com) aman? Ini yang perlu dicek dulu](https://panpull.com/id/blog/is-baidu-pan-safe?utm_source=github&utm_medium=tutorial)

## Apakah saya harus memberikan kata sandi Baidu kepada PanPull?

Tidak. PanPull bekerja dengan tautan berbagi dan kode aksesnya. PanPull tidak pernah meminta kata sandi atau cookie Baidu Anda. Jangan berikan keduanya kepada situs web atau program apa pun.

## Apa itu kode akses?

Empat huruf atau angka yang membuka kunci file berbagi. Pembagi mengirimkannya bersama tautan. Lihat [Kode akses](extraction-code.md).

## Kenapa unduhan Baidu saya lambat sekali?

Akun gratis dibatasi sekitar 100 sampai 170 KB/s. Lihat [Berapa lama unduhan berjalan](slow-download-speed.md).

## Berapa biaya PanPull?

File berbagi hingga 150 MB gratis. Di atas itu, GB pertama US$0,98 dan setiap GB tambahan US$0,48, dengan batas harga maksimum untuk file berbagi yang besar. Lihat [Harga dan unduhan gratis](pricing-and-free-downloads.md).

## Bisakah saya memilih file tertentu saja dari sebuah file berbagi?

Untuk saat ini belum: satu pesanan mengambil seluruh file berbagi. Sebelum membayar, Anda bisa melihat berapa file yang ada dan berapa total ukurannya. Lebih dari satu file dikirim sebagai satu ZIP dengan struktur folder yang tetap utuh.

## Berapa lama saya bisa mengunduh file saya?

Selama 24 jam setelah unduhan berbayar siap, dan 1 jam untuk unduhan gratis. Setelah itu, file yang sudah disiapkan dihapus.

## Bagaimana jika unduhan gagal?

Halaman pesanan akan memberi tahu Anda dan menampilkan tombol "Coba lagi". Masih belum berhasil? Kirim laporan masalah dan sebutkan nomor pesanan Anda. Uang yang dibayar untuk pesanan yang tidak bisa dikirim akan dikembalikan kepada Anda.

## Apakah PanPull bisa dipakai untuk TeraBox atau penyimpanan cloud lain?

Tidak. PanPull hanya bisa dipakai untuk tautan berbagi `pan.baidu.com`. TeraBox adalah layanan terpisah dengan tautannya sendiri.

## Bisakah saya memakainya di HP, Mac, atau Linux?

Bisa. Semuanya berjalan di browser. Lihat [Unduh di iPhone atau Android](download-on-phone.md) dan [Unduh tanpa memasang aplikasi](download-without-client.md).

## File apa saja yang boleh saya unduh?

File milik Anda sendiri, dan file yang pemiliknya mengizinkan Anda memilikinya.
