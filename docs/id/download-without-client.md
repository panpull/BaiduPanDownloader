# Baidu Pan tanpa aplikasi desktop: cara unduh lewat browser di Windows, Mac, dan Linux

Anda menekan tombol unduh di file berbagi Baidu Pan, lalu muncul pop-up berbahasa Mandarin yang menyuruh Anda memasang Baidu Netdisk dulu. Pop-up itu bisa diabaikan. Berikut alasan pop-up itu muncul, apa yang diminta aplikasinya dari Anda, dan cara mendapatkan file yang sama hanya dengan browser.

## Kenapa pop-up itu muncul

Situs Baidu hanya memberikan file tunggal yang kecil, itu pun hanya kepada pengguna yang sudah login. File besar, folder, atau lebih dari satu file sekaligus dialihkan ke aplikasi desktop. Untuk sebagian besar file berbagi, artinya: tanpa aplikasi, tidak bisa unduh.

## Aplikasi atau browser?

| | Aplikasi Baidu Netdisk | Unduh lewat browser dengan PanPull |
| --- | --- | --- |
| Instalasi | Ya. Di Windows, aplikasinya juga ikut berjalan saat sistem menyala dan tetap aktif di latar belakang | Tidak perlu |
| Akun Baidu | Wajib | Tidak perlu |
| Bahasa | Hanya bahasa Mandarin | 29 bahasa |
| Kecepatan | Dibatasi untuk akun gratis | Unduhan biasa dari penyimpanan PanPull |
| Biaya | Gratis, atau keanggotaan SVIP berbayar dari Baidu | Gratis hingga 150 MB, selebihnya sesuai ukuran |
| Sistem | Windows, macOS, Android, iOS; Linux dalam bentuk `.deb` atau `.rpm` | Apa saja yang punya browser |

Jika Anda tetap ingin memakai aplikasinya, ambil langsung dari Baidu di `pan.baidu.com/download`, bukan dari situs kumpulan unduhan.

## Situasi yang cocok untuk jalur browser

- **PC kantor atau kampus:** Anda tidak punya hak untuk memasang program.
- **Linux:** Anda enggan memasang paket sumber tertutup hanya demi satu file.
- **Mac atau PC pribadi:** Anda tidak mau ada satu program lagi yang berjalan di latar belakang.

## Langkah-langkah

1. Salin tautan berbagi ke [pemeriksa tautan PanPull](https://panpull.com/id?utm_source=github&utm_medium=tutorial#link-checker). Tambahkan kode akses jika ada.
2. Lihat hasilnya: berapa file, berapa total ukurannya, berapa harganya.
3. Masuk ke PanPull dengan alamat email dan kata sandi, lalu bayar lewat PayPal atau kartu, kecuali pesanannya gratis.
4. Tunggu email yang memberi tahu bahwa unduhan Anda sudah siap, lalu buka tautannya. Tautan yang sama ada di halaman pesanan Anda.

File berbagi berisi satu file memberi Anda file itu. File berbagi berisi beberapa file memberi Anda satu arsip ZIP dengan struktur folder di dalamnya.

## Mengekstrak ZIP

| Sistem | Caranya |
| --- | --- |
| Windows | Klik kanan arsipnya, lalu **Ekstrak Semua** |
| macOS | Klik dua kali arsipnya |
| Linux | Pakai pengelola file, atau ketik `unzip` dan nama filenya di terminal |

Sediakan ruang disk kosong sekitar dua kali ukuran arsip: sekali untuk ZIP-nya, sekali lagi untuk isinya.
