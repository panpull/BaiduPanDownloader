# Cara unduh dari Baidu Pan (pan.baidu.com): tutorial dalam bahasa Indonesia

Panduan singkat dan praktis untuk Anda yang tinggal di luar China, menerima tautan berbagi Baidu Pan (Baidu Netdisk), tetapi tidak bisa mengambil filenya: tidak punya akun Baidu, tidak punya nomor HP China, aplikasinya berbahasa Mandarin, atau unduhannya lambat sekali.

Panduan ini memakai [PanPull](https://panpull.com/id?utm_source=github&utm_medium=tutorial), situs web yang mengunduh file berbagi Baidu untuk Anda. Anda cukup menempelkan tautan, melihat ukuran dan harganya, lalu mengunduh di browser. File berbagi hingga 150 MB gratis.

## Mulai cepat

1. Buka [pemeriksa tautan PanPull](https://panpull.com/id?utm_source=github&utm_medium=tutorial#link-checker).
2. Tempel tautan `pan.baidu.com` beserta kode aksesnya.
3. Lihat jumlah file, total ukuran, dan harganya.
4. Masuk dengan alamat email, bayar jika pesanan tidak gratis, lalu unduh.
