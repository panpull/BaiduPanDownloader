# Cara unduh file berbagi Baidu Pan di iPhone atau Android tanpa aplikasi Baidu

Begitu Anda membuka tautan Baidu Pan di HP, halamannya berusaha memindahkan Anda ke aplikasi Baidu Netdisk, dan di sana Anda harus login. Ada cara yang tetap di Safari, Chrome, atau browser HP apa pun yang Anda pakai.

## Sebelum mulai

| Periksa | Alasannya |
| --- | --- |
| Ruang penyimpanan | File berbagi yang berisi beberapa file dikirim sebagai satu ZIP. Anda butuh ruang untuk ZIP-nya dan, setelah diekstrak, untuk isinya |
| Wi-Fi | File besar cepat menghabiskan kuota data seluler |
| Layar dan browser | Sebagian HP menjeda unduhan saat browser berjalan di latar belakang. Untuk file besar, biarkan browser tetap terbuka di depan |

## Langkah-langkah

1. Di browser HP, buka [panpull.com](https://panpull.com/id?utm_source=github&utm_medium=tutorial#link-checker).
2. Tekan lama kolom input, lalu tempel tautan Baidu. Jika Anda menyalin seluruh pesan chat yang berisi tautan dan kode akses, tempel saja semuanya: keduanya akan dikenali.
3. Baca hasilnya: jumlah file, total ukuran, harga. Hingga 150 MB tidak dikenai biaya.
4. Masuk dengan email dan kata sandi. Untuk pesanan berbayar, bayar lewat PayPal atau kartu.
5. Silakan taruh HP Anda. Email akan masuk saat file sudah siap.
6. Ketuk tautan di email, lalu ketuk **Unduh** di halaman yang terbuka.

## Mencari file setelahnya

| HP | Tempat mencarinya |
| --- | --- |
| iPhone, iPad dengan Safari | Ikon panah di samping bilah alamat, atau aplikasi **File**, folder **Unduhan** |
| Android dengan Chrome | Menu browser, lalu **Download**; atau folder **Download** di pengelola file |

ZIP bisa dibuka dengan sekali ketuk di aplikasi File (iPhone) atau di pengelola file (Android).

## Jika ada masalah

- **Tidak terjadi apa-apa setelah mengetuk Unduh.** Buka daftar unduhan browser sebelum mengetuk lagi. Ketukan kedua bisa memulai salinan kedua.
- **Unduhan terputus.** Periksa ruang penyimpanan dan sinyal, lalu ketuk tautan di email sekali lagi. Tautan berlaku 24 jam untuk pesanan berbayar dan 1 jam untuk pesanan gratis.
- **File terlalu besar untuk HP.** Buka email yang sama di komputer. Tautannya tidak terikat pada satu perangkat.
