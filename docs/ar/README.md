# كيفية التحميل من Baidu Pan (pan.baidu.com): شروحات بالعربية

أدلة قصيرة وعملية لمن يعيش خارج الصين ووصله رابط مشاركة من Baidu Pan (Baidu Netdisk) ولا يستطيع الوصول إلى الملفات: لا حساب لديه في Baidu، ولا رقم هاتف صيني، والبرنامج بالصينية فقط، أو التنزيل بطيء إلى حد الزحف.

تعتمد هذه الأدلة على [PanPull](https://panpull.com/ar?utm_source=github&utm_medium=tutorial)، وهو موقع يُنزّل مشاركة Baidu نيابةً عنك. تلصق الرابط، فترى الحجم والسعر، ثم تُنزّل الملفات في متصفحك. المشاركات التي لا يتجاوز حجمها 150 MB مجانية.

## البداية السريعة

1. افتح [أداة فحص الرابط في PanPull](https://panpull.com/ar?utm_source=github&utm_medium=tutorial#link-checker).
2. ألصق رابط `pan.baidu.com` ورمز الوصول الخاص به.
3. راجع عدد الملفات والحجم الإجمالي والسعر.
4. سجّل الدخول بعنوان بريد إلكتروني، وادفع إن لم يكن الطلب مجانيًا، ثم نزّل الملفات.
