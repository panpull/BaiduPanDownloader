# Jak stáhnout soubory z Baidu Pan (pan.baidu.com): návody v češtině

Krátké praktické návody pro lidi mimo Čínu, kteří dostali sdílený odkaz z Baidu Pan (Baidu Netdisk) a nemohou se k souborům dostat: nemají účet Baidu ani čínské telefonní číslo, klient je jen v čínštině, nebo se stahování sotva vleče.

Návody pracují s [PanPull](https://panpull.com/cs?utm_source=github&utm_medium=tutorial), webem, který sdílené soubory z Baidu stáhne za vás. Vložíte odkaz, uvidíte velikost a cenu a stáhnete soubory v prohlížeči. Sdílení do 150 MB je zdarma.

## Rychlý start

1. Otevřete [kontrolu odkazu na PanPull](https://panpull.com/cs?utm_source=github&utm_medium=tutorial#link-checker).
2. Vložte odkaz `pan.baidu.com` a jeho přístupový kód.
3. Podívejte se na počet souborů, celkovou velikost a cenu.
4. Přihlaste se e-mailovou adresou, zaplaťte, pokud objednávka není zdarma, a stáhněte soubory.
