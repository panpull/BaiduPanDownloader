# 百度網盤（pan.baidu.com）からダウンロードする方法：日本語チュートリアル

百度網盤（Baidu Netdisk）の共有リンクを受け取ったのにファイルを入手できない、中国国外の方向けの短く実用的なガイドです。百度アカウントがない、中国の電話番号がない、クライアントが中国語しかない、ダウンロードが遅すぎる、といった場合に役立ちます。

ガイドでは [PanPull](https://panpull.com/ja?utm_source=github&utm_medium=tutorial) を使います。百度網盤の共有を代わりにダウンロードしてくれるウェブサイトです。リンクを貼り付けてサイズと料金を確認し、ブラウザでダウンロードします。150 MB までの共有は無料です。

## すぐに始める

1. [PanPull のリンク確認フォーム](https://panpull.com/ja?utm_source=github&utm_medium=tutorial#link-checker)を開きます。
2. `pan.baidu.com` のリンクと共有パスワードを貼り付けます。
3. ファイル数、合計サイズ、料金を確認します。
4. メールアドレスでログインし、無料でない注文は支払いを済ませてから、ダウンロードします。
