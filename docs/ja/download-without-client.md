# 百度網盤のクライアントは不要：Windows・Mac・Linux のブラウザでダウンロードする方法

百度網盤の共有でダウンロードボタンを押すと、中国語のポップアップが出て、先に百度網盤をインストールするよう求められます。これは無視して構いません。ここでは、ポップアップが出る理由、クライアントを使う場合に求められること、そしてブラウザだけで同じファイルを入手する方法を説明します。

## ポップアップが出る理由

百度のウェブサイトから直接ダウンロードできるのは小さな単一ファイルだけで、それもログイン中のユーザーに限られます。大きなファイル、フォルダ、または複数のファイルをまとめてダウンロードしようとすると、デスクトップクライアントに回されます。つまりほとんどの共有は、クライアントがなければダウンロードできません。

## クライアントとブラウザ、どちらにする？

| | 百度網盤クライアント | PanPull でブラウザからダウンロード |
| --- | --- | --- |
| インストール | 必要。Windows ではシステムと一緒に起動し、バックグラウンドで動き続けます | 不要 |
| 百度アカウント | 必要 | 不要 |
| 言語 | 中国語のみ | 29 言語 |
| 速度 | 無料アカウントでは制限あり | PanPull のストレージからの通常のダウンロード |
| 費用 | 無料、または百度の有料会員 SVIP | 150 MB まで無料、それ以降はサイズに応じて |
| 対応システム | Windows、macOS、Android、iOS。Linux は `.deb` または `.rpm` | ブラウザがあれば何でも |

それでもクライアントを使いたい場合は、ダウンロード紹介サイトではなく、百度自身の `pan.baidu.com/download` から入手してください。

## ブラウザで済ませるのが向いているケース

- **会社や大学のパソコン：** プログラムをインストールする権限がない。
- **Linux：** ファイル 1 つのために、ソースが公開されていないパッケージを入れたくない。
- **自分の Mac や PC：** バックグラウンドで動くプログラムをこれ以上増やしたくない。

## 手順

1. 共有リンクを [PanPull のリンク確認フォーム](https://panpull.com/ja?utm_source=github&utm_medium=tutorial#link-checker)にコピーします。共有パスワードがあれば一緒に入力します。
2. 結果を確認します。ファイル数、合計サイズ、料金が表示されます。
3. メールアドレスとパスワードで PanPull にログインし、無料でない注文は PayPal またはカードで支払います。
4. ダウンロードの準備ができたことを知らせるメールを待ち、そのリンクを開きます。注文ページにも同じリンクがあります。

ファイルが 1 つの共有ならそのファイルが届きます。複数のファイルがある共有なら、フォルダ構成を含んだ 1 つの ZIP アーカイブが届きます。

## ZIP の展開

| システム | 方法 |
| --- | --- |
| Windows | アーカイブを右クリックし、**すべて展開** を選びます |
| macOS | アーカイブをダブルクリックします |
| Linux | ファイルマネージャーを使うか、ターミナルで `unzip` とファイル名を入力します |

ディスクの空き容量は、アーカイブのサイズの約 2 倍を確保してください。ZIP 本体の分と、中身の分です。
