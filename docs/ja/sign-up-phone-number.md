# 百度アカウントは中国の電話番号なしで作れる？海外から登録できるかを確認

百度は、SMS を受け取れる携帯電話番号がないとアカウントを作らせてくれません。そのため中国国外の多くの人が、何かをダウンロードする前にここでつまずきます。このページを読めば、登録を試す価値があるのか、アカウントなしで済ませられるのかを 2 分で判断できます。

## ステップ 1：自分の国番号はあるか

百度には海外ユーザー向けの登録ページ `passport.baidu.com/v2/?reg&overseas=1` があります。2026 年 10 月 31 日に数えたところ、その一覧には 161 の国番号がありました。

| ある | ない |
| --- | --- |
| アメリカとカナダ、イギリス、スイス、ノルウェー、日本、韓国、ベトナム、ブラジル、メキシコ、オーストラリア | EU 加盟国すべて。ドイツ、フランス、イタリア、スペイン、オランダ、ポーランド、ポルトガル、アイルランドも含みます |

日本（+81）も一覧に含まれています。

自分の国を確かめるには、ページを開き、最初の入力欄の左にある **+86** をクリックします。開いた一覧に、百度が受け付ける国番号がすべて表示されます。

- 国番号がない場合：その番号では登録できません。ステップ 3 に進んでください。
- 国番号がある場合：ステップ 2 に進んでください。

## ステップ 2：アカウントでできること、できないこと

| 無料の百度アカウントでできること | それでもできないこと |
| --- | --- |
| 共有ページでログインする | サイトを英語で読む：中国語のままです |
| 共有されたファイルを自分の百度網盤に保存する | 大きなファイルやフォルダをブラウザでダウンロードする：百度はデスクトップアプリへ誘導します |
| ダウンロードを開始する | 速くダウンロードする：無料アカウントは約 100〜170 KB/s に制限されています |

試す前に知っておきたいことが、あと 2 つあります。

- 一覧にある国でも、SMS が届かないことがあります。特にインターネット回線を使う番号（VoIP）でよく起こります。
- 売られているアカウントやレンタルの電話番号は避けてください。電話番号を握っている人が、アカウントも握ることになります。

## ステップ 3：どちらにするか決める

| あなたの状況 | おすすめの方法 |
| --- | --- |
| 1 つのリンクのファイルが、1 回だけ必要 | アカウントは作らない。[百度アカウントなしでダウンロードする方法](download-without-account.md)の手順を使う |
| 国番号が一覧にない | アカウントは作らない |
| 百度網盤を日常的に使う予定で、国番号も一覧にある | 登録する。PanPull ブログで中国語の登録フォームを 1 項目ずつ訳しています：[百度網盤を中国国外で登録する方法：使える電話番号は？](https://panpull.com/ja/blog/baidu-netdisk-sign-up-outside-china?utm_source=github&utm_medium=tutorial) |

## アカウントなしで済ませる

[PanPull](https://panpull.com/ja?utm_source=github&utm_medium=tutorial#link-checker) が自分の側で共有を取得し、ファイルをあなたに渡します。必要なのは共有リンクとメールアドレスだけで、百度の情報は何も要りません。150 MB までの共有は無料で、それより大きい共有も、決める前に料金を確認できます。

関連：[クライアントをインストールせずにダウンロード](download-without-client.md) · [ダウンロードにかかる時間](slow-download-speed.md)
