# 百度網盤を日本語で：共有ページの入力欄とボタンをすべてまとめた早見表

`pan.baidu.com` の共有ページは中国語版しかありません。この早見表を使えば、位置を手がかりに操作できます。各要素がどこにあり、何をするもので、使う必要があるかをまとめました。内容は 2026 年 10 月 31 日に確認したページに基づいています。

ヒント：ブラウザの翻訳機能は長い文章ならうまく訳せますが、1 語だけのボタンはおかしな訳になりがちです。位置で判断するほうが確実です。

## 画面 1：ロック画面

この画面が出るのは、共有に共有パスワードが設定されているときだけです。

| 場所 | 内容 | 必要？ |
| --- | --- | --- |
| 中央にある 1 つだけの入力欄 | 4 文字のパスワードを入れる欄 | はい |
| 入力欄の下の青いボタン | 共有を開く | はい |
| ゆがんだ画像の横に出る追加の入力欄 | 画像認証：表示された文字をそのまま入力 | 表示されたときだけ |
| 共有者の名前の横の小さなリンク | 共有者への友だち申請 | いいえ |

パスワードの大文字と小文字は区別されません。パスワードがわからない場合は[共有パスワード](extraction-code.md)をお読みください。

## 画面 2：ファイル一覧

| 場所 | 内容 | 必要？ |
| --- | --- | --- |
| ヘッダー行 | 共有のタイトル、共有日、有効期限または「無期限」 | リンクがいつまで使えるかを知るのに便利 |
| ヘッダーの右側 | 購読、別の端末で開く、通報 | いいえ |
| メインエリア | ファイルとフォルダ。それぞれに日付とチェックボックス付き | 中身を見るため |
| 一覧の上の行 | 親フォルダに戻るためのパス | フォルダの中にいるとき |
| 下部の青いボタン | チェックした項目を自分の百度網盤のストレージにコピー | 百度へのログインが必要 |
| 下部、その横の淡い色のボタン | チェックした項目をダウンロード | 百度へのログインが必要。多くの場合デスクトップアプリも必要 |
| 右上の隅 | ログイン、新規登録、デスクトップアプリの入手、会員プランの案内 | 百度アカウントがある場合のみ |

## アカウントなしでどこまでできるか

| 操作 | 百度アカウントがない場合 |
| --- | --- |
| リンクを開く | できる |
| パスワードを入力する | できる |
| ファイルやフォルダを見る | できる |
| 自分のストレージに保存する | できない：ログインが必要 |
| ダウンロードする | できない：ログインが必要で、たいていはデスクトップアプリも必要。さらに無料アカウントの遅い速度 |

つまりこのページでは、見ることはできても持ち帰ることはできません。海外から登録する方法は[中国の電話番号がない場合は？](sign-up-phone-number.md)をご覧ください。

## 近道

中国語のページは触らずに済ませられます。リンクを [PanPull](https://panpull.com/ja?utm_source=github&utm_medium=tutorial#link-checker) にコピーすれば、共有に含まれるファイル数、合計サイズ、ダウンロードの料金が日本語で表示されます。あとはブラウザでダウンロードするだけです。

PanPull ブログの詳しい解説：[百度網盤の共有ページの使い方を日本語で解説](https://panpull.com/ja/blog/baidu-netdisk-in-english?utm_source=github&utm_medium=tutorial)
