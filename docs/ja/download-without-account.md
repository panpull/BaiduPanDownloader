# 百度アカウントなしで百度網盤からダウンロードする方法

友人やフォーラムの投稿、プロジェクトのページで `pan.baidu.com` のリンクを受け取ったとします。ページは開けても、ダウンロードボタンを押すと百度へのログインを求められます。しかも百度がアカウントを発行するのは、SMS を受け取れる電話番号に限られます。回避策は、[PanPull](https://panpull.com/ja?utm_source=github&utm_medium=tutorial) に共有を取得してもらい、その結果をブラウザでダウンロードすることです。百度アカウントも百度のアプリも要らず、中国語を使う場面もありません。

## 用意するもの

| 項目 | 詳細 |
| --- | --- |
| 共有リンク | `https://pan.baidu.com/s/` で始まります |
| 共有パスワード | 英数字 4 文字。ない共有もあります |
| メールアドレス | PanPull へのログインと「準備完了」の通知に使います |

## 7 つのステップ

1. [panpull.com](https://panpull.com/ja?utm_source=github&utm_medium=tutorial#link-checker) の **リンク確認フォームを開きます**。
2. **リンクを貼り付けます**。共有パスワードはその隣の欄に入力します。近道：リンクとパスワードが書かれていたメッセージを丸ごと貼り付ければ、両方とも自動で見つかります。
3. **見積もりを確認します**。共有に含まれるファイル数、合計サイズ、料金が表示されます。この確認に費用はかからず、150 MB 以下の共有なら最後まで無料です。
4. **PanPull にログインします**。初めての方は、メールアドレスとパスワードで登録します。このログインに百度は関わりません。
5. **無料でない注文は支払います**。PayPal が使えるほか、PayPal 経由でデビットカードやクレジットカードも使えます。
6. **処理を待ちます**。タブは閉じて構いません。ファイルの準備が終わると、あなた専用のダウンロードページへのリンクが PanPull からメールで届きます。同じリンクは注文ページにも表示されます。
7. **ダウンロードします**。ファイルが 1 つならそのファイルのまま、複数ならフォルダ構成を保ったまま 1 つの ZIP にまとめて届きます。

## トラブルを防ぐポイント

- 注文には、いつも共有全体がすべてのファイルごと含まれます。
- 有料のダウンロードは、準備ができてから 24 時間以内に取得できます。無料の場合は 1 時間です。その間なら、途中で切れた転送をやり直せます。
- 百度のパスワードやブラウザの Cookie は一切必要ありません。それを求めるサイトやプログラムは信用しないでください。
- 扱うのは、自分のファイルか、所有者が共有に同意したファイルだけにしてください。
