# 百度網盤の共有パスワード（抽出コード）とは？共有を開くのに必要な 4 文字

百度網盤のリンクだけでは、必要なものの半分にすぎないことがよくあります。残りの半分が共有パスワード（抽出コード）です。共有した人がリンクと一緒に受け取る、英数字 4 文字です。パスワード付きの共有は、正しいパスワードを入力するまでファイル一覧が表示されません。

## パスワードの探し方

- **リンクのそば。** リンクが載っていたメッセージや投稿で、「code」「password」「pwd」と書かれた 4 文字や、中国語の短いラベルに続く 4 文字を探してください。
- **リンクの中。** リンクの末尾が `?pwd=` と 4 文字になっていることがあります。たとえば `?pwd=ab12` です。これがパスワードです。
- **所有者に聞く。** どこにも見当たらなければ、教えられるのは共有した本人だけです。ほかの誰にも調べようがありません。

## 入力のしかた

**百度のページ：** パスワード付きの共有を開くと、入力欄が 1 つと、その下に青いボタンが表示されます。パスワードを入力してボタンをクリックします。大文字と小文字は区別されません。

**PanPull：** リンクを [リンク確認フォーム](https://panpull.com/ja?utm_source=github&utm_medium=tutorial#link-checker)に入力します。

- リンクの末尾が `?pwd=` なら、パスワードはリンクから読み取られます。
- メッセージ全体を貼り付けると、そこからリンクとパスワードの両方が抜き出されます。
- それ以外の場合は、パスワード欄に入力してください。この欄に入力したパスワードは、リンクに別のパスワードが含まれていても優先して使われます。

## パスワードが通らない理由

| 原因 | 対処法 |
| --- | --- |
| パスワードの前後に空白までコピーされた | 4 文字を手で入力する |
| 0 と O、1 と l と I のような似た文字 | 元のメッセージと 1 文字ずつ見比べる |
| 別のリンクのパスワードだった | 所有者が複数のリンクを送ってきた場合は、パスワードとリンクを正しく組み合わせる |
| 所有者が共有を作り直した | いちばん新しいメッセージを使う。古いリンクとパスワードはもう使えない |
| 共有そのものがなくなった | パスワードの問題ではありません。[共有リンクが開けない](share-link-not-working.md)を参照 |

当てずっぽうでパスワードを試すのはやめましょう。所有者にリンクとパスワードをもう一度送ってもらってください。

## パスワードではできないこと

パスワードで開けるのは共有ページだけです。ダウンロードには、やはり百度へのログインか、代わりに共有をダウンロードしてくれるサービスが必要です。PanPull でも、パスワード付きの共有をパスワードなしで開くことはできず、所有者が削除した共有を元に戻すこともできません。
