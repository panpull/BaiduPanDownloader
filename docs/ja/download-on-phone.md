# iPhone・Android で百度網盤の共有をダウンロードする方法（百度アプリ不要）

スマホで百度網盤のリンクを開くと、ページは百度網盤アプリへ移動させようとします。アプリではログインが必要です。Safari や Chrome など、普段使っているスマホのブラウザの中だけで済ませる方法があります。

## 始める前に

| 確認すること | 理由 |
| --- | --- |
| 空き容量 | 複数のファイルがある共有は 1 つの ZIP で届きます。ZIP 本体と、展開したあとの中身の両方を置ける容量が必要です |
| Wi-Fi | 大きなファイルはモバイルデータ通信量をすぐに使い切ります |
| 画面とブラウザ | ブラウザがバックグラウンドに回るとダウンロードを止めてしまうスマホもあります。大きなファイルのときはブラウザを前面に出したままにしてください |

## 手順

1. スマホのブラウザで [panpull.com](https://panpull.com/ja?utm_source=github&utm_medium=tutorial#link-checker) を開きます。
2. 入力欄を長押しして、百度網盤のリンクを貼り付けます。リンクと共有パスワードが入ったチャットのメッセージを丸ごとコピーした場合は、それをそのまま貼り付けてください。両方とも読み取られます。
3. 結果を確認します。ファイル数、合計サイズ、料金が表示されます。150 MB までは料金はかかりません。
4. メールアドレスとパスワードでログインします。有料の注文は PayPal またはカードで支払います。
5. あとはスマホを置いておいても大丈夫です。ファイルの準備ができるとメールが届きます。
6. メールのリンクをタップし、開いたページで **ダウンロード** をタップします。

## ダウンロードしたファイルの場所

| スマホ | 探す場所 |
| --- | --- |
| iPhone・iPad（Safari） | アドレスバーの横にある矢印アイコン、または **ファイル** アプリの **ダウンロード** フォルダ |
| Android（Chrome） | ブラウザのメニューから **ダウンロード**、またはファイル管理アプリの **ダウンロード** フォルダ |

ZIP は、ファイルアプリ（iPhone）やファイル管理アプリ（Android）でタップすれば開けます。

## うまくいかないとき

- **ダウンロードをタップしても何も起きないように見える。** もう一度タップする前に、ブラウザのダウンロード一覧を開いてください。2 回目のタップで、同じファイルがもう 1 つダウンロードされることがあります。
- **ダウンロードが途中で止まる。** 空き容量と電波の状態を確認してから、メールのリンクをもう一度タップしてください。リンクは有料の注文なら 24 時間、無料の注文なら 1 時間有効です。
- **ファイルが大きすぎてスマホに入らない。** 同じメールをパソコンで開いてください。リンクは特定の端末に縛られていません。
