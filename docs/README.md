# Baidu Pan Downloader: download from Baidu Netdisk (pan.baidu.com) without an account

Step-by-step tutorials in 28 languages for getting the files out of a Baidu Pan share link when you live outside China. No Baidu account, no Chinese phone number and no desktop client are needed.

The tutorials use [PanPull](https://panpull.com/?utm_source=github&utm_medium=tutorial), a website that downloads a Baidu share for you. You paste the link, see the file count, the total size and the price, and download in your browser. Shares up to 150 MB are free.

## Quick start

1. Open the [PanPull link checker](https://panpull.com/?utm_source=github&utm_medium=tutorial#link-checker).
2. Paste your `pan.baidu.com` link and its extraction code.
3. Look at the file count, the total size and the price.
4. Sign in with an email address, pay if the order is not free, and download.
