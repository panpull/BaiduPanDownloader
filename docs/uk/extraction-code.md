# Код доступу Baidu Pan: 4 символи, без яких посилання не відкрити

Посилання Baidu Pan — часто лише половина того, що потрібно. Друга половина — код доступу: чотири літери або цифри, які той, хто ділиться файлами, отримує разом із посиланням. Поки не введено правильний код, захищене посилання не показує списку файлів.

## Де знайти код

- **Поруч із посиланням.** У повідомленні чи дописі, де ви знайшли посилання, шукайте чотири символи з підписом «code», «password» або «pwd» чи чотири символи після короткого китайського підпису.
- **Усередині посилання.** Деякі посилання закінчуються на `?pwd=` і чотири символи, наприклад `?pwd=ab12`. Це і є код.
- **У власника.** Коду ніде не видно? Повідомити його може лише той, хто поділився файлами. Більше ніхто його не дізнається.

## Як його ввести

**На сторінці Baidu:** захищене посилання відкривається з одним полем введення й синьою кнопкою під ним. Введіть код і натисніть кнопку. Великі й малі літери не розрізняються.

**На PanPull:** вставте посилання в [перевірку посилання](https://panpull.com/uk?utm_source=github&utm_medium=tutorial#link-checker).

- Якщо посилання закінчується на `?pwd=`, код буде взято з самого посилання.
- Якщо вставити все повідомлення, з нього буде вибрано і посилання, і код.
- В інших випадках введіть код у поле для коду. Код, введений там, має пріоритет, навіть якщо в посиланні є інший.

## Чому код не приймається

| Причина | Що робити |
| --- | --- |
| Разом із кодом скопіювався пробіл перед ним або після нього | Введіть чотири символи вручну |
| Схожі символи, як-от 0 і O або 1, l та I | Порівняйте з початковим повідомленням символ за символом |
| Код належить до іншого посилання | Власник надіслав кілька посилань: зіставте кожен код із його посиланням |
| Власник створив нове посилання | Беріть найновіше повідомлення: старі посилання й код більше не працюють |
| Самого посилання вже немає | Справа не в коді. Див. [Посилання не працює](share-link-not-working.md) |

Не підбирайте коди навмання. Попросіть власника надіслати посилання й код ще раз.

## Чого код не робить

Код лише відкриває сторінку з файлами. Для завантаження все одно потрібен вхід у Baidu або сервіс, який завантажить файли за вас. PanPull не відкриє захищене посилання без коду й не поверне посилання, яке власник видалив.
