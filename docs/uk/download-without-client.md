# Baidu Pan без клієнта для комп’ютера: завантаження в браузері на Windows, Mac і Linux

Ви натискаєте кнопку завантаження на сторінці Baidu Pan, і китайське спливаюче вікно вимагає спершу встановити Baidu Netdisk. Його можна проігнорувати. Нижче пояснено, чому з’являється це вікно, чого від вас вимагав би клієнт і як отримати ті самі файли лише за допомогою браузера.

## Чому з’являється це вікно

Сайт Baidu віддає тільки невеликі окремі файли і тільки тим, хто увійшов в обліковий запис. Великий файл, папку або кілька файлів одночасно передають клієнту для комп’ютера. Для більшості посилань це означає: немає клієнта — немає завантаження.

## Клієнт чи браузер?

| | Клієнт Baidu Netdisk | Завантаження в браузері через PanPull |
| --- | --- | --- |
| Встановлення | Так. На Windows він ще й запускається разом із системою і працює у фоні | Не потрібне |

| Системи | Windows, macOS, Android, iOS; Linux у вигляді `.deb` або `.rpm` | Будь-яка система з браузером |

Якщо клієнт вам таки потрібен, завантажуйте його в самого Baidu за адресою `pan.baidu.com/download`, а не з каталогів програм.

## Коли браузер зручніший

- **Офісний чи університетський ПК:** у вас немає прав на встановлення програм.
- **Linux:** не хочеться ставити пакет із закритим кодом заради одного файлу.
- **Власний Mac або ПК:** не хочеться мати ще одну програму, що працює у фоні.

1. Скопіюйте посилання в [перевірку посилання PanPull](https://panpull.com/uk?utm_source=github&utm_medium=tutorial#link-checker). Додайте код доступу, якщо він є.

4. Дочекайтеся листа про те, що завантаження готове, і відкрийте посилання з нього. Те саме посилання є на сторінці замовлення.

Якщо за посиланням один файл, ви отримаєте саме цей файл. Якщо файлів кілька — один ZIP-архів зі структурою папок усередині.

## Як розпакувати ZIP

| Система | Як |
| --- | --- |
| Windows | Клацніть архів правою кнопкою миші й виберіть **Видобути все** |
| macOS | Двічі клацніть архів |
| Linux | Скористайтеся файловим менеджером або введіть у терміналі `unzip` та ім’я файлу |

Майте на диску вільне місце приблизно вдвічі більше за розмір архіву: для самого ZIP і для його вмісту.
