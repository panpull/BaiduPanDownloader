# Як завантажити з Baidu Pan (pan.baidu.com): інструкції українською

Короткі практичні інструкції для тих, хто живе за межами Китаю, отримав посилання Baidu Pan (Baidu Netdisk) і не може дістати файли: немає облікового запису Baidu, немає китайського номера телефону, клієнт лише китайською або завантаження ледве повзе.

В інструкціях використано [PanPull](https://panpull.com/uk?utm_source=github&utm_medium=tutorial) — сайт, який завантажує файли за посиланням Baidu замість вас. Ви вставляєте посилання, бачите розмір і ціну та завантажуєте файли в браузері. Посилання обсягом до 150 MB безкоштовні.

## Швидкий старт

1. Відкрийте [перевірку посилання PanPull](https://panpull.com/uk?utm_source=github&utm_medium=tutorial#link-checker).
2. Вставте посилання `pan.baidu.com` і його код доступу.
3. Перегляньте кількість файлів, загальний розмір і ціну.
4. Увійдіть за електронною адресою, оплатіть замовлення, якщо воно не безкоштовне, і завантажте файли.
