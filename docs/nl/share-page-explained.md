# Baidu Netdisk in het Nederlands: spiekbriefje voor de deelpagina, elk vak en elke knop

Een deelpagina op `pan.baidu.com` bestaat alleen in het Chinees. Met dit spiekbriefje vind je je weg op basis van positie: waar iets staat, wat het doet en of je het nodig hebt. Het beschrijft de pagina zoals we die op 31 oktober 2026 zagen.

Tip: de vertaalfunctie van je browser krijgt lange teksten goed vertaald, maar maakt van knoppen met één woord vaak onzin. Op positie kun je beter vertrouwen.

## Scherm 1: het slot

Dit scherm zie je alleen als de deellink een toegangscode heeft.

| Waar | Wat het is | Heb je het nodig? |
| --- | --- | --- |
| Midden, één tekstvak | Veld voor de code van 4 tekens | Ja |
| Blauwe knop onder het vak | Opent de deellink | Ja |
| Extra vak naast een vervormd plaatje | Captcha: neem de tekens over die je ziet | Alleen als het verschijnt |
| Kleine link naast de naam van de afzender | Vriendschapsverzoek aan de afzender | Nee |

Hoofdletters en kleine letters maken voor de code niet uit. Code kwijt? Lees [Toegangscode](extraction-code.md).

## Scherm 2: de bestanden

| Waar | Wat het is | Heb je het nodig? |
| --- | --- | --- |
| Kopregel | Titel van de deellink, datum van delen, vervaldatum of "verloopt nooit" | Handig om te zien hoe lang de link blijft werken |
| Rechts van de kopregel | Abonneren, openen op een ander apparaat, melden | Nee |
| Hoofdgedeelte | Bestanden en mappen, elk met een datum en een selectievakje | Om te zien wat erin zit |
| Regel boven de lijst | Pad terug naar de bovenliggende map | Als je in een map zit |
| Onderaan, blauwe knop | De aangevinkte items kopiëren naar je eigen Baidu-opslag | Vereist een Baidu-login |
| Onderaan, lichte knop ernaast | De aangevinkte items downloaden | Vereist een Baidu-login, en vaak de desktopapp |
| Rechterbovenhoek | Inloggen, registreren, de desktopapp downloaden, lidmaatschapsaanbiedingen | Alleen met een Baidu-account |

## Hoe ver je komt zonder account

| Actie | Zonder Baidu-account |
| --- | --- |
| De link openen | Werkt |
| De code invullen | Werkt |
| Door bestanden en mappen bladeren | Werkt |
| Opslaan in je eigen opslag | Geblokkeerd: inloggen vereist |
| Downloaden | Geblokkeerd: inloggen, daarna meestal de desktopapp, daarna de lage snelheid van een gratis account |

De pagina laat je dus kijken, maar niets meenemen. Wil je je vanuit het buitenland registreren, zie dan [Geen Chinees telefoonnummer?](sign-up-phone-number.md)
