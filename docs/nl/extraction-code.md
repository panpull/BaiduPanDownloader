# Toegangscode voor Baidu Pan: de 4 tekens waarmee je een deellink opent

Een Baidu Pan-link is vaak maar de helft van wat je nodig hebt. De andere helft is de toegangscode: vier letters of cijfers die de afzender samen met de link krijgt. Een vergrendelde deellink toont geen bestandslijst zolang de juiste code niet is ingevuld.

## Waar je de code vindt

- **Naast de link.** Zoek in het bericht of de post waarin je de link vond naar vier tekens met het label "code", "password" of "pwd", of naar een kort Chinees label met vier tekens erachter.
- **In de link zelf.** Sommige links eindigen op `?pwd=` en vier tekens, bijvoorbeeld `?pwd=ab12`. Dat is de code.
- **Bij de eigenaar.** Nergens een code te zien? Dan kan alleen de afzender hem je geven. Niemand anders kan hem opzoeken.

## Zo vul je hem in

**Op de pagina van Baidu:** een beveiligde deellink opent met één invoervak en een blauwe knop eronder. Typ de code en klik op de knop. Hoofdletters en kleine letters maken geen verschil.

**Op PanPull:** zet de link in de [linkcontrole](https://panpull.com/nl?utm_source=github&utm_medium=tutorial#link-checker).

- Eindigt de link op `?pwd=`, dan wordt de code uit de link gelezen.
- Plak je het hele bericht, dan worden de link en de code er allebei uit gehaald.
- Typ anders de code in het codeveld. Een code die je daar invult, gaat voor, ook als de link een andere bevat.

## Waarom een code wordt geweigerd

| Oorzaak | Wat je doet |
| --- | --- |
| Er is een spatie voor of na de code mee gekopieerd | Typ de vier tekens met de hand |
| Tekens die op elkaar lijken, zoals 0 en O, of 1, l en I | Vergelijk teken voor teken met het oorspronkelijke bericht |
| De code hoort bij een andere link | De eigenaar stuurde meerdere links: koppel elke code aan de eigen link |
| De eigenaar heeft een nieuwe deellink gemaakt | Gebruik het nieuwste bericht; de oude link en code werken niet meer |
| De deellink zelf is weg | Het ligt niet aan de code. Zie [Deellink werkt niet](share-link-not-working.md) |

Probeer niet zomaar codes uit. Vraag de eigenaar om de link en de code opnieuw te sturen.

## Wat een code niet kan

Een code opent alleen de deelpagina. Om te downloaden heb je nog steeds een Baidu-login nodig, of een dienst die de deellink voor je downloadt. PanPull kan een beveiligde deellink niet openen zonder de code, en kan ook geen deellink terughalen die de eigenaar heeft verwijderd.
