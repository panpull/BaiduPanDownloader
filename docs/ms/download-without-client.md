# Baidu Pan tanpa aplikasi desktop: cara muat turun dalam pelayar di Windows, Mac dan Linux

Anda menekan butang muat turun pada perkongsian Baidu Pan dan tetingkap timbul berbahasa Cina meminta anda memasang Baidu Netdisk terlebih dahulu. Anda boleh abaikannya. Berikut sebab tetingkap timbul itu muncul, apa yang diminta oleh aplikasi itu daripada anda, dan cara mendapatkan fail yang sama dengan hanya menggunakan pelayar.

## Kenapa tetingkap timbul itu muncul

Laman web Baidu hanya memberikan fail tunggal yang kecil, itu pun hanya kepada pengguna yang sudah log masuk. Fail besar, folder atau lebih daripada satu fail sekaligus dihantar ke aplikasi desktop. Bagi kebanyakan perkongsian, maksudnya: tiada aplikasi, tiada muat turun.

## Aplikasi atau pelayar?

| | Aplikasi Baidu Netdisk | Muat turun dalam pelayar dengan PanPull |
| --- | --- | --- |
| Pemasangan | Ya. Di Windows, ia juga bermula bersama sistem dan kekal berjalan di latar belakang | Tiada |
| Akaun Baidu | Wajib | Tidak perlu |
| Bahasa | Bahasa Cina sahaja | 29 bahasa |
| Kelajuan | Dihadkan bagi akaun percuma | Muat turun biasa dari storan PanPull |
| Kos | Percuma, atau keahlian SVIP berbayar Baidu | Percuma sehingga 150 MB, selepas itu mengikut saiz |
| Sistem | Windows, macOS, Android, iOS; Linux sebagai `.deb` atau `.rpm` | Apa sahaja yang ada pelayar |

Jika anda memang mahukan aplikasi itu, ambil terus daripada Baidu di `pan.baidu.com/download` dan bukan dari portal muat turun.

## Situasi biasa untuk laluan pelayar

- **PC pejabat atau universiti:** anda tiada kebenaran untuk memasang program.
- **Linux:** anda lebih suka tidak memasang pakej sumber tertutup hanya untuk satu fail.
- **Mac atau PC sendiri:** anda tidak mahu satu lagi program berjalan di latar belakang.

## Langkah-langkah

1. Salin pautan perkongsian ke dalam [penyemak pautan PanPull](https://panpull.com/ms?utm_source=github&utm_medium=tutorial#link-checker). Tambah kod akses jika ada.
2. Lihat hasilnya: berapa banyak fail, berapa jumlah saiznya, berapa harganya.
3. Log masuk ke PanPull dengan alamat e-mel dan kata laluan, dan bayar melalui PayPal atau kad kecuali pesanan itu percuma.
4. Tunggu e-mel yang memberitahu muat turun anda sudah sedia, kemudian buka pautannya. Halaman pesanan anda mempunyai pautan yang sama.

Perkongsian dengan satu fail memberi anda fail itu. Perkongsian dengan beberapa fail memberi anda satu arkib ZIP dengan struktur folder di dalamnya.

## Mengekstrak ZIP

| Sistem | Caranya |
| --- | --- |
| Windows | Klik kanan pada arkib, kemudian **Ekstrak Semua** |
| macOS | Dwiklik pada arkib |
| Linux | Gunakan pengurus fail, atau taip `unzip` dan nama fail dalam terminal |

Sediakan ruang cakera kosong kira-kira dua kali ganda saiz arkib: sekali untuk ZIP, sekali lagi untuk kandungannya.
