# Cara muat turun dari Baidu Pan (pan.baidu.com): tutorial dalam bahasa Melayu

Panduan ringkas dan praktikal untuk mereka di luar China yang menerima pautan perkongsian Baidu Pan (Baidu Netdisk) tetapi tidak dapat mengambil failnya: tiada akaun Baidu, tiada nombor telefon China, aplikasinya dalam bahasa Cina, atau muat turun bergerak terlalu perlahan.

Panduan ini menggunakan [PanPull](https://panpull.com/ms?utm_source=github&utm_medium=tutorial), laman web yang memuat turun perkongsian Baidu untuk anda. Anda tampal pautan, lihat saiz dan harga, kemudian muat turun dalam pelayar. Perkongsian sehingga 150 MB adalah percuma.

## Mula pantas

1. Buka [penyemak pautan PanPull](https://panpull.com/ms?utm_source=github&utm_medium=tutorial#link-checker).
2. Tampal pautan `pan.baidu.com` anda bersama kod aksesnya.
3. Lihat bilangan fail, jumlah saiz dan harganya.
4. Log masuk dengan alamat e-mel, bayar jika pesanan tidak percuma, dan muat turun.

## Sila ambil perhatian

Gunakan panduan ini untuk fail anda sendiri dan fail yang pemiliknya bersetuju untuk anda miliki. Jangan dedahkan kata laluan dan kuki Baidu anda kepada sesiapa: tiada laman web atau program yang memerlukannya.
