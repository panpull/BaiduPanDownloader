# Baidu Pan extraction code: the 4 characters you need to open a share

A Baidu Pan link is often only half of what you need. The other half is the extraction code: four letters or digits that the sharer gets together with the link. A locked share shows no file list until the right code is entered.

## Where to find the code

- **Next to the link.** In the message or post where you found the link, look for four characters labelled "code", "password" or "pwd", or a short Chinese label followed by four characters.
- **Inside the link.** Some links end with `?pwd=` and four characters, for example `?pwd=ab12`. That is the code.
- **From the owner.** No code in sight? Only the sharer can tell you. Nobody else is able to look it up.

## How to enter it

**On Baidu's page:** a protected share opens with a single input box and a blue button under it. Type the code and click the button. Capital and small letters count as the same.

**On PanPull:** put the link into the [link checker](https://panpull.com/?utm_source=github&utm_medium=tutorial#link-checker).

- If the link ends with `?pwd=`, the code is read from the link.
- If you paste the whole message, the link and the code are both picked out of it.
- Otherwise type the code into the code field. A code typed there is used first, even when the link contains another one.

## Why a code is rejected

| Cause | What to do |
| --- | --- |
| A space was copied before or after the code | Type the four characters by hand |
| Characters that look alike, such as 0 and O, or 1, l and I | Compare with the original message one character at a time |
| The code belongs to another link | The owner sent several links: match each code to its own link |
| The owner made a new share | Use the newest message; the old link and code no longer work |
| The share itself is gone | The code is not the problem. See [Share link not working](share-link-not-working.md) |

Do not try codes at random. Ask the owner to send the link and the code again.

## What a code cannot do

A code only opens the share page. Downloading still needs a Baidu login, or a service that downloads the share for you. PanPull cannot open a protected share without its code, and it cannot bring back a share that the owner has deleted.
