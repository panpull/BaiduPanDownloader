# Baidu Netdisk in English: share page cheat sheet for every box and button

A `pan.baidu.com` share page exists in Chinese only. Use this cheat sheet to find your way by position: where each thing sits, what it does, and whether you need it. It describes the page as we saw it on 31 October 2026.

Tip: the translate function of your browser gets the long texts right, but it often garbles one-word buttons. Position is more reliable.

## Screen 1: the lock

You only see this screen when the share has an extraction code.

| Where | What it is | Do you need it? |
| --- | --- | --- |
| Centre, single text box | Field for the 4-character code | Yes |
| Blue button below the box | Opens the share | Yes |
| Extra box beside a distorted image | Captcha: copy the characters you see | Only when it shows up |
| Small link beside the sharer's name | Friend request to the sharer | No |

Upper and lower case do not matter in the code. Lost the code? Read [Extraction code](extraction-code.md).

## Screen 2: the files

| Where | What it is | Do you need it? |
| --- | --- | --- |
| Header line | Share title, sharing date, expiry date or "never expires" | Useful to see how long the link lives |
| Right of the header | Subscribe, open on another device, report | No |
| Main area | Files and folders, each with a date and a tick box | To look at what is inside |
| Line above the list | Path back to the parent folder | When you are inside a folder |
| Bottom, blue button | Copy the ticked items into your own Baidu storage | Needs a Baidu login |
| Bottom, pale button beside it | Download the ticked items | Needs a Baidu login, and often the desktop app |
| Top right corner | Log in, sign up, get the desktop app, membership offers | Only with a Baidu account |

## How far you get without an account

| Action | Without a Baidu account |
| --- | --- |
| Open the link | Works |
| Enter the code | Works |
| Look through files and folders | Works |
| Save to your own storage | Blocked: login |
| Download | Blocked: login, then usually the desktop app, then a slow free-account speed |

So the page lets you look, but not take. To sign up from abroad, see [No Chinese phone number?](sign-up-phone-number.md)
