# Baidu Netdisk without the desktop client: download in the browser on Windows, Mac and Linux

You press the download button on a Baidu Pan share and a Chinese pop-up tells you to install Baidu Netdisk first. You can ignore it. Here is why the pop-up appears, what the client would ask of you, and how to get the same files with nothing but your browser.

## Why the pop-up appears

Baidu's website only hands out small single files, and only to logged-in users. A big file, a folder, or more than one file at a time is passed to the desktop client. For most shares that means: no client, no download.

If you do want the client, take it from Baidu itself at `pan.baidu.com/download` and not from a download portal.

## Typical cases for the browser route

- **Office or university PC:** you have no rights to install programs.
- **Linux:** you would rather not install a closed-source package for one file.
- **Your own Mac or PC:** you do not want one more program that runs in the background.

## Unpacking the ZIP

| System | How |
| --- | --- |
| Windows | Right-click the archive, then **Extract All** |
| macOS | Double-click the archive |
| Linux | Use the file manager, or type `unzip` and the file name in a terminal |

Keep free disk space of about twice the archive size: once for the ZIP, once for its contents.
