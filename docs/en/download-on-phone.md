# Download a Baidu Pan share on iPhone or Android, without the Baidu app

Open a Baidu Pan link on a phone and the page tries to move you into the Baidu Netdisk app, where you would have to log in. There is a way that stays in Safari, Chrome or whichever mobile browser you use.

## Before you start

| Check | Why |
| --- | --- |
| Free storage | A share with several files comes as one ZIP. You need room for the ZIP and, after unpacking, for its contents |
| Wi-Fi | Large files use up mobile data quickly |
| Screen and browser | Some phones pause downloads when the browser goes to the background. Keep it in front for large files |

## Steps

1. In your mobile browser, open [panpull.com](https://panpull.com/?utm_source=github&utm_medium=tutorial#link-checker).
2. Long-press the input field and paste the Baidu link. If you copied a whole chat message with the link and the extraction code in it, paste that: both are recognised.
3. Read the result: file count, total size, price. Nothing is charged up to 150 MB.
4. Log in with email and password. For a paid order, pay by PayPal or card.
5. Put the phone away if you like. An email arrives when the files are ready.
6. Tap the link in the email, then tap **Download** on the page that opens.

## Finding the file afterwards

| Phone | Where to look |
| --- | --- |
| iPhone, iPad with Safari | The arrow icon beside the address bar, or the **Files** app, folder **Downloads** |
| Android with Chrome | Browser menu, then **Downloads**; or the **Downloads** folder in your file manager |

A ZIP opens with a tap in the Files app (iPhone) or in the file manager (Android).

## When something goes wrong

- **Nothing seems to happen after tapping Download.** Open the browser's download list before you tap again. A second tap can start a second copy.
- **The download breaks off.** Check storage and signal, then tap the link in your email once more. It stays valid for 24 hours on a paid order and 1 hour on a free one.
- **The file is too big for the phone.** Open the same email on a computer. The link is not bound to one device.
