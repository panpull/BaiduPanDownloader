# Baidu Pan share link not working: what each message means

You open a `pan.baidu.com` link and get a short message in Chinese instead of a file list. This page tells you what the message means and what you can do.

## First, check the address

A healthy link has the form `https://pan.baidu.com/s/1…` with a long run of letters and digits after the `1`. Once opened, the browser may show `https://pan.baidu.com/share/init?surl=…` instead. That is the same share.

If the link was cut off when it was copied, it will not open. Copy it again from the original message, all the way to the end.

## What the page is telling you

| What you see | What it means | Who can fix it |
| --- | --- | --- |
| A box that asks for four characters | The share is protected. You need the [extraction code](extraction-code.md) | You, with the code from the owner |
| A message that you came too late and the share was cancelled | The owner stopped sharing, or Baidu removed the files | The owner |
| A message about infringement or banned content | Baidu blocked the share | Nobody: the share stays blocked |
| A file list with a note that some files were filtered out | Part of the share broke Baidu's rules and is hidden | The owner |
| A message that the share is no longer valid | The share has expired | The owner |

Your browser's translate feature helps you tell these messages apart.

## What to do

- **The code is rejected:** compare it with the original message one character at a time. See [Extraction code](extraction-code.md).
- **The share is cancelled or expired:** ask the owner to share the files again and to send you the new link and code.
- **The share is blocked:** there is nothing to download. Ask the owner whether the files are available somewhere else.

## Check before you pay anything

Test the link in the [PanPull link checker](https://panpull.com/?utm_source=github&utm_medium=tutorial#link-checker). Checking is free. A readable share comes back with its file count, total size and price. If it cannot be read, you get an error instead, and nothing is charged.

No service can bring back a share that was deleted, cancelled or blocked. If a share fails on PanPull but opens fine for the owner, try again a little later: the cause may be temporary.
