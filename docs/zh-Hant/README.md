# 百度網盤（pan.baidu.com）下載教學：繁體中文版

給中國大陸以外的讀者的簡短實用指南。你收到了百度網盤的分享連結，卻拿不到檔案：沒有百度帳號、手機號碼收不到驗證簡訊、不想安裝百度的用戶端，或是下載速度慢得像在爬。

這些教學使用 [PanPull](https://panpull.com/zh-Hant?utm_source=github&utm_medium=tutorial)，一個替你下載百度分享的網站。貼上連結，看到大小和價格，然後在瀏覽器裡下載。150 MB 以內免費。

## 快速開始

1. 開啟 [PanPull 連結檢查](https://panpull.com/zh-Hant?utm_source=github&utm_medium=tutorial#link-checker)。
2. 貼上 `pan.baidu.com` 連結和提取碼。
3. 查看檔案數量、總大小和價格。
4. 用電子郵件地址登入，非免費訂單先付款，然後下載。

## 請注意

這些教學只用於你自己的檔案，以及擁有者同意給你的檔案。百度密碼和 cookie 請自己保管：任何網站或程式都不需要它們。
