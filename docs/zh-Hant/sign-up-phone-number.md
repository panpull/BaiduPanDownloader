# 百度帳號沒有中國大陸手機號碼能註冊嗎？在海外申請前先確認

百度註冊帳號一定要有能收簡訊的手機號碼。很多中國大陸以外的人，還沒下載任何東西就卡在這一步。本頁幫你在兩分鐘內決定：值得試著註冊，還是乾脆跳過帳號？

## 第 1 步：你的國碼在清單上嗎？

百度有一個給海外用戶的註冊頁面：`passport.baidu.com/v2/?reg&overseas=1`。2026 年 10 月 31 日，我們在它的清單裡數到 161 個國碼。

| 有提供 | 沒有提供 |
| --- | --- |
| 美國和加拿大、英國、瑞士、挪威、日本、南韓、越南、巴西、墨西哥、澳洲 | 所有歐盟國家，包括德國、法國、義大利、西班牙、荷蘭、波蘭、葡萄牙和愛爾蘭 |

在台灣，常有使用者在論壇上反映：發到 +886 號碼的驗證簡訊收不到，登入時也一再被要求做安全驗證。

要查你自己的國家，開啟這個頁面，點第一個欄位左邊的 **+86**。展開的清單會列出百度接受的所有國碼。

- 你的國碼不在清單上：你沒辦法用自己的號碼註冊。請跳到第 3 步。
- 你的國碼在清單上：請看第 2 步。

## 第 2 步：帳號能給你什麼，又不能給你什麼

| 有了免費百度帳號，你可以 | 你還是不能 |
| --- | --- |
| 在分享頁面登入 | 換成繁體中文介面：網站只有簡體中文 |
| 把分享的檔案存到自己的網盤 | 在瀏覽器下載大檔案或資料夾：百度會要你改用電腦版用戶端 |
| 開始下載 | 快速下載：免費帳號的速度大約限制在 100 到 170 KB/s |

動手之前還有兩件事要知道：

- 即使國碼在清單上，驗證簡訊有時還是收不到。網路電話（VoIP）號碼最常遇到這種情況。
- 不要買帳號，也不要租號碼。誰控制手機號碼，誰就控制這個帳號。

## 第 3 步：做決定

| 你的情況 | 最好的做法 |
| --- | --- |
| 你只需要一個連結裡的檔案，只用一次 | 跳過帳號。照[沒有百度帳號怎麼下載](download-without-account.md)的步驟做 |
| 你的國碼不在清單上 | 跳過帳號 |
| 你會經常使用百度網盤，而且國碼在清單上 | 註冊。請使用百度的海外註冊頁面 `passport.baidu.com/v2/?reg&overseas=1` |
