# 在 iPhone 或 Android 上下載百度網盤分享，不用百度 App

用手機開啟百度網盤連結，頁面會一直把你導向百度網盤 App，進去之後又得登入。其實有個辦法可以全程留在 Safari、Chrome 或你慣用的手機瀏覽器裡。

## 開始之前

| 檢查項目 | 原因 |
| --- | --- |
| 可用空間 | 含多個檔案的分享會打包成一個 ZIP 壓縮檔。你需要放得下 ZIP 檔，解壓縮後還要放得下裡面的內容 |
| Wi-Fi | 大檔案很快就會用光行動數據 |
| 螢幕和瀏覽器 | 有些手機在瀏覽器切到背景時會暫停下載。下載大檔案時請讓瀏覽器保持在前景 |

## 步驟

1. 在手機瀏覽器開啟 [panpull.com](https://panpull.com/zh-Hant?utm_source=github&utm_medium=tutorial#link-checker)。
2. 長按輸入框，貼上百度連結。如果你複製的是整段聊天訊息，裡面同時有連結和提取碼，直接整段貼上即可：兩者都會被識別。
3. 看結果：檔案數量、總大小、價格。150 MB 以內不收費。
4. 用電子郵件和密碼登入。付費訂單用 PayPal 或信用卡、簽帳金融卡付款。
5. 接下來手機可以先放著。檔案準備好時會收到一封郵件。
6. 點郵件裡的連結，再在開啟的頁面點 **下載**。

## 下載後去哪裡找檔案

| 手機 | 去哪裡找 |
| --- | --- |
| iPhone、iPad 使用 Safari | 網址列旁的下載圖示，或「檔案」App 裡的「下載項目」資料夾 |
| Android 使用 Chrome | 瀏覽器選單裡的「下載」；或檔案管理程式裡的下載資料夾 |

ZIP 檔在「檔案」App（iPhone）或檔案管理程式（Android）裡點一下就能開啟。

## 遇到問題時

- **點了下載好像沒反應。** 先打開瀏覽器的下載清單看看，不要急著再點一次。點第二次可能會再下載一份。
- **下載中斷。** 檢查儲存空間和訊號，然後再點一次郵件裡的連結。付費訂單的連結 24 小時內有效，免費訂單為 1 小時。
- **檔案太大，手機放不下。** 在電腦上開啟同一封郵件。這個連結沒有綁定裝置。
