# 百度網盤分享連結打不開：每則訊息代表什麼

你開啟 `pan.baidu.com` 連結，看到的不是檔案清單，而是一行簡短的訊息。本頁說明這些訊息的意思，以及你能怎麼處理。

## 先檢查網址

正常的連結長這樣：`https://pan.baidu.com/s/1…`，`1` 後面接著一長串字母和數字。開啟後，瀏覽器可能改為顯示 `https://pan.baidu.com/share/init?surl=…`。那是同一個分享。

如果複製時連結被截斷了，就打不開。請從原始訊息重新複製，一直複製到最後一個字元。

## 頁面在告訴你什麼

| 你看到的 | 代表什麼 | 誰能解決 |
| --- | --- | --- |
| 一個寫著「请输入提取码，不区分大小写」的輸入框 | 這個分享有加密。你需要[提取碼](extraction-code.md) | 你自己，用擁有者給的提取碼 |
| 「啊哦，你来晚了，分享的文件已经被取消了」 | 擁有者取消了分享，或百度移除了檔案 | 擁有者 |
| 「此链接分享内容可能因为涉及侵权……无法访问」 | 百度封鎖了這個分享 | 沒有人：分享會一直被封鎖 |
| 檔案清單上方有「部分文件违规，已被过滤」 | 分享的一部分違反百度規定，已被隱藏 | 擁有者 |
| 「已失效」 | 分享已經過期 | 擁有者 |

訊息全是簡體中文，看得懂字面意思不難；重點是分辨是哪一種情況，以及能不能補救。

## 怎麼處理

- **提取碼被拒絕：** 對照原始訊息，一個字元一個字元比對。請看[提取碼](extraction-code.md)。
- **分享被取消或已過期：** 請擁有者重新分享，並把新的連結和提取碼傳給你。
- **分享被封鎖：** 沒有東西可以下載。問問擁有者，檔案是否放在其他地方。

## 付錢之前先檢查

用 [PanPull 連結檢查](https://panpull.com/zh-Hant?utm_source=github&utm_medium=tutorial#link-checker)測試這個連結。檢查免費。讀得到的分享會顯示檔案數量、總大小和價格。讀不到的話，你會看到錯誤訊息，也不會被收費。

已經刪除、取消或被封鎖的分享，任何服務都救不回來。如果分享在 PanPull 上失敗，但擁有者那邊開得好好的，請過一陣子再試：原因可能只是暫時的。
