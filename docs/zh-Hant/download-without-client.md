# 不裝百度網盤用戶端：在 Windows、Mac 和 Linux 上用瀏覽器下載

你在百度網盤分享頁面按下「下载」，跳出一個視窗，要你先安裝百度網盤用戶端。這個視窗可以不理它。下面說明它為什麼會出現、用戶端會要你做什麼，以及怎麼只用瀏覽器拿到同樣的檔案。

## 為什麼會跳出這個視窗

百度網站只提供單個小檔案的下載，而且只給已登入的用戶。大檔案、資料夾，或一次下載多個檔案，都會交給電腦版用戶端處理。對大多數分享來說，這代表：不裝用戶端，就下載不了。

## 用戶端還是瀏覽器？

| | 百度網盤用戶端 | 用 PanPull 在瀏覽器下載 |
| --- | --- | --- |
| 安裝 | 需要。在 Windows 上還會開機自動啟動，常駐背景 | 不需要 |
| 百度帳號 | 必須 | 不需要 |
| 語言 | 只有簡體中文 | 29 種語言，包括繁體中文 |
| 速度 | 免費帳號有限速 | 從 PanPull 的儲存空間正常下載 |
| 費用 | 免費，或付費購買百度的 SVIP 會員 | 150 MB 以內免費，超過則依大小計費 |
| 系統 | Windows、macOS、Android、iOS；Linux 提供 `.deb` 或 `.rpm` | 任何有瀏覽器的裝置 |

如果你真的要用用戶端，請從百度官方的 `pan.baidu.com/download` 下載，不要從下載站取得。

## 適合用瀏覽器下載的情況

- **公司或學校的電腦：** 你沒有安裝程式的權限。
- **Linux：** 你不想為了一個檔案安裝閉源套件。
- **你自己的 Mac 或 PC：** 你不想再多一個常駐背景的程式。

## 步驟

1. 把分享連結複製到 [PanPull 連結檢查](https://panpull.com/zh-Hant?utm_source=github&utm_medium=tutorial#link-checker)。有提取碼的話一起填上。
2. 看結果：幾個檔案、總共多大、價格多少。
3. 用電子郵件地址和密碼登入 PanPull；不是免費訂單的話，用 PayPal 或信用卡付款。
4. 等待通知下載已準備好的郵件，然後開啟裡面的連結。訂單頁上也有同一個連結。

只有一個檔案的分享，你拿到的就是那個檔案。含多個檔案的分享，你會拿到一個 ZIP 壓縮檔，裡面保留原本的資料夾結構。

## 解壓縮 ZIP 檔

| 系統 | 做法 |
| --- | --- |
| Windows | 在壓縮檔上按右鍵，選「解壓縮全部」 |
| macOS | 按兩下壓縮檔 |
| Linux | 用檔案管理員，或在終端機輸入 `unzip` 加上檔名 |

請預留大約壓縮檔兩倍大小的磁碟空間：一份給 ZIP 檔，一份給解壓縮後的內容。
