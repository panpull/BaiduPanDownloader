# 百度網盤分享頁面按鈕速查表：每個輸入框和按鈕各做什麼

`pan.baidu.com` 的分享頁面只有簡體中文介面。字你都看得懂，難的是知道每個按鈕會帶你去哪裡、百度會在哪一步擋住你。這份速查表依位置說明每個元素在哪裡、做什麼、你需不需要它。內容依據我們在 2026 年 10 月 31 日看到的頁面。

提示：百度會不定期改版。如果按鈕文字和這裡寫的不同，請以位置為準。

## 畫面 1：加密鎖

只有分享設了提取碼時，才會看到這個畫面。

| 位置 | 是什麼 | 需要嗎？ |
| --- | --- | --- |
| 中央，唯一的輸入框 | 輸入 4 位提取碼的欄位，頁面上寫著「请输入提取码，不区分大小写」 | 需要 |
| 輸入框下方的藍色按鈕「提取文件」 | 開啟分享 | 需要 |
| 扭曲圖片旁多出來的輸入框 | 驗證碼：照著圖上的字元輸入 | 出現時才需要 |
| 分享者名稱旁的小連結 | 向分享者送出好友邀請 | 不需要 |

提取碼不分大小寫。提取碼弄丟了？請看[提取碼](extraction-code.md)。

## 畫面 2：檔案清單

| 位置 | 是什麼 | 需要嗎？ |
| --- | --- | --- |
| 標題列 | 分享標題、分享日期、到期日或「过期时间：永久有效」 | 可以看出連結還能用多久 |
| 標題列右側 | 訂閱、在其他裝置開啟、檢舉 | 不需要 |
| 主要區域 | 「全部文件」下的檔案和資料夾，有「文件名」和「修改日期」欄，每項前面有勾選框 | 用來查看分享內容 |
| 清單上方那一行 | 回到上層資料夾的路徑 | 在資料夾裡面時 |
| 底部，藍色按鈕「保存到网盘」 | 把勾選的項目複製到你自己的百度網盤 | 需要登入百度 |
| 底部，旁邊的淺色按鈕「下载」 | 下載勾選的項目 | 需要登入百度，而且常常還要電腦版用戶端 |
| 右上角 | 「登录」、「注册」、「客户端下载」和會員方案的入口 | 只對有百度帳號的人有用 |

## 沒有帳號能走到哪一步

| 動作 | 沒有百度帳號時 |
| --- | --- |
| 開啟連結 | 可以 |
| 輸入提取碼 | 可以 |
| 瀏覽檔案和資料夾 | 可以 |
| 存到自己的網盤 | 被擋：要登入 |
| 下載 | 被擋：要登入，接著通常要裝電腦版用戶端，最後還有免費帳號的慢速 |

所以這個頁面讓你看得到，卻拿不走。想從中國大陸以外註冊，請看[沒有中國大陸手機號碼？](sign-up-phone-number.md)

## 捷徑

你可以不管百度的分享頁面。把連結複製到 [PanPull](https://panpull.com/zh-Hant?utm_source=github&utm_medium=tutorial#link-checker)：它會用繁體中文告訴你這個分享有幾個檔案、合計多大、下載要多少錢。然後你就在瀏覽器裡下載。
