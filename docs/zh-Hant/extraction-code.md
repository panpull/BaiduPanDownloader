# 百度網盤提取碼：開啟分享需要的 4 個字元

百度網盤連結往往只是你需要的一半，另一半是提取碼：分享者建立連結時一併拿到的四個字母或數字。有加密的分享，在輸入正確的提取碼之前，不會顯示檔案清單。

## 提取碼在哪裡

- **在連結旁邊。** 在你找到連結的訊息或文章裡，找標著「提取碼」、「密碼」、「code」或「pwd」的四個字元。
- **在連結裡面。** 有些連結結尾是 `?pwd=` 加四個字元，例如 `?pwd=ab12`。那就是提取碼。
- **問擁有者。** 看不到提取碼？只有分享者能告訴你，別人查不到。

## 怎麼輸入

**在百度的頁面上：** 有加密的分享開啟時，只有一個寫著「请输入提取码，不区分大小写」的輸入框，下面是藍色的「提取文件」按鈕。輸入提取碼，再按這個按鈕。大小寫視為相同。

**在 PanPull 上：** 把連結貼到[連結檢查](https://panpull.com/zh-Hant?utm_source=github&utm_medium=tutorial#link-checker)。

- 連結結尾有 `?pwd=` 的話，會直接從連結讀出提取碼。
- 貼上整段訊息的話，連結和提取碼都會從中找出來。
- 其他情況，請在提取碼欄位手動輸入。手動填寫的提取碼優先，即使連結裡帶著另一組也一樣。

## 提取碼為什麼被拒絕

| 原因 | 怎麼辦 |
| --- | --- |
| 複製時在提取碼前後多帶了空格 | 手動輸入這四個字元 |
| 長得很像的字元，例如 0 和 O，或 1、l 和 I | 對照原始訊息，一個字元一個字元比對 |
| 這組提取碼屬於另一個連結 | 擁有者傳了好幾個連結：把每組提取碼對應到它自己的連結 |
| 擁有者重新建立了分享 | 以最新的訊息為準；舊的連結和提取碼已經失效 |
| 分享本身已經不在了 | 問題不在提取碼。請看[分享連結打不開](share-link-not-working.md) |

不要亂猜提取碼。請擁有者重新傳一次連結和提取碼。

## 提取碼做不到的事

提取碼只能打開分享頁面。要下載，還是得登入百度，或交給替你下載分享的服務。沒有提取碼，PanPull 打不開有加密的分享；擁有者已經刪除的分享，PanPull 也救不回來。
