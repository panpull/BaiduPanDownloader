# 沒有百度帳號，怎麼下載百度網盤的檔案

朋友、論壇文章或專案頁面給了你一個 `pan.baidu.com` 連結。頁面打得開，但下載按鈕要你先登入百度，而百度只讓收得到驗證簡訊的手機號碼註冊帳號。解決辦法：讓 [PanPull](https://panpull.com/zh-Hant?utm_source=github&utm_medium=tutorial) 去取得分享內容，你在瀏覽器裡下載結果。全程不需要百度帳號，也不需要百度 App 或用戶端。

## 先準備好

| 項目 | 說明 |
| --- | --- |
| 分享連結 | 以 `https://pan.baidu.com/s/` 開頭 |
| 提取碼 | 4 位字母或數字。不是每個分享都有 |
| 電子郵件地址 | 用來登入 PanPull，以及接收「檔案已準備好」的通知 |

## 七個步驟

1. **前往連結檢查**：開啟 [panpull.com](https://panpull.com/zh-Hant?utm_source=github&utm_medium=tutorial#link-checker)。
2. **貼上連結。** 提取碼填在旁邊的欄位。捷徑：把含有連結和提取碼的整段訊息貼上，兩者都會自動找出來。
3. **看報價。** 結果會列出分享裡有幾個檔案、總大小和價格。這次檢查不收費；分享在 150 MB 以內的話，整筆訂單都免費。
4. **登入 PanPull。** 新用戶用電子郵件地址和密碼註冊。這個登入和百度無關。
5. **付款（免費訂單除外）。** 可以用 PayPal，也可以透過 PayPal 用簽帳金融卡或信用卡付款。
6. **等它處理。** 想關掉分頁也可以。檔案準備好後，PanPull 會寄一封郵件給你，裡面是私人下載頁的連結。訂單頁也會顯示這個連結。
7. **下載。** 只有一個檔案時，就是那個檔案本身。多個檔案會打包成一個 ZIP 壓縮檔，資料夾結構保持不變。

## 省麻煩的小細節

- 每筆訂單一律包含整個分享的所有檔案。
- 付費下載準備好後，你有 24 小時可以下載；免費下載則是 1 小時。在這段時間內，中斷的下載可以重新開始。
- 永遠不需要你的百度密碼或瀏覽器 cookie。向你要這些東西的網站或程式都不值得信任。
- 只下載屬於你的檔案，或擁有者同意分享給你的檔案。
