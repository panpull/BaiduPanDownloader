# Baidu Pan ohne Desktop-Client: im Browser herunterladen unter Windows, Mac und Linux

Sie klicken auf einer Baidu-Pan-Freigabe auf den Download-Knopf, und ein chinesisches Pop-up fordert Sie auf, zuerst Baidu Netdisk zu installieren. Das können Sie ignorieren. Hier lesen Sie, warum das Pop-up erscheint, was der Client von Ihnen verlangen würde und wie Sie dieselben Dateien nur mit Ihrem Browser bekommen.

## Warum das Pop-up erscheint

Die Baidu-Website gibt nur kleine Einzeldateien heraus, und das nur an angemeldete Nutzer. Eine große Datei, ein Ordner oder mehrere Dateien auf einmal werden an den Desktop-Client weitergereicht. Bei den meisten Freigaben heißt das: ohne Client kein Download.

## Client oder Browser?

| | Client Baidu Netdisk | Browser-Download mit PanPull |
| --- | --- | --- |
| Installation | Ja. Unter Windows startet er außerdem mit dem System und läuft im Hintergrund | Keine |
| Baidu-Konto | Erforderlich | Nicht nötig |
| Sprache | Nur Chinesisch | 29 Sprachen |
| Geschwindigkeit | Mit kostenlosem Konto gedrosselt | Ein normaler Download aus dem Speicher von PanPull |
| Kosten | Kostenlos oder die kostenpflichtige SVIP-Mitgliedschaft von Baidu | Bis 150 MB kostenlos, danach nach Größe |
| Systeme | Windows, macOS, Android, iOS; Linux als `.deb` oder `.rpm` | Alles mit einem Browser |

Wenn Sie den Client doch wollen, holen Sie ihn direkt bei Baidu unter `pan.baidu.com/download` und nicht von einem Downloadportal.

## Typische Fälle für den Weg über den Browser

- **Rechner im Büro oder an der Uni:** Sie dürfen keine Programme installieren.
- **Linux:** Sie möchten für eine einzige Datei kein Closed-Source-Paket installieren.
- **Ihr eigener Mac oder PC:** Sie wollen nicht noch ein Programm, das im Hintergrund läuft.

## Schritte

1. Kopieren Sie den Freigabelink in die [Linkprüfung von PanPull](https://panpull.com/de?utm_source=github&utm_medium=tutorial#link-checker). Geben Sie den Zugangscode dazu, falls es einen gibt.
2. Sehen Sie sich das Ergebnis an: wie viele Dateien, wie groß insgesamt, welcher Preis.
3. Melden Sie sich bei PanPull mit E-Mail-Adresse und Passwort an und bezahlen Sie mit PayPal oder Karte, sofern die Bestellung nicht kostenlos ist.
4. Warten Sie auf die E-Mail, dass Ihr Download bereitsteht, und öffnen Sie den Link darin. Auf Ihrer Bestellseite steht derselbe Link.

Eine Freigabe mit einer Datei liefert genau diese Datei. Eine Freigabe mit mehreren Dateien liefert ein ZIP-Archiv, in dem die Ordnerstruktur erhalten ist.

## Das ZIP entpacken

| System | So geht's |
| --- | --- |
| Windows | Rechtsklick auf das Archiv, dann **Alle extrahieren** |
| macOS | Doppelklick auf das Archiv |
| Linux | Über den Dateimanager oder im Terminal mit `unzip` und dem Dateinamen |

Halten Sie etwa doppelt so viel freien Speicherplatz bereit, wie das Archiv groß ist: einmal für das ZIP, einmal für den Inhalt.
