# Baidu Netdisk auf Deutsch: Spickzettel zur Freigabeseite für jedes Feld und jede Schaltfläche

Eine Freigabeseite auf `pan.baidu.com` gibt es nur auf Chinesisch. Mit diesem Spickzettel finden Sie sich über die Position zurecht: wo etwas sitzt, was es tut und ob Sie es brauchen. Er beschreibt die Seite so, wie wir sie am 31. Oktober 2026 gesehen haben.

Tipp: Die Übersetzungsfunktion Ihres Browsers gibt längere Texte richtig wieder, macht aus Schaltflächen mit nur einem Wort aber oft Unsinn. Auf die Position ist mehr Verlass.

## Bildschirm 1: das Schloss

Diesen Bildschirm sehen Sie nur, wenn die Freigabe einen Zugangscode hat.

| Wo | Was es ist | Brauchen Sie es? |
| --- | --- | --- |
| Mitte, einzelnes Textfeld | Feld für den 4-stelligen Code | Ja |
| Blaue Schaltfläche unter dem Feld | Öffnet die Freigabe | Ja |
| Zusätzliches Feld neben einem verzerrten Bild | Captcha: Zeichen abtippen, die Sie sehen | Nur wenn es erscheint |
| Kleiner Link neben dem Namen des Absenders | Freundschaftsanfrage an den Absender | Nein |

Groß- und Kleinschreibung spielen beim Code keine Rolle. Code verloren? Lesen Sie [Zugangscode](extraction-code.md).

## Bildschirm 2: die Dateien

| Wo | Was es ist | Brauchen Sie es? |
| --- | --- | --- |
| Kopfzeile | Titel der Freigabe, Freigabedatum, Ablaufdatum oder „läuft nie ab“ | Nützlich, um zu sehen, wie lange der Link gilt |
| Rechts neben der Kopfzeile | Abonnieren, auf einem anderen Gerät öffnen, melden | Nein |
| Hauptbereich | Dateien und Ordner, jeweils mit Datum und Kontrollkästchen | Um zu sehen, was drin ist |
| Zeile über der Liste | Pfad zurück zum übergeordneten Ordner | Wenn Sie in einem Ordner sind |
| Unten, blaue Schaltfläche | Markierte Einträge in Ihren eigenen Baidu-Speicher kopieren | Erfordert eine Baidu-Anmeldung |
| Unten, blasse Schaltfläche daneben | Markierte Einträge herunterladen | Erfordert eine Baidu-Anmeldung und oft die Desktop-App |
| Ecke oben rechts | Anmelden, registrieren, Desktop-App holen, Mitgliedschaftsangebote | Nur mit Baidu-Konto |

## Wie weit Sie ohne Konto kommen

| Aktion | Ohne Baidu-Konto |
| --- | --- |
| Link öffnen | Funktioniert |
| Code eingeben | Funktioniert |
| Dateien und Ordner durchsehen | Funktioniert |
| In den eigenen Speicher übernehmen | Gesperrt: Anmeldung nötig |
| Herunterladen | Gesperrt: Anmeldung, dann meist die Desktop-App, dann das langsame Tempo eines kostenlosen Kontos |

Die Seite lässt Sie also schauen, aber nichts mitnehmen. Wie Sie sich aus dem Ausland registrieren, steht unter [Keine chinesische Handynummer?](sign-up-phone-number.md)

## Die Abkürzung

Sie können die chinesische Seite links liegen lassen. Kopieren Sie den Link in [PanPull](https://panpull.com/de?utm_source=github&utm_medium=tutorial#link-checker): Dort sehen Sie in Ihrer Sprache, wie viele Dateien die Freigabe enthält, wie groß sie zusammen sind und was der Download kostet. Danach laden Sie im Browser herunter.

Mehr Details im PanPull-Blog: [Baidu Netdisk auf Deutsch oder Englisch? So nutzen Sie die Freigabeseite](https://panpull.com/de/blog/baidu-netdisk-in-english?utm_source=github&utm_medium=tutorial).
