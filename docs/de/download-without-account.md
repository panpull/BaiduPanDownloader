# Von Baidu Pan ohne Baidu-Konto herunterladen: so geht's

Ein Freund, ein Forenbeitrag oder eine Projektseite hat Ihnen einen `pan.baidu.com`-Link gegeben. Die Seite öffnet sich, aber der Download-Knopf verlangt eine Baidu-Anmeldung, und Baidu vergibt Konten nur an Handynummern, an die es eine SMS schicken kann. Der Ausweg: Lassen Sie [PanPull](https://panpull.com/de?utm_source=github&utm_medium=tutorial) die Freigabe abholen und laden Sie das Ergebnis im Browser herunter. Dafür brauchen Sie weder ein Baidu-Konto noch die Baidu-App noch Chinesischkenntnisse.

## Das sollten Sie bereithalten

| Was | Details |
| --- | --- |
| Freigabelink | Beginnt mit `https://pan.baidu.com/s/` |
| Zugangscode | 4 Buchstaben oder Ziffern. Nicht jede Freigabe hat einen |
| E-Mail-Adresse | Für Ihre Anmeldung bei PanPull und die Nachricht, dass alles bereitsteht |

## Die sieben Schritte

1. **Öffnen Sie die Linkprüfung** auf [panpull.com](https://panpull.com/de?utm_source=github&utm_medium=tutorial#link-checker).
2. **Fügen Sie den Link ein.** Der Code gehört in das Feld daneben. Abkürzung: Fügen Sie die ganze Nachricht ein, in der Link und Code standen, dann werden beide für Sie erkannt.
3. **Lesen Sie das Angebot.** Es zeigt, wie viele Dateien die Freigabe enthält, wie groß sie zusammen sind und was es kostet. Die Prüfung ist kostenlos, und wenn die Freigabe 150 MB oder kleiner ist, zahlen Sie gar nichts.
4. **Melden Sie sich bei PanPull an.** Neue Nutzer registrieren sich mit E-Mail-Adresse und Passwort. Baidu hat mit dieser Anmeldung nichts zu tun.
5. **Bezahlen Sie, wenn die Bestellung nicht kostenlos ist.** PayPal funktioniert, ebenso Debit- und Kreditkarten über PayPal.
6. **Lassen Sie PanPull arbeiten.** Sie können den Tab ruhig schließen. Sobald die Dateien vorbereitet sind, schickt PanPull Ihnen per E-Mail einen Link zu einer privaten Download-Seite. Auf Ihrer Bestellseite finden Sie diesen Link ebenfalls.
7. **Laden Sie herunter.** Eine einzelne Datei bekommen Sie als genau diese Datei. Mehrere Dateien kommen gepackt in einem einzigen ZIP-Archiv, die Ordnerstruktur bleibt erhalten.

## Details, die Ärger ersparen

- Eine Bestellung umfasst immer die ganze Freigabe mit allen Dateien.
- Wenn ein bezahlter Download bereitsteht, haben Sie 24 Stunden Zeit, ihn abzuholen. Bei einem kostenlosen ist es 1 Stunde. Eine abgebrochene Übertragung können Sie innerhalb dieser Zeit neu starten.
- Ihr Baidu-Passwort und Ihre Browser-Cookies werden nie gebraucht. Einer Website oder einem Programm, das danach fragt, sollten Sie nicht trauen.
- Bleiben Sie bei Dateien, die Ihnen gehören oder die der Eigentümer mit Ihnen teilen wollte.
