# Baidu-Pan-Zugangscode: die 4 Zeichen, mit denen sich eine Freigabe öffnet

Ein Baidu-Pan-Link ist oft nur die halbe Miete. Die andere Hälfte ist der Zugangscode: vier Buchstaben oder Ziffern, die der Absender zusammen mit dem Link erhält. Eine gesperrte Freigabe zeigt keine Dateiliste, bis der richtige Code eingegeben ist.

## Wo Sie den Code finden

- **Neben dem Link.** Suchen Sie in der Nachricht oder dem Beitrag, in dem der Link stand, nach vier Zeichen mit der Bezeichnung „code“, „password“ oder „pwd“ oder nach einer kurzen chinesischen Bezeichnung, auf die vier Zeichen folgen.
- **Im Link selbst.** Manche Links enden mit `?pwd=` und vier Zeichen, zum Beispiel `?pwd=ab12`. Das ist der Code.
- **Beim Eigentümer.** Nirgends ein Code zu sehen? Dann kann nur der Absender ihn Ihnen nennen. Niemand sonst kann ihn nachschlagen.

## So geben Sie ihn ein

**Auf der Baidu-Seite:** Eine geschützte Freigabe öffnet sich mit einem einzelnen Eingabefeld und einer blauen Schaltfläche darunter. Tippen Sie den Code ein und klicken Sie auf die Schaltfläche. Groß- und Kleinschreibung spielen keine Rolle.

**Bei PanPull:** Geben Sie den Link in die [Linkprüfung](https://panpull.com/de?utm_source=github&utm_medium=tutorial#link-checker) ein.

- Endet der Link mit `?pwd=`, wird der Code aus dem Link gelesen.
- Fügen Sie die ganze Nachricht ein, werden Link und Code beide daraus herausgesucht.
- Andernfalls tippen Sie den Code in das Codefeld. Ein dort eingegebener Code hat Vorrang, auch wenn der Link einen anderen enthält.

## Warum ein Code abgelehnt wird

| Ursache | Was Sie tun können |
| --- | --- |
| Vor oder hinter dem Code wurde ein Leerzeichen mitkopiert | Tippen Sie die vier Zeichen von Hand ein |
| Zeichen, die sich ähneln, etwa 0 und O oder 1, l und I | Vergleichen Sie Zeichen für Zeichen mit der ursprünglichen Nachricht |
| Der Code gehört zu einem anderen Link | Der Eigentümer hat mehrere Links geschickt: Ordnen Sie jedem Link seinen Code zu |
| Der Eigentümer hat eine neue Freigabe erstellt | Nehmen Sie die neueste Nachricht; alter Link und alter Code funktionieren nicht mehr |
| Die Freigabe selbst ist weg | Am Code liegt es nicht. Siehe [Freigabelink funktioniert nicht](share-link-not-working.md) |

Probieren Sie keine Codes auf gut Glück aus. Bitten Sie den Eigentümer, Link und Code noch einmal zu schicken.

## Was ein Code nicht kann

Ein Code öffnet nur die Freigabeseite. Zum Herunterladen brauchen Sie trotzdem eine Baidu-Anmeldung oder einen Dienst, der die Freigabe für Sie herunterlädt. PanPull kann eine geschützte Freigabe ohne ihren Code nicht öffnen und auch keine Freigabe zurückholen, die der Eigentümer gelöscht hat.
