# Baidu-Pan-Freigabe auf iPhone oder Android herunterladen, ohne Baidu-App

Wenn Sie einen Baidu-Pan-Link auf dem Handy öffnen, will die Seite Sie in die App Baidu Netdisk schicken, wo Sie sich anmelden müssten. Es geht auch so, dass Sie in Safari, Chrome oder Ihrem gewohnten mobilen Browser bleiben.

## Bevor Sie anfangen

| Prüfen | Warum |
| --- | --- |
| Freier Speicher | Eine Freigabe mit mehreren Dateien kommt als ein ZIP-Archiv. Sie brauchen Platz für das ZIP und nach dem Entpacken auch für seinen Inhalt |
| WLAN | Große Dateien verbrauchen schnell Ihr mobiles Datenvolumen |
| Bildschirm und Browser | Manche Handys pausieren Downloads, sobald der Browser in den Hintergrund geht. Lassen Sie ihn bei großen Dateien im Vordergrund |

## Schritte

1. Öffnen Sie im mobilen Browser [panpull.com](https://panpull.com/de?utm_source=github&utm_medium=tutorial#link-checker).
2. Tippen Sie lange auf das Eingabefeld und fügen Sie den Baidu-Link ein. Haben Sie eine ganze Chatnachricht mit Link und Zugangscode kopiert, fügen Sie einfach diese ein: Beides wird erkannt.
3. Lesen Sie das Ergebnis: Dateianzahl, Gesamtgröße, Preis. Bis 150 MB wird nichts berechnet.
4. Melden Sie sich mit E-Mail-Adresse und Passwort an. Eine kostenpflichtige Bestellung bezahlen Sie mit PayPal oder Karte.
5. Jetzt können Sie das Handy weglegen. Sobald die Dateien bereitstehen, kommt eine E-Mail.
6. Tippen Sie auf den Link in der E-Mail und dann auf der geöffneten Seite auf **Herunterladen**.

## Wo die Datei danach liegt

| Gerät | Wo Sie suchen |
| --- | --- |
| iPhone, iPad mit Safari | Das Pfeilsymbol neben der Adressleiste oder die App **Dateien**, Ordner **Downloads** |
| Android mit Chrome | Browsermenü, dann **Downloads**; oder der Ordner **Downloads** in Ihrem Dateimanager |

Ein ZIP öffnen Sie mit einem Tippen in der App Dateien (iPhone) oder im Dateimanager (Android).

## Wenn etwas schiefgeht

- **Nach dem Tippen auf Herunterladen passiert scheinbar nichts.** Schauen Sie in die Downloadliste des Browsers, bevor Sie noch einmal tippen. Ein zweites Tippen kann eine zweite Kopie starten.
- **Der Download bricht ab.** Prüfen Sie Speicher und Empfang und tippen Sie dann erneut auf den Link in Ihrer E-Mail. Er gilt bei einer bezahlten Bestellung 24 Stunden, bei einer kostenlosen 1 Stunde.
- **Die Datei ist zu groß für das Handy.** Öffnen Sie dieselbe E-Mail am Computer. Der Link ist nicht an ein Gerät gebunden.
