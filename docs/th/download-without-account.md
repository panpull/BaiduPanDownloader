# วิธีดาวน์โหลดไฟล์จาก Baidu Pan โดยไม่ต้องมีบัญชี Baidu

เพื่อน โพสต์ในฟอรัม หรือหน้าเว็บของโปรเจกต์หนึ่งให้ลิงก์ `pan.baidu.com` มา หน้าเว็บเปิดได้ แต่ปุ่มดาวน์โหลดต้องเข้าสู่ระบบ Baidu และ Baidu ให้บัญชีเฉพาะเบอร์โทรศัพท์ที่ส่ง SMS ถึงได้เท่านั้น ทางออกคือให้ [PanPull](https://panpull.com/th?utm_source=github&utm_medium=tutorial) ดึงไฟล์จากลิงก์แชร์มา แล้วคุณดาวน์โหลดผลลัพธ์ในเบราว์เซอร์ ไม่ต้องมีบัญชี Baidu ไม่ต้องใช้แอป Baidu และไม่ต้องอ่านภาษาจีน

## เตรียมสิ่งเหล่านี้ไว้

| รายการ | รายละเอียด |
| --- | --- |
| ลิงก์แชร์ | ขึ้นต้นด้วย `https://pan.baidu.com/s/` |
| รหัสเข้าถึง | ตัวอักษรภาษาอังกฤษหรือตัวเลข 4 ตัว ไม่ใช่ทุกลิงก์แชร์ที่มี |
| อีเมล | ใช้เข้าสู่ระบบ PanPull และรับข้อความแจ้งว่าไฟล์พร้อมแล้ว |

## เจ็ดขั้นตอน

1. **ไปที่เครื่องมือตรวจสอบลิงก์** บน [panpull.com](https://panpull.com/th?utm_source=github&utm_medium=tutorial#link-checker)
2. **วางลิงก์** รหัสเข้าถึงใส่ในช่องข้างๆ ทางลัดคือวางข้อความทั้งข้อความที่มีลิงก์และรหัส แล้วระบบจะหาทั้งสองอย่างให้
3. **อ่านใบเสนอราคา** ใบเสนอราคาจะบอกว่าลิงก์แชร์มีกี่ไฟล์ ขนาดรวมเท่าไร และราคาเท่าไร การตรวจสอบนี้ไม่เสียเงิน และถ้าลิงก์แชร์มีขนาด 150 MB หรือน้อยกว่า ก็ไม่ต้องจ่ายอะไรเลย
4. **เข้าสู่ระบบ PanPull** ผู้ใช้ใหม่สมัครด้วยอีเมลและรหัสผ่าน การเข้าสู่ระบบนี้ไม่เกี่ยวข้องกับ Baidu
5. **ชำระเงิน เว้นแต่คำสั่งซื้อจะฟรี** จ่ายผ่าน PayPal ได้ และใช้บัตรเดบิตหรือบัตรเครดิตผ่าน PayPal ได้เช่นกัน
6. **รอให้ระบบทำงาน** จะปิดแท็บไปก็ได้ เมื่อเตรียมไฟล์เสร็จ PanPull จะส่งอีเมลพร้อมลิงก์ไปยังหน้าดาวน์โหลดส่วนตัวของคุณ หน้าคำสั่งซื้อก็แสดงลิงก์นี้ด้วย
7. **ดาวน์โหลด** ถ้ามีไฟล์เดียวก็จะได้ไฟล์นั้นตามเดิม ถ้ามีหลายไฟล์จะรวมอยู่ในไฟล์ ZIP เดียว โดยคงโครงสร้างโฟลเดอร์ไว้ครบ

## รายละเอียดที่ช่วยให้ไม่ติดปัญหา

- คำสั่งซื้อจะดึงลิงก์แชร์ทั้งหมดเสมอ พร้อมไฟล์ทุกไฟล์ในลิงก์นั้น
- เมื่อการดาวน์โหลดแบบชำระเงินพร้อมแล้ว คุณมีเวลา 24 ชั่วโมงในการดาวน์โหลด ส่วนแบบฟรีมีเวลา 1 ชั่วโมง หากดาวน์โหลดขาดกลางทาง ก็เริ่มใหม่ได้ภายในเวลานั้น
- ไม่จำเป็นต้องใช้รหัสผ่าน Baidu หรือคุกกี้เบราว์เซอร์ของคุณเลย เว็บไซต์หรือโปรแกรมที่ขอข้อมูลเหล่านี้ไม่น่าไว้ใจ
- ดาวน์โหลดเฉพาะไฟล์ที่เป็นของคุณ หรือไฟล์ที่เจ้าของยินยอมแชร์ให้คุณ
