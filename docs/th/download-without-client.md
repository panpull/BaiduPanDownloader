# ดาวน์โหลด Baidu Pan โดยไม่ต้องลงโปรแกรม: โหลดผ่านเบราว์เซอร์บน Windows, Mac และ Linux

คุณกดปุ่มดาวน์โหลดบนหน้าแชร์ Baidu Pan แล้วมีป๊อปอัปภาษาจีนเด้งขึ้นมาบอกให้ติดตั้ง Baidu Netdisk ก่อน คุณไม่ต้องสนใจมันก็ได้ บทความนี้อธิบายว่าทำไมป๊อปอัปนี้ถึงขึ้นมา โปรแกรมจะเรียกร้องอะไรจากคุณ และจะได้ไฟล์ชุดเดียวกันโดยใช้แค่เบราว์เซอร์ได้อย่างไร

## ทำไมป๊อปอัปถึงขึ้นมา

เว็บไซต์ของ Baidu ให้ดาวน์โหลดได้เฉพาะไฟล์เดี่ยวขนาดเล็ก และเฉพาะผู้ใช้ที่เข้าสู่ระบบแล้วเท่านั้น ไฟล์ใหญ่ โฟลเดอร์ หรือการโหลดหลายไฟล์พร้อมกัน จะถูกส่งต่อไปที่โปรแกรมบนคอมพิวเตอร์ สำหรับลิงก์แชร์ส่วนใหญ่ จึงหมายความว่า ไม่มีโปรแกรมก็ดาวน์โหลดไม่ได้

| การติดตั้ง | ต้องติดตั้ง บน Windows ยังเปิดขึ้นเองพร้อมระบบและทำงานอยู่เบื้องหลัง | ไม่ต้อง |

| ค่าใช้จ่าย | ฟรี หรือสมัครสมาชิก SVIP แบบเสียเงินของ Baidu | ฟรีไม่เกิน 150 MB หลังจากนั้นคิดตามขนาด |

หากต้องการใช้โปรแกรมจริงๆ ให้ดาวน์โหลดจาก Baidu โดยตรงที่ `pan.baidu.com/download` ไม่ใช่จากเว็บรวมโปรแกรม

## กรณีที่เหมาะกับการโหลดผ่านเบราว์เซอร์

- **คอมพิวเตอร์ที่ทำงานหรือมหาวิทยาลัย:** คุณไม่มีสิทธิ์ติดตั้งโปรแกรม
- **Linux:** คุณไม่อยากติดตั้งแพ็กเกจที่ไม่เปิดเผยซอร์สโค้ดเพียงเพื่อไฟล์เดียว
- **Mac หรือ PC ของคุณเอง:** คุณไม่อยากมีโปรแกรมทำงานเบื้องหลังเพิ่มอีกตัว

## ขั้นตอน

1. คัดลอกลิงก์แชร์ไปวางใน [เครื่องมือตรวจสอบลิงก์ของ PanPull](https://panpull.com/th?utm_source=github&utm_medium=tutorial#link-checker) ใส่รหัสเข้าถึงด้วยหากมี
2. ดูผลลัพธ์ว่ามีกี่ไฟล์ ขนาดรวมเท่าไร และราคาเท่าไร
3. เข้าสู่ระบบ PanPull ด้วยอีเมลและรหัสผ่าน แล้วชำระเงินผ่าน PayPal หรือบัตร เว้นแต่คำสั่งซื้อจะฟรี
4. รออีเมลแจ้งว่าไฟล์ดาวน์โหลดพร้อมแล้ว จากนั้นเปิดลิงก์ในอีเมล หน้าคำสั่งซื้อของคุณก็มีลิงก์เดียวกัน

ลิงก์แชร์ที่มีไฟล์เดียวจะได้ไฟล์นั้นมาเลย ลิงก์แชร์ที่มีหลายไฟล์จะได้ไฟล์ ZIP หนึ่งไฟล์ที่คงโครงสร้างโฟลเดอร์ไว้ข้างใน

## แตกไฟล์ ZIP

| ระบบ | วิธีทำ |
| --- | --- |
| Windows | คลิกขวาที่ไฟล์ แล้วเลือก **แยกไฟล์ทั้งหมด** (Extract All) |
| macOS | ดับเบิลคลิกที่ไฟล์ |
