# รหัสเข้าถึง Baidu Pan: รหัส 4 ตัวที่ต้องใช้เปิดลิงก์แชร์

ลิงก์ Baidu Pan มักเป็นแค่ครึ่งเดียวของสิ่งที่คุณต้องใช้ อีกครึ่งคือรหัสเข้าถึง ซึ่งเป็นตัวอักษรภาษาอังกฤษหรือตัวเลข 4 ตัวที่ผู้แชร์ได้มาพร้อมกับลิงก์ ลิงก์แชร์ที่ล็อกไว้จะไม่แสดงรายการไฟล์จนกว่าจะกรอกรหัสที่ถูกต้อง

## หารหัสได้ที่ไหน

- **ข้างๆ ลิงก์** ในข้อความหรือโพสต์ที่คุณเจอลิงก์ ให้มองหาตัวอักษร 4 ตัวที่มีคำว่า "code", "password" หรือ "pwd" กำกับอยู่ หรือ 4 ตัวที่ตามหลังป้ายภาษาจีนสั้นๆ
- **ในตัวลิงก์เอง** ลิงก์บางลิงก์ลงท้ายด้วย `?pwd=` ตามด้วยตัวอักษร 4 ตัว เช่น `?pwd=ab12` นั่นแหละคือรหัส
- **จากเจ้าของ** ไม่เห็นรหัสเลยใช่ไหม มีแค่ผู้แชร์เท่านั้นที่บอกคุณได้ ไม่มีใครอื่นค้นหารหัสนี้ได้

## วิธีกรอกรหัส

**บนหน้าเว็บของ Baidu:** ลิงก์แชร์ที่ล็อกไว้จะเปิดขึ้นมาพร้อมช่องกรอกช่องเดียวและปุ่มสีน้ำเงินด้านล่าง พิมพ์รหัสแล้วคลิกปุ่ม ตัวพิมพ์ใหญ่และตัวพิมพ์เล็กถือว่าเหมือนกัน

**บน PanPull:** ใส่ลิงก์ลงใน [เครื่องมือตรวจสอบลิงก์](https://panpull.com/th?utm_source=github&utm_medium=tutorial#link-checker)

- ถ้าลิงก์ลงท้ายด้วย `?pwd=` ระบบจะอ่านรหัสจากลิงก์
- ถ้าคุณวางทั้งข้อความ ระบบจะดึงทั้งลิงก์และรหัสออกมาจากข้อความนั้น
- นอกจากนั้น ให้พิมพ์รหัสลงในช่องรหัสเข้าถึง รหัสที่พิมพ์ในช่องนี้จะถูกใช้ก่อน แม้ในลิงก์จะมีรหัสอื่นอยู่ก็ตาม

## ทำไมรหัสถึงไม่ผ่าน

| สาเหตุ | สิ่งที่ควรทำ |
| --- | --- |
| มีช่องว่างติดมาก่อนหรือหลังรหัสตอนคัดลอก | พิมพ์รหัส 4 ตัวเอง |
| ตัวอักษรที่หน้าตาคล้ายกัน เช่น 0 กับ O หรือ 1, l กับ I | เทียบกับข้อความต้นฉบับทีละตัว |
| รหัสเป็นของลิงก์อื่น | เจ้าของส่งมาหลายลิงก์ ให้จับคู่รหัสแต่ละตัวกับลิงก์ของมัน |
| เจ้าของสร้างลิงก์แชร์ใหม่ | ใช้ข้อความล่าสุด ลิงก์และรหัสเก่าใช้ไม่ได้แล้ว |
| ลิงก์แชร์ไม่มีอยู่แล้ว | ปัญหาไม่ได้อยู่ที่รหัส ดู [ลิงก์แชร์เปิดไม่ได้](share-link-not-working.md) |

อย่าสุ่มเดารหัส ให้ขอเจ้าของส่งลิงก์และรหัสมาใหม่

## สิ่งที่รหัสทำไม่ได้

รหัสใช้เปิดได้แค่หน้าแชร์ การดาวน์โหลดยังต้องเข้าสู่ระบบ Baidu หรือใช้บริการที่ดาวน์โหลดลิงก์แชร์ให้คุณ PanPull เปิดลิงก์แชร์ที่ล็อกไว้โดยไม่มีรหัสไม่ได้ และกู้คืนลิงก์แชร์ที่เจ้าของลบไปแล้วไม่ได้
