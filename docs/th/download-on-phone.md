# ดาวน์โหลดไฟล์จากลิงก์แชร์ Baidu Pan บน iPhone หรือ Android โดยไม่ต้องใช้แอป Baidu

เมื่อเปิดลิงก์ Baidu Pan บนมือถือ หน้าเว็บจะพยายามพาคุณไปที่แอป Baidu Netdisk ซึ่งคุณต้องเข้าสู่ระบบ แต่มีวิธีที่ใช้ได้โดยไม่ต้องออกจาก Safari, Chrome หรือเบราว์เซอร์มือถือที่คุณใช้อยู่

## ก่อนเริ่ม

| ตรวจสอบ | เหตุผล |
| --- | --- |
| พื้นที่ว่าง | ลิงก์แชร์ที่มีหลายไฟล์จะมาเป็นไฟล์ ZIP ไฟล์เดียว คุณต้องมีพื้นที่สำหรับไฟล์ ZIP และสำหรับไฟล์ข้างในหลังแตกไฟล์แล้ว |
| Wi-Fi | ไฟล์ขนาดใหญ่ใช้เน็ตมือถือหมดเร็ว |
| หน้าจอและเบราว์เซอร์ | มือถือบางรุ่นจะหยุดดาวน์โหลดชั่วคราวเมื่อเบราว์เซอร์ถูกย่อไปทำงานเบื้องหลัง หากเป็นไฟล์ใหญ่ ให้เปิดเบราว์เซอร์ค้างไว้ |

## ขั้นตอน

1. เปิด [panpull.com](https://panpull.com/th?utm_source=github&utm_medium=tutorial#link-checker) ในเบราว์เซอร์บนมือถือ
2. กดค้างที่ช่องกรอกแล้ววางลิงก์ Baidu หากคุณคัดลอกข้อความแชททั้งข้อความที่มีทั้งลิงก์และรหัสเข้าถึงมา ก็วางทั้งข้อความได้เลย ระบบจะจับได้ทั้งสองอย่าง
3. อ่านผลลัพธ์ ได้แก่ จำนวนไฟล์ ขนาดรวม และราคา ไม่เกิน 150 MB ไม่เสียค่าใช้จ่าย
4. เข้าสู่ระบบด้วยอีเมลและรหัสผ่าน หากเป็นคำสั่งซื้อแบบชำระเงิน ให้จ่ายผ่าน PayPal หรือบัตร
5. จะวางมือถือไว้ก่อนก็ได้ เมื่อไฟล์พร้อม คุณจะได้รับอีเมล
6. แตะลิงก์ในอีเมล แล้วแตะ **ดาวน์โหลด** ในหน้าที่เปิดขึ้น

## หาไฟล์หลังดาวน์โหลด

| มือถือ | ดูที่ไหน |
| --- | --- |
| iPhone, iPad ที่ใช้ Safari | ไอคอนลูกศรข้างแถบที่อยู่ หรือแอป **ไฟล์** โฟลเดอร์ **ดาวน์โหลด** |
| Android ที่ใช้ Chrome | เมนูเบราว์เซอร์ แล้วเลือก **ดาวน์โหลด** หรือโฟลเดอร์ **Download** ในแอปจัดการไฟล์ |

ไฟล์ ZIP เปิดได้ด้วยการแตะครั้งเดียวในแอปไฟล์ (iPhone) หรือในแอปจัดการไฟล์ (Android)

## เมื่อมีปัญหา

- **แตะดาวน์โหลดแล้วเหมือนไม่มีอะไรเกิดขึ้น** เปิดรายการดาวน์โหลดของเบราว์เซอร์ดูก่อนจะแตะอีกครั้ง การแตะซ้ำอาจทำให้ได้ไฟล์ซ้ำอีกชุด
- **ดาวน์โหลดขาดกลางทาง** ตรวจสอบพื้นที่ว่างและสัญญาณ แล้วแตะลิงก์ในอีเมลอีกครั้ง ลิงก์ใช้ได้ 24 ชั่วโมงสำหรับคำสั่งซื้อแบบชำระเงิน และ 1 ชั่วโมงสำหรับคำสั่งซื้อฟรี
- **ไฟล์ใหญ่เกินกว่าที่มือถือจะรับไหว** เปิดอีเมลฉบับเดียวกันบนคอมพิวเตอร์ ลิงก์ไม่ได้ผูกกับอุปกรณ์เครื่องใดเครื่องหนึ่ง
