# Baidu Netdisk เป็นภาษาไทย: คู่มือฉบับย่อทุกช่องและทุกปุ่มบนหน้าแชร์

หน้าแชร์ของ `pan.baidu.com` มีแต่ภาษาจีน ใช้คู่มือฉบับย่อนี้หาทางตามตำแหน่งบนหน้า ว่าแต่ละอย่างอยู่ตรงไหน ใช้ทำอะไร และคุณจำเป็นต้องใช้หรือไม่ เนื้อหาอธิบายหน้าเว็บตามที่เราเห็นเมื่อวันที่ 31 ตุลาคม 2026

เคล็ดลับ: ฟีเจอร์แปลภาษาของเบราว์เซอร์แปลข้อความยาวๆ ได้ถูกต้อง แต่มักแปลปุ่มที่มีคำเดียวผิดเพี้ยน อาศัยตำแหน่งจึงแม่นยำกว่า

## หน้าจอที่ 1: หน้าล็อก

คุณจะเห็นหน้าจอนี้ก็ต่อเมื่อลิงก์แชร์มีรหัสเข้าถึงเท่านั้น

| ตำแหน่ง | คืออะไร | ต้องใช้ไหม |
| --- | --- | --- |
| ตรงกลาง ช่องข้อความช่องเดียว | ช่องกรอกรหัส 4 ตัว | ใช่ |
| ปุ่มสีน้ำเงินใต้ช่องกรอก | เปิดลิงก์แชร์ | ใช่ |
| ช่องเพิ่มเติมข้างรูปภาพที่บิดเบี้ยว | แคปต์ชา พิมพ์ตัวอักษรที่เห็นตาม | เฉพาะเมื่อมีขึ้นมา |
| ลิงก์เล็กๆ ข้างชื่อผู้แชร์ | ส่งคำขอเป็นเพื่อนถึงผู้แชร์ | ไม่ |

ตัวพิมพ์ใหญ่หรือเล็กในรหัสไม่มีผล ทำรหัสหาย? อ่าน [รหัสเข้าถึง](extraction-code.md)

## หน้าจอที่ 2: รายการไฟล์

| ตำแหน่ง | คืออะไร | ต้องใช้ไหม |
| --- | --- | --- |
| บรรทัดหัวเรื่อง | ชื่อลิงก์แชร์ วันที่แชร์ วันหมดอายุ หรือ "ไม่มีวันหมดอายุ" | มีประโยชน์เพื่อดูว่าลิงก์จะใช้ได้อีกนานแค่ไหน |
| ด้านขวาของหัวเรื่อง | ติดตาม เปิดบนอุปกรณ์อื่น รายงาน | ไม่ |
| พื้นที่หลัก | ไฟล์และโฟลเดอร์ แต่ละรายการมีวันที่และช่องติ๊ก | เพื่อดูว่าข้างในมีอะไร |
| บรรทัดเหนือรายการ | เส้นทางกลับไปยังโฟลเดอร์ระดับบน | เมื่อคุณอยู่ในโฟลเดอร์ |
| ด้านล่าง ปุ่มสีน้ำเงิน | คัดลอกรายการที่ติ๊กไว้ไปยังพื้นที่จัดเก็บ Baidu ของคุณ | ต้องเข้าสู่ระบบ Baidu |
| ด้านล่าง ปุ่มสีอ่อนข้างกัน | ดาวน์โหลดรายการที่ติ๊กไว้ | ต้องเข้าสู่ระบบ Baidu และมักต้องใช้แอปบนคอมพิวเตอร์ด้วย |
| มุมขวาบน | เข้าสู่ระบบ สมัคร ดาวน์โหลดแอปบนคอมพิวเตอร์ ข้อเสนอสมาชิก | เฉพาะเมื่อมีบัญชี Baidu |

## ไม่มีบัญชีแล้วทำอะไรได้แค่ไหน

| การกระทำ | ไม่มีบัญชี Baidu |
| --- | --- |
| เปิดลิงก์ | ได้ |
| กรอกรหัส | ได้ |
| ดูไฟล์และโฟลเดอร์ | ได้ |
| บันทึกลงพื้นที่จัดเก็บของคุณ | ไม่ได้ ต้องเข้าสู่ระบบ |
| ดาวน์โหลด | ไม่ได้ ต้องเข้าสู่ระบบ จากนั้นมักต้องใช้แอปบนคอมพิวเตอร์ แล้วยังเจอความเร็วที่ช้าของบัญชีฟรีอีก |

สรุปคือหน้านี้ให้คุณดูได้ แต่เอาไปไม่ได้ ถ้าจะสมัครจากต่างประเทศ ดู [ไม่มีเบอร์โทรศัพท์จีน?](sign-up-phone-number.md)
