# Il link condiviso di Baidu Pan non funziona: cosa significa ogni messaggio

Apri un link `pan.baidu.com` e invece dell’elenco dei file compare un breve messaggio in cinese. Questa pagina ti spiega cosa significa e cosa puoi fare.

## Prima di tutto, controlla l’indirizzo

Un link valido ha la forma `https://pan.baidu.com/s/1…`, con una lunga sequenza di lettere e numeri dopo l’`1`. Una volta aperto, il browser può mostrare invece `https://pan.baidu.com/share/init?surl=…`. È la stessa condivisione.

Se il link si è troncato durante la copia, non si apre. Copialo di nuovo dal messaggio originale, fino all’ultimo carattere.

## Cosa ti sta dicendo la pagina

| Cosa vedi | Cosa significa | Chi può risolvere |
| --- | --- | --- |
| Un campo che chiede quattro caratteri | La condivisione è protetta. Ti serve il [codice di accesso](extraction-code.md) | Tu, con il codice ricevuto dal proprietario |
| Un messaggio che dice che sei arrivato tardi e la condivisione è stata annullata | Il proprietario ha smesso di condividere, oppure Baidu ha rimosso i file | Il proprietario |
| Un messaggio su violazioni o contenuti vietati | Baidu ha bloccato la condivisione | Nessuno: la condivisione resta bloccata |
| Un elenco di file con una nota che alcuni file sono stati filtrati | Una parte della condivisione viola le regole di Baidu ed è nascosta | Il proprietario |
| Un messaggio che la condivisione non è più valida | La condivisione è scaduta | Il proprietario |

La funzione di traduzione del browser ti aiuta a distinguere questi messaggi.

## Cosa fare

- **Il codice viene rifiutato:** confrontalo con il messaggio originale un carattere alla volta. Vedi [Codice di accesso](extraction-code.md).
- **La condivisione è annullata o scaduta:** chiedi al proprietario di condividere di nuovo i file e di mandarti il nuovo link e il nuovo codice.
- **La condivisione è bloccata:** non c’è niente da scaricare. Chiedi al proprietario se i file sono disponibili altrove.

## Controlla prima di pagare qualsiasi cosa

Prova il link nella [verifica del link di PanPull](https://panpull.com/it?utm_source=github&utm_medium=tutorial#link-checker). Il controllo è gratuito. Una condivisione leggibile torna con numero di file, dimensioni totali e prezzo. Se non si riesce a leggerla, ricevi invece un errore e non ti viene addebitato nulla.

Nessun servizio può recuperare una condivisione eliminata, annullata o bloccata. Se una condivisione non funziona su PanPull ma al proprietario si apre senza problemi, riprova un po’ più tardi: la causa può essere temporanea.
