# Baidu Pan senza il client desktop: scaricare dal browser su Windows, Mac e Linux

Premi il pulsante di download su una condivisione di Baidu Pan e un pop-up in cinese ti dice di installare prima Baidu Netdisk. Puoi ignorarlo. Ecco perché compare il pop-up, cosa ti chiederebbe il client e come ottenere gli stessi file usando soltanto il browser.

## Perché compare il pop-up

Il sito di Baidu consegna solo file singoli e piccoli, e solo agli utenti che hanno fatto l’accesso. Un file grande, una cartella o più file insieme vengono passati al client desktop. Per la maggior parte delle condivisioni significa: senza client, niente download.

## Client o browser?

| | Client Baidu Netdisk | Download dal browser con PanPull |
| --- | --- | --- |
| Installazione | Sì. Su Windows si avvia anche con il sistema e resta in background | Nessuna |
| Account Baidu | Obbligatorio | Non serve |
| Lingua | Solo cinese | 29 lingue |
| Velocità | Limitata con un account gratuito | Un normale download dallo spazio di archiviazione di PanPull |
| Costo | Gratis, oppure l’abbonamento SVIP a pagamento di Baidu | Gratis fino a 150 MB, poi in base alle dimensioni |
| Sistemi | Windows, macOS, Android, iOS; Linux come `.deb` o `.rpm` | Qualsiasi dispositivo con un browser |

Se il client ti serve davvero, scaricalo direttamente da Baidu su `pan.baidu.com/download` e non da un portale di download.

## Casi tipici per la strada del browser

- **PC dell’ufficio o dell’università:** non hai i permessi per installare programmi.
- **Linux:** preferisci non installare un pacchetto closed source per un solo file.
- **Il tuo Mac o PC:** non vuoi un altro programma che gira in background.

## Passaggi

1. Copia il link condiviso nella [verifica del link di PanPull](https://panpull.com/it?utm_source=github&utm_medium=tutorial#link-checker). Aggiungi il codice di accesso, se c’è.
2. Guarda il risultato: quanti file, quanto pesano in totale, quale prezzo.
3. Accedi a PanPull con un indirizzo email e una password e paga con PayPal o con carta, a meno che l’ordine non sia gratuito.
4. Aspetta l’email che ti avvisa che il download è pronto, poi apri il link che contiene. La pagina dell’ordine ha lo stesso link.

Una condivisione con un file ti dà quel file. Una condivisione con più file ti dà un unico archivio ZIP con dentro la struttura delle cartelle.

## Estrarre lo ZIP

| Sistema | Come |
| --- | --- |
| Windows | Clic destro sull’archivio, poi **Estrai tutto** |
| macOS | Doppio clic sull’archivio |
| Linux | Usa il gestore file, oppure scrivi `unzip` e il nome del file in un terminale |

Tieni libero sul disco circa il doppio delle dimensioni dell’archivio: una volta per lo ZIP, una volta per il contenuto.
