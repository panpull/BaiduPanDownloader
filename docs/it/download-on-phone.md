# Scaricare una condivisione Baidu Pan su iPhone o Android senza l’app di Baidu

Se apri un link di Baidu Pan sul cellulare, la pagina cerca di spostarti nell’app Baidu Netdisk, dove dovresti fare il login. C’è un’alternativa che resta in Safari, Chrome o qualunque browser tu usi sul telefono.

## Prima di iniziare

| Cosa controllare | Perché |
| --- | --- |
| Spazio libero | Una condivisione con più file arriva come un unico ZIP. Ti serve spazio per lo ZIP e, dopo l’estrazione, per il suo contenuto |
| Wi-Fi | I file grandi consumano in fretta i dati mobili |
| Schermo e browser | Alcuni telefoni mettono in pausa i download quando il browser va in background. Per i file grandi tienilo in primo piano |

## Passaggi

1. Nel browser del telefono apri [panpull.com](https://panpull.com/it?utm_source=github&utm_medium=tutorial#link-checker).
2. Tieni premuto sul campo di inserimento e incolla il link Baidu. Se hai copiato un intero messaggio di chat con il link e il codice di accesso, incollalo così com’è: vengono riconosciuti entrambi.
3. Leggi il risultato: numero di file, dimensioni totali, prezzo. Fino a 150 MB non paghi nulla.
4. Accedi con email e password. Per un ordine a pagamento, paga con PayPal o con carta.
5. Se vuoi, metti via il telefono. Quando i file sono pronti ricevi un’email.
6. Tocca il link nell’email, poi tocca **Scarica** nella pagina che si apre.

## Dove trovare il file dopo

| Telefono | Dove cercare |
| --- | --- |
| iPhone, iPad con Safari | L’icona a freccia accanto alla barra degli indirizzi, oppure l’app **File**, cartella **Download** |
| Android con Chrome | Menu del browser, poi **Download**; oppure la cartella **Download** nel gestore file |

Uno ZIP si apre con un tocco nell’app File (iPhone) o nel gestore file (Android).

## Se qualcosa va storto

- **Dopo aver toccato Scarica non succede niente.** Apri l’elenco dei download del browser prima di toccare di nuovo. Un secondo tocco può avviare una seconda copia.
- **Il download si interrompe.** Controlla spazio e segnale, poi tocca ancora il link nell’email. Resta valido 24 ore per un ordine a pagamento e 1 ora per uno gratuito.
- **Il file è troppo grande per il telefono.** Apri la stessa email su un computer. Il link non è legato a un solo dispositivo.
