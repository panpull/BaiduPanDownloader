# Как скачать с Baidu Pan (pan.baidu.com): инструкции на русском

Короткие практические инструкции для тех, кто живёт за пределами Китая, получил ссылку Baidu Pan (Baidu Netdisk) и не может добраться до файлов: нет аккаунта Baidu, нет китайского номера телефона, клиент только на китайском или скачивание еле ползёт.

Во всех инструкциях используется [PanPull](https://panpull.com/ru?utm_source=github&utm_medium=tutorial) — сайт, который скачивает файлы по ссылке Baidu за вас. Вы вставляете ссылку, видите размер и цену и скачиваете файлы в браузере. Ссылки объёмом до 150 MB — бесплатно.

## Быстрый старт

1. Откройте [проверку ссылки PanPull](https://panpull.com/ru?utm_source=github&utm_medium=tutorial#link-checker).
2. Вставьте ссылку `pan.baidu.com` и её код доступа.
3. Посмотрите количество файлов, общий размер и цену.
4. Войдите по адресу электронной почты, оплатите заказ, если он не бесплатный, и скачайте файлы.

## Обратите внимание

Используйте эти инструкции для своих файлов и для файлов, владелец которых согласился, что вы можете их получить. Никому не сообщайте пароль и cookies от Baidu: ни одному сайту и ни одной программе они не нужны.
