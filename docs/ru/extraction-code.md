# Код доступа Baidu Pan: 4 символа, без которых ссылка не откроется

Ссылка Baidu Pan — часто только половина того, что нужно. Вторая половина — код доступа: четыре буквы или цифры, которые тот, кто делится файлами, получает вместе со ссылкой. Пока не введён правильный код, защищённая ссылка не показывает список файлов.

## Где найти код

- **Рядом со ссылкой.** В сообщении или посте, где вы нашли ссылку, ищите четыре символа с подписью «code», «password» или «pwd» либо четыре символа после короткой китайской подписи.
- **Внутри ссылки.** Некоторые ссылки заканчиваются на `?pwd=` и четыре символа, например `?pwd=ab12`. Это и есть код.
- **У владельца.** Кода нигде не видно? Сообщить его может только тот, кто поделился файлами. Больше никто его не узнает.

## Как его ввести

**На странице Baidu:** защищённая ссылка открывается с одним полем ввода и синей кнопкой под ним. Введите код и нажмите кнопку. Заглавные и строчные буквы не различаются.

**На PanPull:** вставьте ссылку в [проверку ссылки](https://panpull.com/ru?utm_source=github&utm_medium=tutorial#link-checker).

- Если ссылка заканчивается на `?pwd=`, код будет взят из самой ссылки.
- Если вставить сообщение целиком, из него будут извлечены и ссылка, и код.
- В остальных случаях введите код в поле для кода. Код, введённый там, имеет приоритет, даже если в ссылке есть другой.

## Почему код не принимается

| Причина | Что делать |
| --- | --- |
| Вместе с кодом скопировался пробел перед ним или после него | Введите четыре символа вручную |
| Похожие символы, например 0 и O или 1, l и I | Сверьте с исходным сообщением символ за символом |
| Код относится к другой ссылке | Владелец прислал несколько ссылок: сопоставьте каждый код со своей ссылкой |
| Владелец создал новую ссылку | Берите самое свежее сообщение: старые ссылка и код больше не работают |
| Самой ссылки больше нет | Дело не в коде. См. [Ссылка не работает](share-link-not-working.md) |

Не подбирайте коды наугад. Попросите владельца прислать ссылку и код ещё раз.

## Чего код не умеет

Код только открывает страницу с файлами. Для скачивания всё равно нужен вход в Baidu или сервис, который скачает файлы за вас. PanPull не откроет защищённую ссылку без кода и не вернёт ссылку, которую владелец удалил.

Подробнее в блоге PanPull: [Код доступа Baidu: где его найти и почему он не подходит](https://panpull.com/ru/blog/baidu-share-extraction-code-checklist?utm_source=github&utm_medium=tutorial).
