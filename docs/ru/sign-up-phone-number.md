# Аккаунт Baidu без китайского номера телефона: можно ли зарегистрироваться из-за рубежа?

Baidu не создаст аккаунт без мобильного номера, на который может отправить SMS. Из-за этого многие за пределами Китая застревают, ещё ничего не скачав. Эта страница поможет за две минуты решить, стоит ли пытаться зарегистрироваться или можно обойтись без аккаунта.

## Шаг 1: есть ли в списке код вашей страны?

Для пользователей из-за рубежа у Baidu есть страница регистрации `passport.baidu.com/v2/?reg&overseas=1`. 31 октября 2026 года мы насчитали в её списке 161 код страны.

| Есть | Нет |
| --- | --- |
| США и Канада, Великобритания, Швейцария, Норвегия, Япония, Южная Корея, Вьетнам, Бразилия, Мексика, Австралия | Все страны ЕС, в том числе Германия, Франция, Италия, Испания, Нидерланды, Польша, Португалия и Ирландия |

Чтобы проверить свою страну, откройте страницу и нажмите **+86** слева от первого поля. В открывшемся списке есть все коды, которые принимает Baidu.

- Вашего кода нет: зарегистрироваться со своим номером не получится. Переходите к шагу 3.
- Ваш код есть: переходите к шагу 2.

## Шаг 2: что даёт аккаунт, а чего не даёт

| С бесплатным аккаунтом Baidu вы можете | Но по-прежнему не можете |
| --- | --- |
| Войти на странице ссылки | Читать сайт на русском: он остаётся китайским |
| Сохранять файлы, которыми с вами поделились, в свой Netdisk | Скачивать большие файлы или папки в браузере: Baidu отправляет вас в свою программу для компьютера |
| Запускать скачивание | Скачивать быстро: бесплатные аккаунты ограничены примерно 100–170 KB/s |

Ещё две вещи, которые стоит знать, прежде чем пробовать:

- Даже если ваша страна есть в списке, SMS иногда не приходит. Чаще всего это касается интернет-номеров (VoIP).
- Покупать готовые аккаунты или арендовать номера — плохая идея. Кто контролирует номер телефона, тот контролирует и аккаунт.

## Шаг 3: выберите

| Ваша ситуация | Лучший путь |
| --- | --- |
| Вам нужны файлы по одной ссылке, один раз | Обойдитесь без аккаунта. Следуйте шагам из инструкции [Как скачать без аккаунта Baidu](download-without-account.md) |
| Кода вашей страны нет | Обойдитесь без аккаунта |
| Вы будете пользоваться Baidu Pan регулярно, и ваш код есть в списке | Зарегистрируйтесь. В блоге PanPull китайская форма переведена поле за полем: [Регистрация в Baidu Netdisk за пределами Китая: какие номера подходят](https://panpull.com/ru/blog/baidu-netdisk-sign-up-outside-china?utm_source=github&utm_medium=tutorial) |
