# Baidu Netdisk на русском: шпаргалка по каждому полю и кнопке на странице ссылки

Страница с файлами `pan.baidu.com` существует только на китайском. С этой шпаргалкой можно ориентироваться по расположению элементов: где что находится, что делает и нужно ли оно вам. Страница описана такой, какой мы видели её 31 октября 2026 года.

Совет: встроенный переводчик браузера хорошо справляется с длинными текстами, но часто искажает кнопки из одного слова. Расположение надёжнее.

## Экран 1: замок

Этот экран появляется, только если у ссылки есть код доступа.

| Где | Что это | Нужно ли? |
| --- | --- | --- |
| По центру, единственное текстовое поле | Поле для кода из 4 символов | Да |
| Синяя кнопка под полем | Открывает ссылку | Да |
| Дополнительное поле рядом с искажённой картинкой | Капча: введите символы, которые видите | Только если появится |
| Небольшая ссылка рядом с именем владельца | Запрос на добавление владельца в друзья | Нет |

Регистр букв в коде не важен. Потеряли код? Прочитайте [Код доступа](extraction-code.md).

## Экран 2: файлы

| Где | Что это | Нужно ли? |
| --- | --- | --- |
| Строка заголовка | Название, дата публикации, дата окончания доступа или пометка «бессрочно» | Полезно, чтобы знать, сколько проживёт ссылка |
| Справа от заголовка | Подписаться, открыть на другом устройстве, пожаловаться | Нет |
| Основная область | Файлы и папки, у каждого элемента дата и флажок | Чтобы посмотреть, что внутри |
| Строка над списком | Путь назад к родительской папке | Когда вы внутри папки |
| Внизу, синяя кнопка | Копирует отмеченные элементы в ваше собственное хранилище Baidu | Нужен вход в Baidu |
| Внизу, бледная кнопка рядом | Скачивает отмеченные элементы | Нужен вход в Baidu, а часто и программа для компьютера |
| Правый верхний угол | Вход, регистрация, программа для компьютера, предложения подписки | Только с аккаунтом Baidu |

## Что получится сделать без аккаунта

| Действие | Без аккаунта Baidu |
| --- | --- |
| Открыть ссылку | Работает |
| Ввести код | Работает |
| Просмотреть файлы и папки | Работает |
| Сохранить в своё хранилище | Заблокировано: нужен вход |
| Скачать | Заблокировано: нужен вход, затем обычно программа для компьютера, а потом низкая скорость бесплатного аккаунта |

Иными словами, страница позволяет посмотреть, но не забрать. Как зарегистрироваться из-за границы, см. [Нет китайского номера телефона?](sign-up-phone-number.md)

## Короткий путь

Китайскую страницу можно вообще не трогать. Скопируйте ссылку в [PanPull](https://panpull.com/ru?utm_source=github&utm_medium=tutorial#link-checker): он покажет на вашем языке, сколько файлов по ссылке, какой у них общий размер и сколько будет стоить скачивание. Дальше вы скачиваете файлы в браузере.

Подробнее в блоге PanPull: [Baidu Netdisk на русском: как пользоваться страницей общего доступа](https://panpull.com/ru/blog/baidu-netdisk-in-english?utm_source=github&utm_medium=tutorial).
