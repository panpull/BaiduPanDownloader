# Baidu Pan без клиента для компьютера: скачивание в браузере на Windows, Mac и Linux

Вы нажимаете кнопку скачивания на странице Baidu Pan, и всплывающее окно на китайском требует сначала установить Baidu Netdisk. Его можно проигнорировать. Ниже объясняется, почему появляется это окно, что потребовал бы от вас клиент и как получить те же файлы с помощью одного только браузера.

## Почему появляется это окно

Сайт Baidu отдаёт только небольшие одиночные файлы и только тем, кто вошёл в аккаунт. Большой файл, папку или несколько файлов сразу передают клиенту для компьютера. Для большинства ссылок это значит: нет клиента — нет скачивания.

## Клиент или браузер?

| | Клиент Baidu Netdisk | Скачивание в браузере через PanPull |
| --- | --- | --- |
| Установка | Да. В Windows он к тому же запускается вместе с системой и работает в фоне | Не нужна |
| Аккаунт Baidu | Обязателен | Не нужен |
| Язык | Только китайский | 29 языков |
| Скорость | Ограничена на бесплатном аккаунте | Обычное скачивание из хранилища PanPull |
| Стоимость | Бесплатно или платная подписка Baidu SVIP | Бесплатно до 150 MB, дальше в зависимости от размера |
| Системы | Windows, macOS, Android, iOS; Linux в виде `.deb` или `.rpm` | Любая система с браузером |

Если клиент вам всё-таки нужен, скачивайте его у самого Baidu по адресу `pan.baidu.com/download`, а не с каталогов программ.

## Когда браузер удобнее

- **Офисный или университетский ПК:** у вас нет прав на установку программ.
- **Linux:** не хочется ставить пакет с закрытым кодом ради одного файла.
- **Собственный Mac или ПК:** не хочется заводить ещё одну программу, которая работает в фоне.

## Шаги

1. Скопируйте ссылку в [проверку ссылки PanPull](https://panpull.com/ru?utm_source=github&utm_medium=tutorial#link-checker). Добавьте код доступа, если он есть.
2. Посмотрите результат: сколько файлов, какой общий размер, какая цена.
3. Войдите в PanPull по адресу электронной почты и паролю и, если заказ не бесплатный, оплатите его через PayPal или картой.
4. Дождитесь письма о том, что скачивание готово, и откройте ссылку из него. Та же ссылка есть на странице заказа.

Если по ссылке один файл, вы получите именно этот файл. Если файлов несколько — один ZIP-архив со структурой папок внутри.

## Как распаковать ZIP

| Система | Как |
| --- | --- |
| Windows | Щёлкните архив правой кнопкой мыши и выберите **Извлечь все** |
| macOS | Дважды щёлкните архив |
| Linux | Воспользуйтесь файловым менеджером или введите в терминале `unzip` и имя файла |

Держите на диске свободное место примерно вдвое больше размера архива: для самого ZIP и для его содержимого.
