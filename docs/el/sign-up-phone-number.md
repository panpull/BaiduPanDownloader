# Λογαριασμός Baidu χωρίς κινεζικό αριθμό τηλεφώνου: μπορείτε να εγγραφείτε από το εξωτερικό;

Η Baidu δεν δημιουργεί λογαριασμό χωρίς αριθμό κινητού στον οποίο μπορεί να στείλει SMS. Αυτό σταματά πολλούς εκτός Κίνας πριν κατεβάσουν οτιδήποτε. Αυτή η σελίδα σάς βοηθά να αποφασίσετε σε δύο λεπτά: αξίζει να δοκιμάσετε να εγγραφείτε ή μπορείτε να προχωρήσετε χωρίς λογαριασμό;

## Βήμα 1: υπάρχει ο κωδικός της χώρας σας;

Η Baidu έχει σελίδα εγγραφής για χρήστες του εξωτερικού στο `passport.baidu.com/v2/?reg&overseas=1`. Στις 31 Οκτωβρίου 2026 μετρήσαμε 161 κωδικούς χώρας στη λίστα της.

| Υπάρχουν | Λείπουν |
| --- | --- |
| ΗΠΑ και Καναδάς, Ηνωμένο Βασίλειο, Ελβετία, Νορβηγία, Ιαπωνία, Νότια Κορέα, Βιετνάμ, Βραζιλία, Μεξικό, Αυστραλία | Όλες οι χώρες της ΕΕ, μεταξύ αυτών Γερμανία, Γαλλία, Ιταλία, Ισπανία, Ολλανδία, Πολωνία, Πορτογαλία και Ιρλανδία |

Λείπουν επίσης η Ελλάδα (+30) και η Κύπρος (+357).

Για να ελέγξετε τη δική σας χώρα, ανοίξτε τη σελίδα και πατήστε το **+86** αριστερά από το πρώτο πεδίο. Η λίστα που ανοίγει δείχνει όλους τους κωδικούς που δέχεται η Baidu.

- Ο κωδικός σας λείπει: δεν μπορείτε να εγγραφείτε με τον αριθμό σας. Πηγαίνετε στο βήμα 3.
- Ο κωδικός σας υπάρχει: πηγαίνετε στο βήμα 2.

## Βήμα 2: τι σας δίνει ένας λογαριασμός και τι όχι

| Με δωρεάν λογαριασμό Baidu μπορείτε | Εξακολουθείτε να μην μπορείτε |
| --- | --- |
| Να συνδεθείτε στη σελίδα κοινής χρήσης | Να διαβάσετε τον ιστότοπο στα ελληνικά ή στα αγγλικά: μένει στα κινεζικά |
| Να αποθηκεύσετε κοινόχρηστα αρχεία στο δικό σας Netdisk | Να κατεβάσετε μεγάλα αρχεία ή φακέλους στον browser: η Baidu σάς στέλνει στο πρόγραμμα για υπολογιστή |
| Να ξεκινήσετε λήψεις | Να κατεβάσετε γρήγορα: οι δωρεάν λογαριασμοί περιορίζονται σε περίπου 100 έως 170 KB/s |

Δύο ακόμη πράγματα πριν δοκιμάσετε:

- Ακόμη και με χώρα που υπάρχει στη λίστα, το SMS μερικές φορές δεν έρχεται. Αυτό συμβαίνει συνήθως με αριθμούς διαδικτύου (VoIP).
- Λογαριασμοί προς πώληση και νοικιασμένοι αριθμοί είναι κακή ιδέα. Όποιος ελέγχει τον αριθμό τηλεφώνου ελέγχει και τον λογαριασμό.
