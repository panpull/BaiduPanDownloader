# Πώς να κατεβάσετε από το Baidu Pan (pan.baidu.com): οδηγοί στα ελληνικά

Σύντομοι, πρακτικοί οδηγοί για όσους ζουν εκτός Κίνας, έλαβαν σύνδεσμο κοινής χρήσης Baidu Pan (Baidu Netdisk) και δεν μπορούν να πάρουν τα αρχεία: δεν έχουν λογαριασμό Baidu ούτε κινεζικό αριθμό τηλεφώνου, το πρόγραμμα είναι στα κινεζικά ή η λήψη σέρνεται.

Οι οδηγοί χρησιμοποιούν το [PanPull](https://panpull.com/el?utm_source=github&utm_medium=tutorial), έναν ιστότοπο που κατεβάζει για εσάς τα αρχεία ενός συνδέσμου Baidu. Επικολλάτε τον σύνδεσμο, βλέπετε το μέγεθος και την τιμή και κατεβάζετε στον browser σας. Οι σύνδεσμοι έως 150 MB είναι δωρεάν.

## Γρήγορη εκκίνηση

1. Ανοίξτε τον [έλεγχο συνδέσμου του PanPull](https://panpull.com/el?utm_source=github&utm_medium=tutorial#link-checker).
2. Επικολλήστε τον σύνδεσμο `pan.baidu.com` και τον κωδικό κοινής χρήσης του.
3. Δείτε τον αριθμό αρχείων, το συνολικό μέγεθος και την τιμή.
4. Συνδεθείτε με μια διεύθυνση email, πληρώστε αν η παραγγελία δεν είναι δωρεάν και κατεβάστε τα αρχεία.

## Προσοχή

Χρησιμοποιήστε αυτούς τους οδηγούς για δικά σας αρχεία και για αρχεία που ο κάτοχός τους συμφώνησε να τα έχετε. Μη δίνετε σε κανέναν τον κωδικό πρόσβασης και τα cookies της Baidu: κανένας ιστότοπος και κανένα πρόγραμμα δεν τα χρειάζεται.
