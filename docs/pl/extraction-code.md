# Kod dostępu Baidu Pan: 4 znaki potrzebne do otwarcia udostępnienia

Link z Baidu Pan to często tylko połowa tego, czego potrzebujesz. Druga połowa to kod dostępu: cztery litery lub cyfry, które osoba udostępniająca dostaje razem z linkiem. Zablokowane udostępnienie nie pokaże listy plików, dopóki nie wpiszesz poprawnego kodu.

## Gdzie znaleźć kod

- **Obok linku.** W wiadomości lub wpisie, w którym był link, poszukaj czterech znaków opisanych jako „code”, „password” lub „pwd” albo czterech znaków po krótkim chińskim napisie.
- **W samym linku.** Niektóre linki kończą się na `?pwd=` i cztery znaki, na przykład `?pwd=ab12`. To jest kod.
- **U właściciela.** Nigdzie nie widać kodu? Może ci go podać tylko osoba, która udostępniła pliki. Nikt inny nie jest w stanie go sprawdzić.

## Jak go wpisać

**Na stronie Baidu:** chronione udostępnienie otwiera się z jednym polem tekstowym i niebieskim przyciskiem pod nim. Wpisz kod i kliknij przycisk. Wielkość liter nie ma znaczenia.

**W PanPull:** wklej link do [narzędzia do sprawdzania linków](https://panpull.com/pl?utm_source=github&utm_medium=tutorial#link-checker).

- Jeśli link kończy się na `?pwd=`, kod zostanie odczytany z linku.
- Jeśli wkleisz całą wiadomość, link i kod zostaną z niej wyłowione.
- W pozostałych przypadkach wpisz kod w pole kodu dostępu. Kod wpisany tam ma pierwszeństwo, nawet jeśli link zawiera inny.

## Dlaczego kod jest odrzucany

| Przyczyna | Co zrobić |
| --- | --- |
| Przed kodem lub po nim skopiowała się spacja | Wpisz cztery znaki ręcznie |
| Podobnie wyglądające znaki, np. 0 i O albo 1, l i I | Porównuj z oryginalną wiadomością znak po znaku |
| Kod należy do innego linku | Właściciel wysłał kilka linków: dopasuj każdy kod do jego linku |
| Właściciel utworzył nowe udostępnienie | Użyj najnowszej wiadomości; stary link i kod już nie działają |
| Samo udostępnienie zniknęło | To nie wina kodu. Zobacz [Udostępniony link nie działa](share-link-not-working.md) |

Nie próbuj kodów na chybił trafił. Poproś właściciela, żeby wysłał link i kod jeszcze raz.

## Czego kod nie zrobi

Kod otwiera tylko stronę udostępnienia. Do pobrania nadal potrzebne jest logowanie do Baidu albo usługa, która pobierze udostępnione pliki za ciebie. PanPull nie otworzy chronionego udostępnienia bez kodu i nie przywróci udostępnienia, które właściciel usunął.
