# Jak pobrać pliki z Baidu Pan (pan.baidu.com): poradniki po polsku

Krótkie, praktyczne poradniki dla osób spoza Chin, które dostały udostępniony link z Baidu Pan (Baidu Netdisk) i nie mogą pobrać plików: nie mają konta Baidu ani chińskiego numeru telefonu, klient jest tylko po chińsku albo pobieranie ledwo się wlecze.

Poradniki korzystają z [PanPull](https://panpull.com/pl?utm_source=github&utm_medium=tutorial), strony, która pobiera udostępnione pliki z Baidu za ciebie. Wklejasz link, widzisz rozmiar i cenę, a potem pobierasz pliki w przeglądarce. Udostępnienia do 150 MB są bezpłatne.

## Szybki start

1. Otwórz [narzędzie PanPull do sprawdzania linków](https://panpull.com/pl?utm_source=github&utm_medium=tutorial#link-checker).
2. Wklej link `pan.baidu.com` i jego kod dostępu.
3. Sprawdź liczbę plików, łączny rozmiar i cenę.
4. Zaloguj się adresem e-mail, zapłać, jeśli zamówienie nie jest darmowe, i pobierz pliki.

## Ważne

Korzystaj z tych poradników tylko w przypadku własnych plików i plików, na których pobranie zgodził się ich właściciel. Nie podawaj nikomu hasła do Baidu ani plików cookie: żadna strona ani żaden program ich nie potrzebuje.
