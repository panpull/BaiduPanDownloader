# Cómo descargar de Baidu Pan en iPhone o Android sin la app de Baidu

Si abres un enlace de Baidu Pan en el móvil, la página intenta llevarte a la app de Baidu Netdisk, donde tendrías que iniciar sesión. Hay una forma de hacerlo sin salir de Safari, Chrome o el navegador móvil que uses.

## Antes de empezar

| Qué revisar | Por qué |
| --- | --- |
| Espacio libre | Un enlace con varios archivos llega como un único ZIP. Necesitas espacio para el ZIP y, después de descomprimirlo, para su contenido |
| Wi-Fi | Los archivos grandes consumen los datos móviles muy rápido |
| Pantalla y navegador | Algunos móviles pausan las descargas cuando el navegador pasa a segundo plano. Con archivos grandes, déjalo en primer plano |

## Pasos

1. En el navegador del móvil, abre [panpull.com](https://panpull.com/es?utm_source=github&utm_medium=tutorial#link-checker).
2. Mantén pulsado el campo de texto y pega el enlace de Baidu. Si copiaste un mensaje de chat completo con el enlace y el código de acceso, pégalo tal cual: se reconocen los dos.
3. Lee el resultado: número de archivos, tamaño total y precio. Hasta 150 MB no se cobra nada.
4. Inicia sesión con tu correo y tu contraseña. Si el pedido es de pago, paga con PayPal o con tarjeta.
5. Si quieres, deja el móvil. Te llegará un correo cuando los archivos estén listos.
6. Toca el enlace del correo y luego toca **Descargar** en la página que se abre.

## Dónde encontrar el archivo después

| Móvil | Dónde buscar |
| --- | --- |
| iPhone o iPad con Safari | El icono de la flecha junto a la barra de direcciones, o la app **Archivos**, carpeta **Descargas** |
| Android con Chrome | Menú del navegador y luego **Descargas**; o la carpeta **Descargas** del gestor de archivos |

Un ZIP se abre con un toque en la app Archivos (iPhone) o en el gestor de archivos (Android).

## Si algo falla

- **No pasa nada al tocar Descargar.** Abre la lista de descargas del navegador antes de volver a tocar. Un segundo toque puede iniciar una segunda copia.
- **La descarga se corta.** Revisa el espacio y la cobertura, y vuelve a tocar el enlace del correo. Sigue siendo válido 24 horas en un pedido de pago y 1 hora en uno gratuito.
- **El archivo es demasiado grande para el móvil.** Abre el mismo correo en un ordenador. El enlace no está ligado a un solo dispositivo.
