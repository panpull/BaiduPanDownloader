# Descargar de Baidu Pan sin el cliente de escritorio: desde el navegador en Windows, Mac y Linux

Pulsas el botón de descarga en un enlace de Baidu Pan y aparece una ventana en chino que te pide instalar primero Baidu Netdisk. Puedes ignorarla. Aquí verás por qué aparece esa ventana, qué te exigiría el cliente y cómo conseguir los mismos archivos solo con el navegador.

## Por qué aparece la ventana

La web de Baidu solo entrega archivos sueltos y pequeños, y solo a usuarios con la sesión iniciada. Un archivo grande, una carpeta o varios archivos a la vez pasan al cliente de escritorio. En la mayoría de los enlaces compartidos eso significa: sin cliente, no hay descarga.

## ¿Cliente o navegador?

| | Cliente de Baidu Netdisk | Descarga en el navegador con PanPull |
| --- | --- | --- |
| Instalación | Sí. En Windows, además, se inicia con el sistema y se queda en segundo plano | Ninguna |
| Cuenta de Baidu | Obligatoria | No hace falta |
| Idioma | Solo chino | 29 idiomas |
| Velocidad | Limitada en una cuenta gratuita | Una descarga normal desde el almacenamiento de PanPull |
| Coste | Gratis, o la suscripción SVIP de pago de Baidu | Gratis hasta 150 MB; después, según el tamaño |
| Sistemas | Windows, macOS, Android, iOS; Linux como `.deb` o `.rpm` | Cualquiera con navegador |

Si de verdad quieres el cliente, descárgalo del propio Baidu en `pan.baidu.com/download` y no de un portal de descargas.

## Casos típicos para usar el navegador

- **Ordenador de la oficina o de la universidad:** no tienes permisos para instalar programas.
- **Linux:** prefieres no instalar un paquete de código cerrado por un solo archivo.
- **Tu propio Mac o PC:** no quieres otro programa más funcionando en segundo plano.

## Pasos

1. Copia el enlace compartido en el [comprobador de enlaces de PanPull](https://panpull.com/es?utm_source=github&utm_medium=tutorial#link-checker). Añade el código de acceso si lo hay.
2. Revisa el resultado: cuántos archivos, cuánto ocupan en total y qué precio tienen.
3. Inicia sesión en PanPull con una dirección de correo y una contraseña, y paga con PayPal o con tarjeta, salvo que el pedido sea gratis.
4. Espera el correo que te avisa de que la descarga está lista y abre su enlace. La página de tu pedido tiene el mismo enlace.

Si el enlace contiene un solo archivo, recibes ese archivo. Si contiene varios, recibes un único archivo ZIP con la estructura de carpetas dentro.

## Descomprimir el ZIP

| Sistema | Cómo |
| --- | --- |
| Windows | Clic derecho en el archivo y luego **Extraer todo** |
| macOS | Doble clic en el archivo |
| Linux | Usa el gestor de archivos, o escribe `unzip` y el nombre del archivo en una terminal |

Deja libre en el disco unas dos veces el tamaño del ZIP: una vez para el ZIP y otra para su contenido.
