# El enlace compartido de Baidu Pan no funciona: qué significa cada mensaje

Abres un enlace de `pan.baidu.com` y, en lugar de una lista de archivos, aparece un mensaje corto en chino. Esta página te explica qué significa ese mensaje y qué puedes hacer.

## Primero, revisa la dirección

Un enlace en buen estado tiene la forma `https://pan.baidu.com/s/1…`, con una larga serie de letras y números después del `1`. Una vez abierto, el navegador puede mostrar `https://pan.baidu.com/share/init?surl=…` en su lugar. Es el mismo enlace compartido.

Si el enlace se cortó al copiarlo, no se abrirá. Vuelve a copiarlo del mensaje original, hasta el final.

## Qué te está diciendo la página

| Lo que ves | Qué significa | Quién puede solucionarlo |
| --- | --- | --- |
| Una casilla que pide cuatro caracteres | El enlace está protegido. Necesitas el [código de acceso](extraction-code.md) | Tú, con el código que te dé el propietario |
| Un mensaje de que llegas tarde y el enlace se ha cancelado | El propietario dejó de compartir, o Baidu eliminó los archivos | El propietario |
| Un mensaje sobre infracción o contenido prohibido | Baidu bloqueó el enlace | Nadie: el enlace sigue bloqueado |
| Una lista de archivos con una nota de que algunos se han filtrado | Una parte del contenido incumplía las normas de Baidu y está oculta | El propietario |
| Un mensaje de que el enlace ya no es válido | El enlace ha caducado | El propietario |

La función de traducción del navegador te ayuda a distinguir estos mensajes.

## Qué hacer

- **Se rechaza el código:** compáralo con el mensaje original carácter por carácter. Consulta [Código de acceso](extraction-code.md).
- **El enlace está cancelado o caducado:** pide al propietario que vuelva a compartir los archivos y te envíe el nuevo enlace y el código.
- **El enlace está bloqueado:** no hay nada que descargar. Pregunta al propietario si los archivos están disponibles en otro sitio.

## Compruébalo antes de pagar nada

Prueba el enlace en el [comprobador de enlaces de PanPull](https://panpull.com/es?utm_source=github&utm_medium=tutorial#link-checker). Comprobar es gratis. Si el enlace se puede leer, verás el número de archivos, el tamaño total y el precio. Si no, recibirás un error y no se te cobrará nada.

Ningún servicio puede recuperar un enlace compartido que se haya eliminado, cancelado o bloqueado. Si un enlace falla en PanPull pero al propietario se le abre sin problemas, vuelve a intentarlo un poco más tarde: puede que la causa sea temporal.
