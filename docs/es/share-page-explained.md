# Baidu Netdisk en español: guía rápida de la página compartida, cada casilla y cada botón

Una página compartida de `pan.baidu.com` solo existe en chino. Usa esta guía rápida para orientarte por la posición: dónde está cada cosa, para qué sirve y si la necesitas. Describe la página tal como la vimos el 31 de octubre de 2026.

Consejo: la función de traducción del navegador acierta con los textos largos, pero suele estropear los botones de una sola palabra. La posición es más fiable.

## Pantalla 1: el candado

Esta pantalla solo aparece cuando el enlace tiene código de acceso.

| Dónde | Qué es | ¿Lo necesitas? |
| --- | --- | --- |
| En el centro, una sola casilla de texto | Campo para el código de 4 caracteres | Sí |
| Botón azul debajo de la casilla | Abre el contenido compartido | Sí |
| Casilla adicional junto a una imagen distorsionada | Captcha: copia los caracteres que ves | Solo cuando aparece |
| Enlace pequeño junto al nombre de quien comparte | Solicitud de amistad a quien comparte | No |

En el código da igual usar mayúsculas o minúsculas. ¿Has perdido el código? Lee [Código de acceso](extraction-code.md).

## Pantalla 2: los archivos

| Dónde | Qué es | ¿Lo necesitas? |
| --- | --- | --- |
| Línea de cabecera | Título del enlace, fecha en que se compartió, fecha de caducidad o "no caduca" | Útil para ver cuánto dura el enlace |
| A la derecha de la cabecera | Suscribirse, abrir en otro dispositivo, denunciar | No |
| Zona principal | Archivos y carpetas, cada uno con una fecha y una casilla de selección | Para ver qué hay dentro |
| Línea encima de la lista | Ruta para volver a la carpeta superior | Cuando estás dentro de una carpeta |
| Abajo, botón azul | Copia los elementos marcados en tu propio almacenamiento de Baidu | Requiere iniciar sesión en Baidu |
| Abajo, botón pálido junto al anterior | Descarga los elementos marcados | Requiere iniciar sesión en Baidu y, a menudo, la app de escritorio |
| Esquina superior derecha | Iniciar sesión, registrarse, obtener la app de escritorio, ofertas de suscripción | Solo con una cuenta de Baidu |

## Hasta dónde llegas sin cuenta

| Acción | Sin cuenta de Baidu |
| --- | --- |
| Abrir el enlace | Funciona |
| Introducir el código | Funciona |
| Explorar archivos y carpetas | Funciona |
| Guardar en tu propio almacenamiento | Bloqueado: hay que iniciar sesión |
| Descargar | Bloqueado: hay que iniciar sesión, luego normalmente la app de escritorio y después la velocidad lenta de una cuenta gratuita |

Es decir, la página te deja mirar, pero no llevarte nada. Para registrarte desde el extranjero, consulta [¿Sin número de teléfono chino?](sign-up-phone-number.md)
