# Código de acceso de Baidu Pan: los 4 caracteres que necesitas para abrir un enlace compartido

Un enlace de Baidu Pan muchas veces es solo la mitad de lo que necesitas. La otra mitad es el código de acceso: cuatro letras o números que quien comparte recibe junto con el enlace. Un enlace protegido no muestra la lista de archivos hasta que introduces el código correcto.

## Dónde encontrar el código

- **Junto al enlace.** En el mensaje o la publicación donde encontraste el enlace, busca cuatro caracteres marcados como "code", "password" o "pwd", o una etiqueta corta en chino seguida de cuatro caracteres.
- **Dentro del enlace.** Algunos enlaces terminan en `?pwd=` y cuatro caracteres, por ejemplo `?pwd=ab12`. Ese es el código.
- **Preguntando al propietario.** ¿No ves ningún código? Solo quien compartió el enlace puede dártelo. Nadie más puede averiguarlo.

## Cómo introducirlo

**En la página de Baidu:** un enlace protegido se abre con una sola casilla de texto y un botón azul debajo. Escribe el código y haz clic en el botón. Da igual si usas mayúsculas o minúsculas.

**En PanPull:** pega el enlace en el [comprobador de enlaces](https://panpull.com/es?utm_source=github&utm_medium=tutorial#link-checker).

- Si el enlace termina en `?pwd=`, el código se lee del propio enlace.
- Si pegas el mensaje completo, se extraen de él tanto el enlace como el código.
- Si no, escribe el código en el campo del código. El código escrito ahí tiene prioridad, aunque el enlace contenga otro.

## Por qué se rechaza un código

| Causa | Qué hacer |
| --- | --- |
| Se copió un espacio antes o después del código | Escribe los cuatro caracteres a mano |
| Caracteres que se parecen, como 0 y O, o 1, l e I | Compáralos con el mensaje original carácter por carácter |
| El código es de otro enlace | El propietario envió varios enlaces: empareja cada código con su enlace |
| El propietario creó un enlace nuevo | Usa el mensaje más reciente; el enlace y el código antiguos ya no funcionan |
| El contenido compartido ya no existe | El problema no es el código. Consulta [El enlace compartido no funciona](share-link-not-working.md) |

No pruebes códigos al azar. Pide al propietario que te vuelva a enviar el enlace y el código.

## Lo que un código no puede hacer

Un código solo abre la página compartida. Para descargar sigue haciendo falta iniciar sesión en Baidu, o un servicio que descargue el contenido por ti. PanPull no puede abrir un enlace protegido sin su código, ni recuperar un enlace que el propietario haya eliminado.
