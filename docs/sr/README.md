# Како преузети датотеке са Baidu Pan (pan.baidu.com): упутства на српском

Кратка, практична упутства за људе ван Кине који су добили дељену везу за Baidu Pan (Baidu Netdisk), а не могу да дођу до датотека: немају Baidu налог ни кинески број телефона, клијент је на кинеском или преузимање иде пужевим кораком.

Упутства користе [PanPull](https://panpull.com/sr?utm_source=github&utm_medium=tutorial), сајт који уместо вас преузима Baidu дељење. Налепите везу, видите величину и цену и преузмете датотеке у прегледачу. Дељења до 150 MB су бесплатна.

## Брзи почетак

1. Отворите [PanPull проверу везе](https://panpull.com/sr?utm_source=github&utm_medium=tutorial#link-checker).
2. Налепите своју `pan.baidu.com` везу и њен приступни код.
3. Погледајте број датотека, укупну величину и цену.
4. Пријавите се адресом е-поште, платите ако поруџбина није бесплатна и преузмите датотеке.
