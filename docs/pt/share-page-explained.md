# Baidu Netdisk em português: guia rápido da página de compartilhamento, cada campo e cada botão

Uma página de compartilhamento do `pan.baidu.com` só existe em chinês. Use este guia rápido para se orientar pela posição: onde fica cada coisa, para que serve e se você precisa dela. Ele descreve a página como a vimos em 31 de outubro de 2026.

Dica: a tradução do navegador acerta os textos longos, mas costuma estragar os botões de uma palavra só. A posição é mais confiável.

## Tela 1: o cadeado

Esta tela só aparece quando o compartilhamento tem código de acesso.

| Onde | O que é | Você precisa? |
| --- | --- | --- |
| No centro, um único campo de texto | Campo para o código de 4 caracteres | Sim |
| Botão azul abaixo do campo | Abre o compartilhamento | Sim |
| Campo extra ao lado de uma imagem distorcida | Captcha: copie os caracteres que você vê | Só quando aparecer |
| Link pequeno ao lado do nome de quem compartilhou | Pedido de amizade para quem compartilhou | Não |

No código, tanto faz maiúscula ou minúscula. Perdeu o código? Leia [Código de acesso](extraction-code.md).

## Tela 2: os arquivos

| Onde | O que é | Você precisa? |
| --- | --- | --- |
| Linha do cabeçalho | Título do compartilhamento, data em que foi compartilhado, data de expiração ou "nunca expira" | Útil para saber quanto tempo o link dura |
| À direita do cabeçalho | Inscrever-se, abrir em outro aparelho, denunciar | Não |
| Área principal | Arquivos e pastas, cada um com uma data e uma caixa de seleção | Para ver o que tem dentro |
| Linha acima da lista | Caminho de volta para a pasta anterior | Quando você está dentro de uma pasta |
| Embaixo, botão azul | Copia os itens marcados para o seu próprio armazenamento no Baidu | Exige login no Baidu |
| Embaixo, botão claro ao lado | Baixa os itens marcados | Exige login no Baidu e, muitas vezes, o programa de computador |
| Canto superior direito | Login, cadastro, baixar o programa de computador, ofertas de assinatura | Só com uma conta no Baidu |

## Até onde você chega sem conta

| Ação | Sem conta no Baidu |
| --- | --- |
| Abrir o link | Funciona |
| Digitar o código | Funciona |
| Navegar pelos arquivos e pastas | Funciona |
| Salvar no seu próprio armazenamento | Bloqueado: exige login |
| Baixar | Bloqueado: exige login, depois em geral o programa de computador e, por fim, a velocidade lenta de conta gratuita |

Ou seja, a página deixa você olhar, mas não levar. Para se cadastrar do exterior, veja [Sem número de telefone chinês?](sign-up-phone-number.md)

## O atalho

Você pode deixar a página em chinês de lado. Cole o link no [PanPull](https://panpull.com/pt?utm_source=github&utm_medium=tutorial#link-checker): ele mostra, no seu idioma, quantos arquivos o compartilhamento tem, o tamanho total e quanto custa o download. Depois, você baixa pelo navegador.

Mais detalhes no blog do PanPull: [Baidu Netdisk em português ou inglês? Como usar a página de compartilhamento](https://panpull.com/pt/blog/baidu-netdisk-in-english?utm_source=github&utm_medium=tutorial).
