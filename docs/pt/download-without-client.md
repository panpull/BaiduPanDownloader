# Baidu Pan sem o programa: como baixar pelo navegador no Windows, Mac e Linux

Você clica no botão de download de um compartilhamento do Baidu Pan e aparece uma janela em chinês mandando instalar o Baidu Netdisk primeiro. Pode ignorar. Veja por que essa janela aparece, o que o programa exigiria de você e como pegar os mesmos arquivos usando só o navegador.

## Por que a janela aparece

O site do Baidu só entrega arquivos pequenos e avulsos, e só para quem fez login. Um arquivo grande, uma pasta ou mais de um arquivo de uma vez são enviados para o programa de computador. Na maioria dos compartilhamentos, isso quer dizer: sem programa, sem download.

## Programa ou navegador?

| | Programa do Baidu Netdisk | Download pelo navegador com o PanPull |
| --- | --- | --- |
| Instalação | Sim. No Windows, ele ainda abre junto com o sistema e fica rodando em segundo plano | Nenhuma |
| Conta no Baidu | Obrigatória | Não é necessária |
| Idioma | Só chinês | 29 idiomas |
| Velocidade | Limitada em uma conta gratuita | Um download normal a partir do armazenamento do PanPull |
| Custo | Grátis, ou a assinatura paga SVIP do Baidu | Grátis até 150 MB; depois, conforme o tamanho |
| Sistemas | Windows, macOS, Android, iOS; Linux como `.deb` ou `.rpm` | Qualquer um com navegador |

Se você quiser mesmo o programa, baixe direto do Baidu em `pan.baidu.com/download`, e não de um site de downloads.

## Casos típicos para usar o navegador

- **Computador do escritório ou da universidade:** você não tem permissão para instalar programas.
- **Linux:** você prefere não instalar um pacote de código fechado por causa de um arquivo.
- **Seu próprio Mac ou PC:** você não quer mais um programa rodando em segundo plano.

## Passo a passo

1. Cole o link compartilhado no [verificador de links do PanPull](https://panpull.com/pt?utm_source=github&utm_medium=tutorial#link-checker). Inclua o código de acesso, se houver.
2. Confira o resultado: quantos arquivos, qual o tamanho total e qual o preço.
3. Entre no PanPull com um endereço de e-mail e uma senha e pague com PayPal ou cartão, a não ser que o pedido seja grátis.
4. Espere o e-mail avisando que o download está pronto e abra o link dele. A página do seu pedido tem o mesmo link.

Um compartilhamento com um arquivo entrega esse arquivo. Um compartilhamento com vários arquivos entrega um único arquivo ZIP com a estrutura de pastas dentro.

## Descompactar o ZIP

| Sistema | Como |
| --- | --- |
| Windows | Clique com o botão direito no arquivo e depois em **Extrair Tudo** |
| macOS | Clique duas vezes no arquivo |
| Linux | Use o gerenciador de arquivos, ou digite `unzip` e o nome do arquivo em um terminal |

Deixe livre no disco cerca de duas vezes o tamanho do arquivo compactado: uma para o ZIP e outra para o conteúdo dele.
