# Código de acesso do Baidu Pan: os 4 caracteres para abrir um compartilhamento

Muitas vezes, um link do Baidu Pan é só metade do que você precisa. A outra metade é o código de acesso: quatro letras ou números que quem compartilha recebe junto com o link. Um compartilhamento protegido não mostra a lista de arquivos até que o código certo seja digitado.

## Onde encontrar o código

- **Ao lado do link.** Na mensagem ou no post onde você achou o link, procure quatro caracteres identificados como "code", "password" ou "pwd", ou um rótulo curto em chinês seguido de quatro caracteres.
- **Dentro do link.** Alguns links terminam com `?pwd=` e quatro caracteres, por exemplo `?pwd=ab12`. Esse é o código.
- **Com o dono.** Não achou nenhum código? Só quem compartilhou pode informar. Ninguém mais consegue descobrir.

## Como digitar o código

**Na página do Baidu:** um compartilhamento protegido abre com um único campo de texto e um botão azul embaixo. Digite o código e clique no botão. Tanto faz usar letras maiúsculas ou minúsculas.

**No PanPull:** coloque o link no [verificador de links](https://panpull.com/pt?utm_source=github&utm_medium=tutorial#link-checker).

- Se o link terminar com `?pwd=`, o código é lido do próprio link.
- Se você colar a mensagem inteira, o link e o código são identificados nela.
- Caso contrário, digite o código no campo do código. O código digitado ali tem prioridade, mesmo que o link traga outro.

## Por que um código é recusado

| Causa | O que fazer |
| --- | --- |
| Um espaço foi copiado antes ou depois do código | Digite os quatro caracteres à mão |
| Caracteres parecidos, como 0 e O, ou 1, l e I | Compare com a mensagem original, caractere por caractere |
| O código é de outro link | O dono mandou vários links: confira qual código é de qual link |
| O dono criou um novo compartilhamento | Use a mensagem mais recente; o link e o código antigos não funcionam mais |
| O próprio compartilhamento não existe mais | O problema não é o código. Veja [Link compartilhado não funciona](share-link-not-working.md) |

Não fique testando códigos aleatórios. Peça ao dono que mande o link e o código de novo.

## O que um código não faz

Um código só abre a página de compartilhamento. Para baixar, ainda é preciso fazer login no Baidu ou usar um serviço que baixe o compartilhamento para você. O PanPull não consegue abrir um compartilhamento protegido sem o código, nem trazer de volta um compartilhamento que o dono apagou.
