# Link compartilhado do Baidu Pan não funciona: o que cada mensagem quer dizer

Você abre um link do `pan.baidu.com` e, em vez de uma lista de arquivos, aparece uma mensagem curta em chinês. Esta página explica o que a mensagem quer dizer e o que você pode fazer.

## Primeiro, confira o endereço

Um link em bom estado tem o formato `https://pan.baidu.com/s/1…`, com uma longa sequência de letras e números depois do `1`. Depois de aberto, o navegador pode mostrar `https://pan.baidu.com/share/init?surl=…` no lugar. É o mesmo compartilhamento.

Se o link foi cortado na hora de copiar, ele não abre. Copie de novo da mensagem original, até o fim.

## O que a página está dizendo

| O que você vê | O que significa | Quem pode resolver |
| --- | --- | --- |
| Um campo que pede quatro caracteres | O compartilhamento é protegido. Você precisa do [código de acesso](extraction-code.md) | Você, com o código enviado pelo dono |
| Uma mensagem dizendo que você chegou tarde e o compartilhamento foi cancelado | O dono parou de compartilhar, ou o Baidu removeu os arquivos | O dono |
| Uma mensagem sobre violação ou conteúdo proibido | O Baidu bloqueou o compartilhamento | Ninguém: o compartilhamento continua bloqueado |
| Uma lista de arquivos com um aviso de que alguns foram filtrados | Parte do compartilhamento violou as regras do Baidu e está oculta | O dono |
| Uma mensagem dizendo que o compartilhamento não é mais válido | O compartilhamento expirou | O dono |

A função de tradução do navegador ajuda a diferenciar essas mensagens.

## O que fazer

- **O código é recusado:** compare com a mensagem original, caractere por caractere. Veja [Código de acesso](extraction-code.md).
- **O compartilhamento foi cancelado ou expirou:** peça ao dono que compartilhe os arquivos de novo e mande o novo link e o código.
- **O compartilhamento está bloqueado:** não há nada para baixar. Pergunte ao dono se os arquivos estão disponíveis em outro lugar.

## Verifique antes de pagar qualquer coisa

Teste o link no [verificador de links do PanPull](https://panpull.com/pt?utm_source=github&utm_medium=tutorial#link-checker). A verificação é grátis. Um compartilhamento que pode ser lido volta com a quantidade de arquivos, o tamanho total e o preço. Se não puder ser lido, você recebe uma mensagem de erro e nada é cobrado.

Nenhum serviço consegue trazer de volta um compartilhamento apagado, cancelado ou bloqueado. Se um compartilhamento falhar no PanPull, mas abrir normalmente para o dono, tente de novo um pouco mais tarde: a causa pode ser temporária.
