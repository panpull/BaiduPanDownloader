# Conta no Baidu sem número de telefone chinês: dá para se cadastrar do exterior?

O Baidu não cria conta sem um número de celular para o qual consiga mandar SMS. Isso trava muita gente fora da China antes mesmo de baixar qualquer coisa. Esta página ajuda você a decidir em dois minutos: vale a pena tentar se cadastrar ou dá para pular a conta?

## Passo 1: o código do seu país está disponível?

O Baidu tem uma página de cadastro para usuários no exterior em `passport.baidu.com/v2/?reg&overseas=1`. Em 31 de outubro de 2026, contamos 161 códigos de país na lista.

| Disponíveis | Ausentes |
| --- | --- |
| Estados Unidos e Canadá, Reino Unido, Suíça, Noruega, Japão, Coreia do Sul, Vietnã, Brasil, México, Austrália | Todos os países da UE, incluindo Alemanha, França, Itália, Espanha, Holanda, Polônia, Portugal e Irlanda |

Para quem lê em português: o Brasil está na lista; Portugal, como membro da UE, não.

Para conferir o seu país, abra a página e clique em **+86**, à esquerda do primeiro campo. A lista que abre mostra todos os códigos que o Baidu aceita.

- O seu código não está lá: não dá para se cadastrar com o seu número. Vá para o passo 3.
- O seu código está lá: vá para o passo 2.

## Passo 2: o que uma conta oferece e o que não oferece

| Com uma conta gratuita no Baidu, você pode | Você continua sem poder |
| --- | --- |
| Fazer login na página de compartilhamento | Ler o site em português ou inglês: ele continua em chinês |
| Salvar arquivos compartilhados no seu próprio Netdisk | Baixar arquivos grandes ou pastas pelo navegador: o Baidu manda você para o programa de computador |
| Iniciar downloads | Baixar rápido: contas gratuitas são limitadas a algo entre 100 e 170 KB/s |

Mais duas coisas para saber antes de tentar:

- Mesmo com um país da lista, às vezes o SMS não chega. Números de internet (VoIP) são as vítimas mais comuns.
- Comprar contas ou alugar números é má ideia. Quem controla o número de telefone controla a conta.

## Passo 3: escolha

| Sua situação | Melhor caminho |
| --- | --- |
| Você precisa dos arquivos de um único link, uma vez só | Pule a conta. Siga os passos de [Como baixar sem conta no Baidu](download-without-account.md) |
| O código do seu país não está na lista | Pule a conta |
| Você vai usar o Baidu Pan com frequência e o seu código está disponível | Cadastre-se. ## Pulando a conta

O [PanPull](https://panpull.com/pt?utm_source=github&utm_medium=tutorial#link-checker) busca o compartilhamento do lado dele e repassa os arquivos para você. Você informa o link compartilhado e um endereço de e-mail, nada do Baidu. Compartilhamentos de até 150 MB são grátis, e nos maiores você vê o preço antes de decidir.
