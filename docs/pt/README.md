# Como baixar do Baidu Pan (pan.baidu.com): tutoriais em português

Guias curtos e práticos para quem está fora da China, recebeu um link compartilhado do Baidu Pan (Baidu Netdisk) e não consegue pegar os arquivos: não tem conta no Baidu nem número de telefone chinês, o programa está em chinês ou o download se arrasta.

Os guias usam o [PanPull](https://panpull.com/pt?utm_source=github&utm_medium=tutorial), um site que baixa um compartilhamento do Baidu para você. Você cola o link, vê o tamanho e o preço e baixa pelo navegador. Compartilhamentos de até 150 MB são grátis.

## Começo rápido

1. Abra o [verificador de links do PanPull](https://panpull.com/pt?utm_source=github&utm_medium=tutorial#link-checker).
2. Cole o seu link do `pan.baidu.com` e o código de acesso dele.
3. Confira a quantidade de arquivos, o tamanho total e o preço.
4. Entre com um endereço de e-mail, pague se o pedido não for grátis e baixe.
