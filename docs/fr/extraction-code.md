# Code d’accès Baidu Pan : les 4 caractères pour ouvrir un partage

Un lien Baidu Pan ne suffit souvent pas. Il manque l’autre moitié : le code d’accès, quatre lettres ou chiffres que la personne qui partage obtient en même temps que le lien. Un partage verrouillé n’affiche aucune liste de fichiers tant que le bon code n’a pas été saisi.

## Où trouver le code

- **À côté du lien.** Dans le message ou la publication où vous avez trouvé le lien, cherchez quatre caractères précédés de « code », « password » ou « pwd », ou d’une courte mention en chinois.
- **Dans le lien.** Certains liens se terminent par `?pwd=` suivi de quatre caractères, par exemple `?pwd=ab12`. C’est le code.
- **Auprès du propriétaire.** Aucun code en vue ? Seule la personne qui a partagé peut vous le donner. Personne d’autre ne peut le retrouver.

## Comment le saisir

**Sur la page de Baidu :** un partage protégé s’ouvre sur un seul champ de saisie, avec un bouton bleu en dessous. Tapez le code et cliquez sur le bouton. Majuscules et minuscules sont traitées de la même façon.

**Sur PanPull :** mettez le lien dans le [vérificateur de lien](https://panpull.com/fr?utm_source=github&utm_medium=tutorial#link-checker).

- Si le lien se termine par `?pwd=`, le code est lu dans le lien.
- Si vous collez le message entier, le lien et le code en sont tous deux extraits.
- Sinon, tapez le code dans le champ prévu. Un code saisi à cet endroit est prioritaire, même si le lien en contient un autre.

## Pourquoi un code est refusé

| Cause | Que faire |
| --- | --- |
| Un espace a été copié avant ou après le code | Tapez les quatre caractères à la main |
| Des caractères qui se ressemblent, comme 0 et O, ou 1, l et I | Comparez avec le message d’origine, caractère par caractère |
| Le code correspond à un autre lien | Le propriétaire a envoyé plusieurs liens : associez chaque code à son lien |
| Le propriétaire a créé un nouveau partage | Utilisez le message le plus récent ; l’ancien lien et l’ancien code ne fonctionnent plus |
| Le partage lui-même a disparu | Le code n’y est pour rien. Voir [Lien de partage qui ne fonctionne pas](share-link-not-working.md) |

N’essayez pas des codes au hasard. Demandez au propriétaire de vous renvoyer le lien et le code.

## Ce qu’un code ne permet pas

Un code ouvre seulement la page de partage. Pour télécharger, il faut toujours une connexion Baidu, ou un service qui télécharge le partage pour vous. PanPull ne peut pas ouvrir un partage protégé sans son code, ni faire revenir un partage que le propriétaire a supprimé.
