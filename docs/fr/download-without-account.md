# Comment télécharger depuis Baidu Pan sans compte Baidu

Un ami, un message de forum ou la page d’un projet vous a donné un lien `pan.baidu.com`. La page s’ouvre, mais le bouton de téléchargement exige une connexion Baidu, et Baidu ne crée de compte que pour les numéros de téléphone auxquels il peut envoyer un SMS. La solution : laisser [PanPull](https://panpull.com/fr?utm_source=github&utm_medium=tutorial) récupérer le partage, puis télécharger le résultat dans votre navigateur. Pas de compte Baidu, pas d’appli Baidu et pas un mot de chinois.

## À préparer

| Élément | Détails |
| --- | --- |
| Lien de partage | Commence par `https://pan.baidu.com/s/` |
| Code d’accès | 4 lettres ou chiffres. Tous les partages n’en ont pas |
| Adresse e-mail | Pour votre connexion PanPull et le message « prêt » |

## Les sept étapes

1. **Allez sur le vérificateur de lien** de [panpull.com](https://panpull.com/fr?utm_source=github&utm_medium=tutorial#link-checker).
2. **Collez le lien.** Le code va dans le champ voisin. Raccourci : collez le message entier qui contenait le lien et le code, et les deux sont trouvés pour vous.
3. **Lisez le devis.** Il indique combien de fichiers contient le partage, leur taille totale et le prix. Cette vérification ne coûte rien, et la commande non plus si le partage fait 150 MB ou moins.
4. **Connectez-vous à PanPull.** Les nouveaux utilisateurs s’inscrivent avec une adresse e-mail et un mot de passe. Baidu n’intervient pas dans cette connexion.
5. **Payez, sauf si la commande est gratuite.** PayPal fonctionne, tout comme les cartes de débit et de crédit via PayPal.
6. **Laissez faire.** Vous pouvez fermer l’onglet. Une fois les fichiers préparés, PanPull vous envoie par e-mail le lien d’une page de téléchargement privée. La page de votre commande affiche aussi ce lien.
7. **Téléchargez.** Un fichier unique arrive tel quel. Plusieurs fichiers arrivent réunis dans un seul ZIP, avec leurs dossiers intacts.

## Les détails qui évitent les ennuis

- Une commande porte toujours sur le partage complet, avec tous ses fichiers.
- Quand un téléchargement payant est prêt, vous avez 24 heures pour le récupérer. Pour un téléchargement gratuit, c’est 1 heure. Un transfert interrompu peut être relancé pendant ce délai.
- Votre mot de passe Baidu et les cookies de votre navigateur ne sont jamais nécessaires. Un site ou un programme qui les demande ne mérite aucune confiance.
- Limitez-vous aux fichiers qui vous appartiennent ou que leur propriétaire a accepté de partager avec vous.
