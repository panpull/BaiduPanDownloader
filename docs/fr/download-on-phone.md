# Télécharger un partage Baidu Pan sur iPhone ou Android sans l’appli Baidu

Ouvrez un lien Baidu Pan sur un téléphone, et la page essaie de vous faire passer dans l’appli Baidu Netdisk, où il faudrait vous connecter. Il existe une autre solution, qui reste dans Safari, Chrome ou le navigateur mobile de votre choix.

## Avant de commencer

| À vérifier | Pourquoi |
| --- | --- |
| Espace libre | Un partage de plusieurs fichiers arrive sous forme d’un seul ZIP. Il faut de la place pour le ZIP et, une fois décompressé, pour son contenu |
| Wi-Fi | Les gros fichiers consomment vite les données mobiles |
| Écran et navigateur | Certains téléphones mettent les téléchargements en pause quand le navigateur passe en arrière-plan. Gardez-le au premier plan pour les gros fichiers |

## Étapes

1. Dans votre navigateur mobile, ouvrez [panpull.com](https://panpull.com/fr?utm_source=github&utm_medium=tutorial#link-checker).
2. Appuyez longuement sur le champ de saisie et collez le lien Baidu. Si vous avez copié tout un message contenant le lien et le code d’accès, collez-le tel quel : les deux sont reconnus.
3. Lisez le résultat : nombre de fichiers, taille totale, prix. Rien n’est facturé jusqu’à 150 MB.
4. Connectez-vous avec votre e-mail et un mot de passe. Pour une commande payante, réglez par PayPal ou par carte.
5. Vous pouvez ranger votre téléphone. Un e-mail vous prévient quand les fichiers sont prêts.
6. Touchez le lien de l’e-mail, puis **Télécharger** sur la page qui s’ouvre.

## Retrouver le fichier ensuite

| Téléphone | Où chercher |
| --- | --- |
| iPhone, iPad avec Safari | L’icône en forme de flèche à côté de la barre d’adresse, ou l’app **Fichiers**, dossier **Téléchargements** |
| Android avec Chrome | Menu du navigateur, puis **Téléchargements** ; ou le dossier **Téléchargements** de votre gestionnaire de fichiers |

Un ZIP s’ouvre d’une simple pression dans l’app Fichiers (iPhone) ou dans le gestionnaire de fichiers (Android).

## En cas de problème

- **Rien ne semble se passer après avoir touché Télécharger.** Ouvrez la liste des téléchargements du navigateur avant de réessayer. Une deuxième pression peut lancer une deuxième copie.
- **Le téléchargement s’interrompt.** Vérifiez l’espace disponible et le réseau, puis touchez à nouveau le lien de votre e-mail. Il reste valable 24 heures pour une commande payante et 1 heure pour une commande gratuite.
- **Le fichier est trop gros pour le téléphone.** Ouvrez le même e-mail sur un ordinateur. Le lien n’est pas lié à un appareil.
