# Baidu Pan sans le client : télécharger dans le navigateur sur Windows, Mac et Linux

Vous cliquez sur le bouton de téléchargement d’un partage Baidu Pan et une fenêtre en chinois vous demande d’installer d’abord Baidu Netdisk. Vous pouvez l’ignorer. Voici pourquoi cette fenêtre apparaît, ce que le client vous demanderait, et comment obtenir les mêmes fichiers avec votre seul navigateur.

## Pourquoi cette fenêtre apparaît

Le site de Baidu ne fournit que de petits fichiers isolés, et seulement aux utilisateurs connectés. Un gros fichier, un dossier ou plusieurs fichiers à la fois sont confiés au client de bureau. Pour la plupart des partages, cela veut dire : sans client, pas de téléchargement.

## Client ou navigateur ?

| --- | --- | --- |
| Installation | Oui. Sous Windows, il se lance aussi au démarrage et reste en arrière-plan | Aucune |
| Compte Baidu | Obligatoire | Inutile |

| Systèmes | Windows, macOS, Android, iOS ; Linux en `.deb` ou `.rpm` | Tout appareil doté d’un navigateur |

Si vous voulez quand même le client, prenez-le directement chez Baidu, sur `pan.baidu.com/download`, et non sur un portail de téléchargement.

## Cas typiques pour passer par le navigateur

- **PC de bureau ou d’université :** vous n’avez pas le droit d’installer des programmes.
- **Linux :** vous préférez ne pas installer un paquet propriétaire pour un seul fichier.
- **Votre propre Mac ou PC :** vous ne voulez pas d’un programme de plus qui tourne en arrière-plan.

## Étapes

1. Copiez le lien de partage dans le [vérificateur de lien PanPull](https://panpull.com/fr?utm_source=github&utm_medium=tutorial#link-checker). Ajoutez le code d’accès s’il y en a un.
2. Regardez le résultat : combien de fichiers, quelle taille totale, quel prix.
3. Connectez-vous à PanPull avec une adresse e-mail et un mot de passe, et payez par PayPal ou par carte, sauf si la commande est gratuite.
4. Attendez l’e-mail qui annonce que votre téléchargement est prêt, puis ouvrez son lien. La page de votre commande contient le même lien.

Un partage d’un seul fichier vous donne ce fichier. Un partage de plusieurs fichiers vous donne une seule archive ZIP qui conserve l’arborescence des dossiers.

## Décompresser le ZIP

| Système | Comment |
| --- | --- |
| Windows | Clic droit sur l’archive, puis **Extraire tout** |
| macOS | Double-clic sur l’archive |
| Linux | Passez par le gestionnaire de fichiers, ou tapez `unzip` suivi du nom du fichier dans un terminal |

Prévoyez un espace disque libre d’environ deux fois la taille de l’archive : une fois pour le ZIP, une fois pour son contenu.
