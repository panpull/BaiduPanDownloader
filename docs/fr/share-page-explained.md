# Baidu Netdisk en français : antisèche de la page de partage, chaque champ et chaque bouton

Une page de partage `pan.baidu.com` n’existe qu’en chinois. Cette antisèche vous aide à vous repérer par position : où se trouve chaque élément, à quoi il sert et si vous en avez besoin. Elle décrit la page telle que nous l’avons vue le 31 octobre 2026.

Astuce : la traduction automatique de votre navigateur rend bien les textes longs, mais elle massacre souvent les boutons d’un seul mot. La position est plus fiable.

## Écran 1 : le verrou

Cet écran n’apparaît que si le partage a un code d’accès.

| Où | Ce que c’est | En avez-vous besoin ? |
| --- | --- | --- |
| Au centre, un seul champ de texte | Champ pour le code de 4 caractères | Oui |
| Bouton bleu sous le champ | Ouvre le partage | Oui |
| Champ supplémentaire à côté d’une image déformée | Captcha : recopiez les caractères affichés | Seulement s’il apparaît |
| Petit lien à côté du nom de la personne qui partage | Demande d’ami envoyée à cette personne | Non |

Majuscules et minuscules n’ont pas d’importance dans le code. Code perdu ? Lisez [Code d’accès](extraction-code.md).

## Écran 2 : les fichiers

| Où | Ce que c’est | En avez-vous besoin ? |
| --- | --- | --- |
| Ligne d’en-tête | Titre du partage, date de partage, date d’expiration ou « n’expire jamais » | Utile pour savoir combien de temps le lien reste valable |
| À droite de l’en-tête | S’abonner, ouvrir sur un autre appareil, signaler | Non |
| Zone principale | Fichiers et dossiers, chacun avec une date et une case à cocher | Pour voir ce qu’il y a dedans |
| Ligne au-dessus de la liste | Chemin pour remonter au dossier parent | Quand vous êtes dans un dossier |
| En bas, bouton bleu | Copie les éléments cochés dans votre propre espace Baidu | Nécessite une connexion Baidu |
| En bas, bouton pâle juste à côté | Télécharge les éléments cochés | Nécessite une connexion Baidu, et souvent l’application de bureau |
| Coin supérieur droit | Connexion, inscription, application de bureau, offres d’abonnement | Seulement avec un compte Baidu |

## Jusqu’où aller sans compte

| Action | Sans compte Baidu |
| --- | --- |
| Ouvrir le lien | Possible |
| Saisir le code | Possible |
| Parcourir fichiers et dossiers | Possible |
| Enregistrer dans votre propre espace | Bloqué : connexion requise |
| Télécharger | Bloqué : connexion requise, puis en général l’application de bureau, puis la vitesse lente d’un compte gratuit |

La page vous laisse donc regarder, mais pas emporter. Pour vous inscrire depuis l’étranger, voir [Pas de numéro de téléphone chinois ?](sign-up-phone-number.md)
