# Comment télécharger depuis Baidu Pan (pan.baidu.com) : tutoriels en français

Des guides courts et concrets pour celles et ceux qui, hors de Chine, ont reçu un lien de partage Baidu Pan (Baidu Netdisk) et n’arrivent pas à récupérer les fichiers : pas de compte Baidu, pas de numéro de téléphone chinois, un client en chinois ou un téléchargement qui se traîne.

Ces guides s’appuient sur [PanPull](https://panpull.com/fr?utm_source=github&utm_medium=tutorial), un site qui télécharge un partage Baidu à votre place. Vous collez le lien, vous voyez la taille et le prix, puis vous téléchargez dans votre navigateur. Les partages jusqu’à 150 MB sont gratuits.

## Démarrage rapide

1. Ouvrez le [vérificateur de lien PanPull](https://panpull.com/fr?utm_source=github&utm_medium=tutorial#link-checker).
2. Collez votre lien `pan.baidu.com` et son code d’accès.
3. Regardez le nombre de fichiers, la taille totale et le prix.
4. Connectez-vous avec une adresse e-mail, payez si la commande n’est pas gratuite, puis téléchargez.
