# Baidu Pan extraction code: ang 4 na character na kailangan para mabuksan ang share

Madalas, kalahati lang ng kailangan mo ang Baidu Pan link. Ang kabilang kalahati ay ang extraction code: apat na letra o numero na natatanggap ng nag-share kasabay ng link. Walang lalabas na listahan ng file sa naka-lock na share hangga't hindi naipapasok ang tamang code.

## Saan makikita ang code

- **Katabi ng link.** Sa mensahe o post kung saan mo nakita ang link, hanapin ang apat na character na may label na "code", "password" o "pwd", o isang maikling Chinese na label na sinusundan ng apat na character.
- **Nasa loob ng link.** May mga link na nagtatapos sa `?pwd=` at apat na character, halimbawa `?pwd=ab12`. Iyon ang code.
- **Mula sa may-ari.** Walang makitang code? Ang nag-share lang ang makakapagsabi sa iyo. Wala nang ibang makakahanap nito.

## Paano ito ilagay

**Sa page ng Baidu:** bumubukas ang protektadong share na may iisang input box at isang asul na button sa ilalim nito. I-type ang code at i-click ang button. Pareho lang ang malalaki at maliliit na letra.

**Sa PanPull:** ilagay ang link sa [link checker](https://panpull.com/fil?utm_source=github&utm_medium=tutorial#link-checker).

- Kung nagtatapos ang link sa `?pwd=`, babasahin ang code mula sa link.
- Kung i-paste mo ang buong mensahe, kukunin mula rito ang link at ang code.
- Kung hindi, i-type ang code sa code field. Ang code na tina-type doon ang uunahin, kahit may ibang code sa link.

## Bakit tinatanggihan ang code

| Dahilan | Ano ang gagawin |
| --- | --- |
| May nakopyang space bago o pagkatapos ng code | I-type nang mano-mano ang apat na character |
| Mga character na magkamukha, gaya ng 0 at O, o 1, l at I | Ikumpara sa orihinal na mensahe nang isa-isang character |
| Para sa ibang link ang code | Ilang link ang ipinadala ng may-ari: itugma ang bawat code sa sarili nitong link |
| Gumawa ng bagong share ang may-ari | Gamitin ang pinakabagong mensahe; hindi na gumagana ang lumang link at code |
| Wala na mismo ang share | Hindi ang code ang problema. Tingnan ang [Hindi gumagana ang share link](share-link-not-working.md) |

Huwag manghula ng code. Hilingin sa may-ari na ipadala ulit ang link at ang code.

## Ang hindi kaya ng code

Binubuksan lang ng code ang share page. Para mag-download, kailangan pa rin ng Baidu login, o ng serbisyong magda-download ng share para sa iyo. Hindi kayang buksan ng PanPull ang protektadong share nang wala ang code nito, at hindi nito kayang ibalik ang share na binura na ng may-ari.
