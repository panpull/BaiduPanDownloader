# Baidu account nang walang Chinese na phone number: puwede ka bang mag-sign up mula sa ibang bansa?

Hindi gagawa ang Baidu ng account kung walang mobile number na kaya nitong padalhan ng text. Dito na humihinto ang maraming tao sa labas ng China bago pa sila makapag-download. Tutulungan ka ng page na ito na magpasya sa loob ng dalawang minuto: sulit bang subukang mag-sign up, o puwede mo nang laktawan ang account?

## Hakbang 1: nasa listahan ba ang country code mo?

May sign-up page ang Baidu para sa mga user sa ibang bansa sa `passport.baidu.com/v2/?reg&overseas=1`. Noong Oktubre 31, 2026, 161 na country code ang nabilang namin sa listahan nito.

| Mayroon | Wala |
| --- | --- |
| United States at Canada, United Kingdom, Switzerland, Norway, Japan, South Korea, Vietnam, Brazil, Mexico, Australia | Lahat ng bansa sa EU, kasama ang Germany, France, Italy, Spain, Netherlands, Poland, Portugal at Ireland |

Para suriin ang sarili mong bansa, buksan ang page at i-click ang **+86** sa kaliwa ng unang field. Ipapakita ng listahang bubukas ang bawat code na tinatanggap ng Baidu.

- Wala ang code mo: hindi ka makakapag-sign up gamit ang number mo. Pumunta sa hakbang 3.
- Nandoon ang code mo: pumunta sa hakbang 2.

## Hakbang 2: ano ang naibibigay ng account, at ano ang hindi

| Sa libreng Baidu account, puwede kang | Hindi mo pa rin magagawang |
| --- | --- |
| Mag-log in sa share page | Basahin ang site sa English: Chinese pa rin ito |
| Mag-save ng mga na-share na file sa sarili mong Netdisk | Mag-download ng malalaking file o folder sa browser: ipapasa ka ng Baidu sa desktop app nito |
| Magsimula ng download | Mag-download nang mabilis: nililimitahan ang mga libreng account sa humigit-kumulang 100 hanggang 170 KB/s |

Dalawa pang dapat malaman bago ka sumubok:

- Kahit nasa listahan ang bansa mo, minsan hindi dumarating ang text message. Kadalasang tinatamaan nito ang mga number na nakabase sa internet (VoIP).
- Masamang ideya ang bumili ng account o umupa ng number. Kung sino ang may hawak ng phone number, siya ang may hawak ng account.

## Hakbang 3: pumili

| Sitwasyon mo | Pinakamainam na paraan |

| Wala ang country code mo | Laktawan ang account |
| Regular mong gagamitin ang Baidu Pan at nasa listahan ang code mo | Mag-sign up.
