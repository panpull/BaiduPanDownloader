# Hindi gumagana ang Baidu Pan share link: ano ang ibig sabihin ng bawat mensahe

Binuksan mo ang isang `pan.baidu.com` link at maikling mensahe sa Chinese ang lumabas sa halip na listahan ng file. Ipinapaliwanag ng page na ito kung ano ang ibig sabihin ng mensahe at ano ang puwede mong gawin.

## Una, suriin ang address

Ganito ang anyo ng maayos na link: `https://pan.baidu.com/s/1…`, may mahabang hanay ng mga letra at numero pagkatapos ng `1`. Kapag nabuksan, puwedeng `https://pan.baidu.com/share/init?surl=…` ang ipakita ng browser. Iisang share pa rin iyon.

Kung naputol ang link noong kinopya, hindi ito bubukas. Kopyahin ito ulit mula sa orihinal na mensahe, hanggang sa pinakadulo.

## Ano ang sinasabi ng page

| Ang nakikita mo | Ang ibig sabihin | Sino ang makakaayos |
| --- | --- | --- |
| Isang kahon na humihingi ng apat na character | Protektado ang share. Kailangan mo ang [extraction code](extraction-code.md) | Ikaw, gamit ang code mula sa may-ari |
| Mensaheng huli ka na at kinansela ang share | Itinigil ng may-ari ang pag-share, o tinanggal ng Baidu ang mga file | Ang may-ari |
| Mensahe tungkol sa paglabag sa karapatan o ipinagbabawal na content | Hinarang ng Baidu ang share | Wala: mananatiling harang ang share |
| Listahan ng file na may paalalang may mga file na sinala | Lumabag sa patakaran ng Baidu ang bahagi ng share at nakatago ito | Ang may-ari |
| Mensaheng hindi na valid ang share | Nag-expire na ang share | Ang may-ari |

Makakatulong ang translate feature ng browser mo para matukoy kung alin sa mga mensaheng ito ang nakikita mo.

## Ano ang gagawin

- **Tinatanggihan ang code:** ikumpara ito sa orihinal na mensahe nang isa-isang character. Tingnan ang [Extraction code](extraction-code.md).
- **Kinansela o nag-expire ang share:** hilingin sa may-ari na i-share ulit ang mga file at ipadala sa iyo ang bagong link at code.
- **Hinarang ang share:** walang mada-download. Tanungin ang may-ari kung may iba pang mapagkukunan ng mga file.

## Suriin bago magbayad ng kahit ano

Subukan ang link sa [link checker ng PanPull](https://panpull.com/fil?utm_source=github&utm_medium=tutorial#link-checker). Libre ang pagsusuri. Kapag nababasa ang share, lalabas ang bilang ng file, kabuuang laki at presyo nito. Kung hindi ito mabasa, error ang makukuha mo, at walang sisingilin.

Walang serbisyong makakapagbalik ng share na binura, kinansela o hinarang. Kung pumapalya ang share sa PanPull pero maayos itong bumubukas para sa may-ari, subukan ulit pagkalipas ng kaunting oras: puwedeng pansamantala lang ang dahilan.
