# Paano mag-download sa Baidu Pan (pan.baidu.com): mga tutorial sa Filipino

Maiikli at praktikal na gabay para sa mga nasa labas ng China na nakatanggap ng Baidu Pan (Baidu Netdisk) share link pero hindi makuha ang mga file: walang Baidu account, walang Chinese na phone number, Chinese lang ang client, o sobrang bagal ng download.

Ginagamit ng mga gabay ang [PanPull](https://panpull.com/fil?utm_source=github&utm_medium=tutorial), isang website na nagda-download ng Baidu share para sa iyo. I-paste mo ang link, tingnan ang laki at presyo, at mag-download sa browser mo. Libre ang mga share na hanggang 150 MB.

## Mabilis na simula

1. Buksan ang [link checker ng PanPull](https://panpull.com/fil?utm_source=github&utm_medium=tutorial#link-checker).
2. I-paste ang `pan.baidu.com` link mo at ang extraction code nito.
3. Tingnan ang bilang ng file, ang kabuuang laki at ang presyo.
4. Mag-sign in gamit ang email address, magbayad kung hindi libre ang order, at mag-download.
