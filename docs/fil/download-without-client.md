# Baidu Pan nang walang desktop client: mag-download sa browser sa Windows, Mac at Linux

Pinindot mo ang download button sa isang Baidu Pan share, at may lumabas na Chinese na pop-up na nagsasabing i-install muna ang Baidu Netdisk. Puwede mo itong balewalain. Narito kung bakit lumalabas ang pop-up, ano ang hihingin sa iyo ng client, at paano makuha ang parehong mga file gamit lang ang browser mo.

## Bakit lumalabas ang pop-up

Maliliit at iisang file lang ang ibinibigay ng website ng Baidu, at sa mga naka-log in na user lang. Ang malaking file, folder, o higit sa isang file nang sabay ay ipinapasa sa desktop client. Para sa karamihan ng share, ibig sabihin nito: walang client, walang download.

## Client o browser?

| | Baidu Netdisk client | Pag-download sa browser gamit ang PanPull |
| --- | --- | --- |
| Pag-install | Oo. Sa Windows, sumasabay pa itong magbukas sa system at nananatili sa background | Wala |
| Baidu account | Kailangan | Hindi kailangan |
| Wika | Chinese lang | 29 na wika |
| Bilis | May limit sa libreng account | Karaniwang download mula sa storage ng PanPull |
| Gastos | Libre, o ang bayad na SVIP membership ng Baidu | Libre hanggang 150 MB, pagkatapos ay ayon sa laki |
| Mga system | Windows, macOS, Android, iOS; Linux bilang `.deb` o `.rpm` | Kahit anong may browser |

Kung gusto mo talaga ang client, kunin ito mismo sa Baidu sa `pan.baidu.com/download` at hindi sa isang download portal.

## Mga karaniwang dahilan para gamitin ang browser

- **PC sa opisina o unibersidad:** wala kang pahintulot na mag-install ng program.
- **Linux:** ayaw mong mag-install ng closed-source na package para sa iisang file.
- **Sarili mong Mac o PC:** ayaw mo ng isa na namang program na tumatakbo sa background.

## Mga hakbang

1. Kopyahin ang share link papunta sa [link checker ng PanPull](https://panpull.com/fil?utm_source=github&utm_medium=tutorial#link-checker). Idagdag ang extraction code kung mayroon.
2. Tingnan ang resulta: ilang file, gaano kalaki ang kabuuan, magkano ang presyo.
3. Mag-log in sa PanPull gamit ang email address at password, at magbayad sa PayPal o card maliban kung libre ang order.
4. Hintayin ang email na nagsasabing handa na ang download mo, saka buksan ang link nito. Nasa order page mo rin ang parehong link.

Kung isang file ang nasa share, iyon mismo ang makukuha mo. Kung ilang file, isang ZIP archive ang makukuha mo, at nasa loob nito ang ayos ng mga folder.

## Pag-extract ng ZIP

| System | Paano |
| --- | --- |
| Windows | I-right click ang archive, saka piliin ang **Extract All** |
| macOS | I-double click ang archive |
| Linux | Gamitin ang file manager, o i-type ang `unzip` at ang pangalan ng file sa terminal |

Maglaan ng bakanteng espasyo sa disk na mga dalawang beses ng laki ng archive: isa para sa ZIP, isa para sa laman nito.
