# FAQ sa pag-download sa Baidu Pan: account, kaligtasan, bilis at presyo

Maiikling sagot sa mga madalas itanong ng mga nakakatanggap ng `pan.baidu.com` link sa labas ng China.

## Ano ang Baidu Pan?

Isang online storage service ng Baidu, na ginagamit sa China gaya ng paggamit sa Google Drive o Dropbox sa ibang bansa. Sa English, opisyal itong tinatawag na Baidu Netdisk. Puwede mo ring makita ang mga lumang pangalan na Baidu Cloud at Baidu Yun; iisa lang ang tinutukoy ng lahat ng ito. Higit pa: [Ano ang Baidu Pan?](https://panpull.com/fil/blog/what-is-baidu-pan?utm_source=github&utm_medium=tutorial)

## Puwede ba akong mag-download nang walang Baidu account?

Hindi sa mismong page ng Baidu, kung saan login ang unang hakbang sa pag-download. Sa [PanPull](https://panpull.com/fil?utm_source=github&utm_medium=tutorial#link-checker), puwede, dahil ito ang nagda-download ng share para sa iyo. Tingnan ang [Paano mag-download nang walang Baidu account](download-without-account.md).

## Puwede ba akong mag-sign up nang walang Chinese na phone number?

Minsan. Depende ito sa country code mo, at walang bansa sa EU ang nasa listahan ng Baidu. Tingnan ang [Walang Chinese na phone number?](sign-up-phone-number.md)

## Ligtas bang buksan ang pan.baidu.com link?

Oo. Sariling website ito ng Baidu. Nasa mga file ang panganib, dahil kahit sino ay puwedeng mag-share ng kahit ano. I-scan ang mga dina-download mo, at lalo kang mag-ingat sa mga program at installer. Higit pa: [Ligtas ba ang Baidu Pan?](https://panpull.com/fil/blog/is-baidu-pan-safe?utm_source=github&utm_medium=tutorial)

## Kailangan ko bang ibigay sa PanPull ang Baidu password ko?

Hindi. Gumagana ang PanPull gamit ang share link at ang extraction code nito. Hindi nito kailanman hinihingi ang Baidu password o cookies mo. Huwag ibigay ang mga ito sa kahit anong website o program.

## Ano ang extraction code?

Apat na letra o numero na nagbubukas ng share. Ipinapadala ito ng nag-share kasama ng link. Tingnan ang [Extraction code](extraction-code.md).

## Bakit sobrang bagal ng Baidu download ko?

Nililimitahan ang mga libreng account sa humigit-kumulang 100 hanggang 170 KB/s. Tingnan ang [Gaano katagal ang download](slow-download-speed.md).

## Magkano ang PanPull?

Libre ang mga share na hanggang 150 MB. Lampas diyan, $0.98 ang unang GB at $0.48 ang bawat dagdag na GB, at may maximum na presyo para sa malalaking share. Tingnan ang [Presyo at libreng download](pricing-and-free-downloads.md).

## Puwede ba akong pumili ng ilang file lang mula sa share?

Hindi pa sa ngayon: kinukuha ng isang order ang buong share. Bago magbayad, makikita mo kung ilang file iyon at gaano kalaki ang pinagsama-samang laki nila. Ang higit sa isang file ay darating bilang iisang ZIP, at buo pa rin ang mga folder.

## Gaano katagal ko puwedeng i-download ang mga file ko?

Sa loob ng 24 oras mula nang maging handa ang bayad na download, at 1 oras para sa libre. Pagkatapos nito, binubura ang mga inihandang file.

## Paano kung pumalya ang download?

Sasabihin ito ng order page at may button na "Subukang muli". Ayaw pa rin? Magpadala ng ulat ng problema at banggitin ang order number mo. Ibabalik sa iyo ang perang ibinayad para sa order na hindi maihahatid.

## Gumagana ba ang PanPull sa TeraBox o sa ibang cloud drive?

Hindi. Sa `pan.baidu.com` share link lang ito gumagana. Hiwalay na serbisyo ang TeraBox na may sarili nitong mga link.

## Magagamit ko ba ito sa phone, Mac o Linux?

Oo. Sa browser nangyayari ang lahat. Tingnan ang [Mag-download sa iPhone o Android](download-on-phone.md) at [Mag-download nang hindi nag-i-install ng client](download-without-client.md).

## Aling mga file ang puwede kong i-download?

Ang sarili mong mga file, at ang mga file na pinayagan ng may-ari na mapasaiyo.
