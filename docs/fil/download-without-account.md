# Paano mag-download sa Baidu Pan nang walang Baidu account

May nagbigay sa iyo ng `pan.baidu.com` link: isang kaibigan, isang post sa forum o isang project page. Bumubukas ang page, pero humihingi ng Baidu login ang download button, at nagbibigay lang ang Baidu ng account sa mga phone number na kaya nitong padalhan ng text. Ang solusyon: hayaang kunin ng [PanPull](https://panpull.com/fil?utm_source=github&utm_medium=tutorial) ang share at i-download ang resulta sa browser mo. Walang Baidu account, walang Baidu app at walang Chinese na kailangan.

## Ihanda ang mga ito

| Kailangan | Detalye |
| --- | --- |
| Share link | Nagsisimula sa `https://pan.baidu.com/s/` |
| Extraction code | 4 na letra o numero. Hindi lahat ng share ay mayroon nito |
| Email address | Para sa PanPull login mo at sa mensaheng "handa na" |

## Ang pitong hakbang

1. **Pumunta sa link checker** sa [panpull.com](https://panpull.com/fil?utm_source=github&utm_medium=tutorial#link-checker).
2. **I-paste ang link.** Sa field sa tabi nito ilalagay ang code. Mas mabilis na paraan: i-paste ang buong mensaheng may link at code, at awtomatikong makikita ang dalawa.
3. **Basahin ang quote.** Nakalista rito kung ilang file ang nasa share, ang pinagsamang laki nila at ang presyo. Wala kang babayaran sa pagsusuring ito, at wala ring babayaran kung 150 MB o mas maliit ang share.
4. **Mag-log in sa PanPull.** Nagrerehistro ang mga bagong user gamit ang email address at password. Walang kinalaman ang Baidu sa login na ito.
5. **Magbayad, maliban kung libre ang order.** Puwede ang PayPal, pati debit at credit card sa pamamagitan ng PayPal.
6. **Hayaan itong gumana.** Puwede mong isara ang tab. Mag-e-email sa iyo ang PanPull ng link papunta sa pribadong download page kapag naihanda na ang mga file. Makikita rin ang link na iyon sa order page mo.
7. **Mag-download.** Kung isang file, iyon mismo ang darating. Kung marami, darating ang mga ito sa iisang ZIP, buo pa rin ang mga folder.

## Mga detalyeng makakaiwas sa abala

- Laging kinukuha ng isang order ang buong share, kasama ang lahat ng file nito.
- Kapag handa na ang bayad na download, may 24 oras ka para kunin ito. Sa libre, 1 oras. Puwedeng ulitin ang naputol na transfer sa loob ng panahong iyon.
- Hindi kailanman kailangan ang Baidu password mo o ang cookies ng browser mo. Huwag pagkatiwalaan ang site o program na humihingi ng mga ito.
- Gamitin lang ito para sa mga file na sa iyo o na pumayag ang may-ari na i-share sa iyo.
