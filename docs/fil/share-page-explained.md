# Baidu Netdisk sa Filipino: gabay sa bawat kahon at button ng share page

Sa Chinese lang available ang `pan.baidu.com` share page. Gamitin ang gabay na ito para makagalaw ayon sa posisyon: kung nasaan ang bawat bahagi, ano ang ginagawa nito, at kung kailangan mo ito. Inilalarawan nito ang page ayon sa nakita namin noong Oktubre 31, 2026.

Tip: tama ang pagsasalin ng translate function ng browser mo sa mahahabang teksto, pero madalas nitong guluhin ang mga button na iisang salita lang. Mas maaasahan ang posisyon.

## Screen 1: ang lock

Lalabas lang ang screen na ito kapag may extraction code ang share.

| Saan | Ano ito | Kailangan mo ba ito? |
| --- | --- | --- |
| Gitna, iisang text box | Field para sa code na may 4 na character | Oo |
| Asul na button sa ilalim ng kahon | Binubuksan ang share | Oo |
| Dagdag na kahon sa tabi ng baluktot na larawan | Captcha: kopyahin ang mga character na nakikita mo | Kapag lumabas lang ito |
| Maliit na link sa tabi ng pangalan ng nag-share | Friend request sa nag-share | Hindi |

Hindi mahalaga sa code kung malaki o maliit ang letra. Nawala ang code? Basahin ang [Extraction code](extraction-code.md).

## Screen 2: ang mga file

| Saan | Ano ito | Kailangan mo ba ito? |
| --- | --- | --- |
| Linya ng header | Pamagat ng share, petsa ng pag-share, petsa ng pag-expire o "hindi nag-e-expire" | Para malaman kung hanggang kailan gagana ang link |
| Kanan ng header | Subscribe, buksan sa ibang device, mag-report | Hindi |
| Pangunahing bahagi | Mga file at folder, bawat isa may petsa at check box | Para makita ang laman |
| Linya sa itaas ng listahan | Daan pabalik sa parent folder | Kapag nasa loob ka ng folder |
| Ibaba, asul na button | Kopyahin ang mga naka-check sa sarili mong Baidu storage | Kailangan ng Baidu login |
| Ibaba, maputlang button sa tabi nito | I-download ang mga naka-check | Kailangan ng Baidu login, at madalas ng desktop app |
| Kanang itaas na sulok | Mag-log in, mag-sign up, kunin ang desktop app, mga alok ng membership | Kung may Baidu account lang |

## Hanggang saan ka makakarating nang walang account

| Gagawin | Nang walang Baidu account |
| --- | --- |
| Buksan ang link | Gumagana |
| Ilagay ang code | Gumagana |
| Tingnan ang mga file at folder | Gumagana |
| I-save sa sarili mong storage | Harang: kailangan ng login |
| Mag-download | Harang: login, kadalasan pagkatapos ay ang desktop app, at mabagal na bilis ng libreng account |

Kaya hinahayaan ka ng page na tumingin, pero hindi kumuha. Para mag-sign up mula sa ibang bansa, tingnan ang [Walang Chinese na phone number?](sign-up-phone-number.md)
