# Paano mag-download ng Baidu Pan share sa iPhone o Android nang walang Baidu app

Kapag binuksan mo ang Baidu Pan link sa cellphone, pilit kang inililipat ng page sa Baidu Netdisk app, kung saan kailangan mong mag-log in. May paraan na hindi ka aalis sa Safari, Chrome o kung anumang mobile browser ang gamit mo.

## Bago ka magsimula

| Suriin | Bakit |
| --- | --- |
| Bakanteng storage | Ang share na may ilang file ay darating bilang iisang ZIP. Kailangan mo ng espasyo para sa ZIP at, pagkatapos i-extract, para sa laman nito |
| Wi-Fi | Mabilis maubos ng malalaking file ang mobile data |
| Screen at browser | May mga phone na pinapahinto ang download kapag napunta sa background ang browser. Panatilihin itong nakabukas sa harap para sa malalaking file |

## Mga hakbang

1. Sa mobile browser mo, buksan ang [panpull.com](https://panpull.com/fil?utm_source=github&utm_medium=tutorial#link-checker).
2. I-long press ang input field at i-paste ang Baidu link. Kung buong chat message na may link at extraction code ang nakopya mo, iyon na ang i-paste: makikilala ang dalawa.
3. Basahin ang resulta: bilang ng file, kabuuang laki, presyo. Walang singil hanggang 150 MB.
4. Mag-log in gamit ang email at password. Kung may bayad ang order, magbayad sa PayPal o card.
5. Puwede mo nang ibaba ang phone kung gusto mo. May darating na email kapag handa na ang mga file.
6. I-tap ang link sa email, saka i-tap ang **Download** sa page na bubukas.

## Saan makikita ang file pagkatapos

| Phone | Saan titingin |
| --- | --- |
| iPhone, iPad na may Safari | Ang arrow icon sa tabi ng address bar, o sa **Files** app, sa folder na **Downloads** |
| Android na may Chrome | Menu ng browser, saka **Downloads**; o ang folder na **Downloads** sa file manager mo |

Isang tap lang para buksan ang ZIP sa Files app (iPhone) o sa file manager (Android).

## Kapag may problema

- **Parang walang nangyari pagkatapos i-tap ang Download.** Buksan muna ang download list ng browser bago mag-tap ulit. Puwedeng magsimula ng pangalawang kopya ang pangalawang tap.
- **Naputol ang download.** Suriin ang storage at signal, saka i-tap ulit ang link sa email mo. May bisa ito nang 24 oras para sa bayad na order at 1 oras para sa libre.
- **Masyadong malaki ang file para sa phone.** Buksan ang parehong email sa computer. Hindi nakatali sa iisang device ang link.
